# 사이트 공통 추가 규칙 (master-lab-prompt.md 뒤에 붙인다)

이 실험실은 사이트 `labs/<slug>/`에 들어가 빌드 시 공통 셸이 주입된다. 아래를 지킨다.

## 1. 품질 단계 (학교 크롬북 대응)
- 시작 시 `window.__SITE__?.quality`를 읽는다. 값은 `'high'` 또는 `'low'`(없으면 `'high'`).
- `'low'`이면 처음부터: GTAO/SSAO 끔, 보케(DoF) 끔, 블룸 해상도 절반, 그림자 맵 1개 1024px, 픽셀 비율 1, 입자 수 절반.
- `window.__lab.quality(level)`을 노출해 실행 중에도 바꿀 수 있게 한다.
- 완료 기준: `?lite=1`에서 내장 GPU 노트북(4GB) 기준 30fps 이상. 저사양에서도 현상 셰이더와 콘솔 그래프는 유지한다.

## 2. 사이트 셸과 겹치지 않기
- 셸은 데스크톱에서 **왼쪽 아래**, 모바일(≤980px)에서 **오른쪽 위**에 작은 알약 메뉴(모든 실험실 / 공유 / 저사양 / 기관용 의뢰)를 띄운다.
- 실험실 UI는 이 자리를 비운다. 직접 배치하고 싶으면 원하는 위치에 `<div data-site-slot></div>`을 두면 셸이 그 안에 그린다.
- `/` 키로 UI를 숨길 때 `window.__site?.setVisible(false)`도 호출한다.
- 실험실 자체의 공유 버튼은 `window.__site?.share()`를 호출한다(없으면 직접 구현).

## 3. 다국어
- `<html lang="ko">` 기본. 모든 HUD 문장을 `{ko, en}` 사전 한 곳에 두고 `?lang=en`이면 영어로 표시한다.
- 영어 문장도 캡션 규칙(실제 숫자 2~4개)을 지킨다.

## 4. 메타와 썸네일
- 같은 폴더에 `meta.json`을 둔다(형식은 `labs/hydraulic-ram/meta.json` 참고).
- `__lab.capture('thumb')`로 1200×750 히어로 샷을 찍어 `thumb.jpg`로 저장한다(공유 미리보기·갤러리 카드에 쓰임).

## 5. 검수자용 요약본
- `docs/reviewer-brief.md`: 지배 방정식, 사용한 근사와 과장 스케일, 대표 상태 3개의 입력값과 화면 표시값,
  손계산 결과를 한 장에 정리한다. 물리 교사·대학원생이 30분 안에 검수할 수 있는 분량으로 쓴다.

## 6. 영상 소스
- 시네마틱 샷 6개 외에 세로(9:16) 샷 3개를 `SHOTS_VERTICAL`로 노출한다. 쇼츠 녹화에 쓴다.
