# 학생 직접 조작 검수 · 2026-10-17 · v6.1.0

초등 11개, 중등 17개, 고등 물리학 7개·역학과 에너지 2개, 총 **37개 활동·117개 안내 조건**을 학생 화면에서 수행했다. 수레·배경의 형상과 재질, 기존 지도서 목표 45개와 물리 계산은 유지하며 안내와 입력·기구 연결을 수정했다.

## 검수 방법과 결과

- 데스크톱 1280×720, `?lite=1`: 현재 손잡이 중심에서 표시된 점선 화살표 끝으로 실제 포인터를 끌었다. 숫자 메뉴와 실행 API로 조건을 맞추지 않았다. 전원·영점·처음 위치 표시는 누르고, 학생 눈금 읽기·예상은 입력했다.
- 37활동·117조건 모두 통과. 저장된 조건마다 `interaction.method=pointer` 근거가 있는지 별도 저장 검증으로 확인했다. 준비·예상·관찰·측정 흐름을 검사했으며, 자유 서술의 학습 수준을 자동 평가한 것은 아니다.
- 모바일 크기 390×680에서 컬링, 수평대, 전자저울, 용수철저울, 탄성 모양, 추 지레, 안정성의 **7활동·27조건**을 실제 포인터로 재검수했다. 예상 안내를 누르면 해당 입력으로 초점이 이동하고, 실험대 복귀 후 조작할 수 있다.
- 잘못된 자리에 추 놓기, 키보드로 잡고 이동한 뒤 Esc 취소: 조건과 기록 수 유지.
- 별도 API 회귀: 37활동·117조건·452검사 통과. 물리·수업·교육과정·지도서·기구·입력 단위 검사 81개 통과. API 검사와 실제 드래그 검수를 구분한다.

## 발견한 문제와 수정

| 문제 | 수정·재확인 |
|---|---|
| 약하게/세게 미는 단계의 안내 거리가 같음 | 힘 크기·방향에 맞춰 실제 입력 거리로 화살표 끝 계산. 컬링 3조건·수레 8조건 통과. |
| 저울이 다음 물체 대신 이전 물체를 안내 | 현재 조건의 물체 우선 표시. 4물체 교체·측정 통과. |
| 작은 금속에 큰 상자의 질량이 남음 | 준비한 물체 종류와 질량 함께 반영. 가벼운 상자/무거운 금속 비교 통과. |
| 매단 모빌·크레인 추가 정상 높이에서 제거됨 | 기구별 제거 경계 적용. 무게 추가·제거·칸 이동 통과. |
| 기울어진 지레를 끌 때 회전하며 다른 칸에 놓임 | 잡는 동안 막대 좌표 고정, 실제 놓은 칸으로 위치 결정. 놓은 뒤 반응. |
| 그린 힘 화살표와 크기·방향 조건이 따로 움직임 | 그림·크기·방향 동시 반영. 2N·4N·왼쪽 그리기 통과. |
| 고등 평형 복원에 필요한 손잡이가 부족함 | 양쪽 팔길이와 누르는 힘을 장면에 연결. 3조건 통과. |
| 용수철·빗면·렌치·생활 도구의 안내 끝과 이동 불일치 | 실제 끝점·방향·이동 거리로 계산. 누르는 동안 변형, 놓으면 복원/작동. |
| 이미 맞춘 기준 상태에도 짧은 드래그 요구 | 준비된 기준 상태에 원 표시와 ‘놓고 관찰하기’. 바꿀 조건은 계속 드래그. |
| 여러 표시·빈 공간 손잡이가 혼란을 줌 | 현재 대상 하나 강조. 예비 추 한 물체에 손잡이 하나, 물체 표면에 배치. |
| 예상 미입력 때문에 기록되지 않는 이유가 불명확함 | ‘먼저 예상 적기 ↓’에서 입력으로 이동. 예상 전 조작 안내 숨김, 작성 후 다시 표시. |
| 모바일 입력 후 실험대가 화면 위로 사라짐 | 준비·실험에 ‘실험대 보기 ↑’ 제공. 입력 초점 해제 후 장면 복귀. |

지레 빈칸의 안내는 정답 칸으로 곧바로 이동시키지 않고 한 칸씩 조작해 균형을 찾게 한다. 화살표는 입력 방향·거리 안내이며 실제 손힘 측정값이 아니다. 환경·물체 종류는 단계에 맞춰 준비하고 비교할 힘·위치·개수는 학생이 조작한다.

## 근거·재현·한계

`verification/results/student-drag-v7/summary.json`에 집계, `student-pointer-report.json`에 저장 검증과 전체 상태, `student-runs.json`에 포인터 좌표·화살표·조건별 결과를 보관한다. 실패 후 수정한 시도도 남아 있으므로 활동별 마지막 시도로 최종 결과를 확인한다. 모바일 근거는 `mobile-` 파일, API는 `teaching-qa.json`, 단위 검사는 `validate-*.json`이다. 화면은 `verification/evidence/student-drag-v7/`의 원본 PNG와 37개 장면을 모은 7개 검토 시트에 있다. 시트 일부는 중간 수정 전 화면이며 최종 대표 화면은 `final-desktop.png`이다.

전용 테스트 포트에서 `node serve.mjs 4197` 실행 후 실험실에서 조작하고 `/__student_audit`의 저장 검증을 실행한다. `student-pointer-runner.mjs`는 CUA의 실제 Tab 입력을 받아 화면 손잡이·SVG 끝점만 읽으며 실험 API를 호출하지 않는다. `/__teaching_qa`는 별도 API 검사로 해당 포트의 테스트 기록을 초기화한다. 학생이 기록 중인 포트에서는 실행하지 않는다.

실제 아동 참여 사용성 조사, 물리 터치 기기, 4GB Chromebook FPS는 이번 범위에 포함하지 않았다. 지도서의 모든 교육 효과나 학생 습득을 보증하는 보고서는 아니다.
