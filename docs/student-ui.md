# 학생용 설명·기록 UI · 2026-10-14

기존 3D 교실 배경·수레·상자·조명·재질·화살표·카메라·물리 계산은 유지한다. 이번 수정은 설명 패널과 기록 영역의 가독성, 한 번에 제시하는 정보량에 한정한다.

## 화면 구성

- 힘 정하기: 제목 24px, 주요 안내 16px(모바일 17px), 힘 값 25px. 청록/주황의 역할과 방향을 표시하고 52px 이상 버튼으로 힘을 바꾼다.
- 예상하기: ‘다음: 움직임 예상’으로 이동한다. 힘 조절 버튼을 접고, 큰 방향 그림과 왼쪽/멈춤/오른쪽 선택을 보여 준다. 예상 선택 후 실험을 실행한다. ‘힘 다시 바꾸기’로 돌아갈 수 있다.
- 새 물체 적용에도 같은 조작→예상 순서를 사용한다. 기존 여섯 수업 단계와 평가 기준을 바꾸지 않는다.
- 실험 기록: 기본은 실험 번호 / 양쪽 힘 / 관찰한 움직임의 세 열이다. 방향과 색, N 값을 함께 표시한다. 본문은 데스크톱 17px, 모바일 16px이며 근거 선택 버튼은 48px 높이다.
- ‘내 예상도 보기’를 켜면 각 회차 아래에 당시 예상과 관찰을 표시한다. 원본 예상·수정 이력과 JSON 내보내기·교사 평가 데이터는 계속 보존한다.
- 기록은 직접 펼치거나 이유 찾기 단계에서 사용한다. 새 관찰마다 자동으로 펼쳐 장면을 가리지 않는다.

조작/예상 화면 전환은 표시 상태이며 물리 실험 횟수·응답·평가 점수를 만들지 않는다. 힘을 바꾸면 예상을 다시 고르게 하는 기존 규칙을 유지한다. 초기화는 표시 상태도 초기화한다. 글자 없는 전시 모드의 기존 그림 UI와 한국어/영어 사전을 유지한다.

## 검수

수업·기록·평가 회귀 검사, 방향별 세 실험, 큰 글자/버튼 크기, 표시 단계 분리, 세 열 기록의 실제 값, 상세 예상 표시 시 원본 기록 보존을 검사한다. 데스크톱과 작은 모바일에서 실제 조작과 가로 넘침을 확인한다. 결과와 화면은 outputs/student-ui에 보관한다. 초중학생 대상 사용성 관찰을 실제로 실시한 것으로 주장하지 않는다.
