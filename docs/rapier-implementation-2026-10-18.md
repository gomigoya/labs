# Rapier 적용·검수 — v6.3.0

배경, 조명, 수레 모델·재질을 유지하고 수레·수평대·용수철의 반응과 계측을 교체했다. `instrument-physics.js`가 한 번에 한 기구의 Rapier 세계를 소유한다. 고정 120Hz로 계산하고 30Hz 관측 시계열과 마지막 관측 상태를 저장한다. 렌더링 품질은 물리 조건을 바꾸지 않는다.

## 적용 범위와 조작

- 초등 컬링·무게와 밀기, 중등 두 힘, 고등 힘 복습·역학 벡터의 수레: 실제 힘에 가속하고 합력 0에서 이전 속력을 유지한다. 거리 축척은 항상 0.35장면단위/m. 바퀴 회전은 같은 이동량에서 계산한다. 목표선도 같은 축척으로 수정했다.
- 초등 수평대: 추를 놓거나 칸을 옮기면 접촉·관절·중력으로 회전한다. 결과 각도를 대입하지 않는다. 판을 벗어난 추는 실험대 바닥에 떨어지고 결과에 표시한다. 고등 추 지레·수평대의 매단 추는 고정 부착으로 단순화했다.
- 중등 중력·탄성 용수철: 강체에 탄성력·감쇠력과 하중을 주어 늘어남과 안정화를 계산한다. 코일 피치는 변하되 철사 굵기를 유지한다. 자는 cm 단위이고 끝점과 같은 2.4장면단위/m이다.
- 초등 용수철저울: 물체를 걸면 눈높이 조절 전에도 반응한다. 읽기 준비를 마친 뒤 기록한다. 추를 빼면 이전 늘어남에서 복원된다. 내부 코일·표시자는 읽기용 확대이며 외부 추와 확대율이 다르다(교사 안내에 명시).
- 잡기 취소는 Rapier 세계 스냅숏과 관측 이력까지 복원한다. 물체 호버 흔들림은 기존 렌더링 안내를 유지한다.

## 화면·기록의 출처

`instrument-measurements.js`가 실제 관측에서 위치·속력·가속도·각도·지지된 돌림힘·늘어남·용수철 힘·저울 값을 구한다. 같은 값이 장면, 숫자, 시계열 그래프, 실험 기록으로 이어진다. 용수철 힘–늘어남 비교 그래프도 실제 관측점을 사용한다. 수레 관찰 종료는 일시정지이며 속도를 0으로 바꾸지 않는다. 정적 측정은 안정화 후 읽고, 최대 시간에 이르면 미안정 상태를 표시한다.

기록에는 `simulation.model`, 최종 모의 시각, 안정화 여부, 시계열과 마지막 상태가 들어간다. 내보내기·교사 화면·다시 불러오기에서 보존하고, 다른 기구의 관측값이나 손상된 시계열은 거부한다. 이전 해석식 기록은 이론 계산 출처로 남긴다. 입력 하중·합력 등 기준 수치는 이론 값도 함께 보존한다.

## 검증 근거

- 수치·교육·입력 회귀 스크립트 7개. Rapier 전용 13항목은 힘/질량, 등속 운동, 두 방향 속력, 정적 늘어남, 저울, 수평대 회전, 떨어진 추, 프레임률 독립성, 하중 제거, 취소, 저장·검증을 검사한다.
- 40개 대상 안내 조건의 수치 스캔: 모두 유한 값, 정적 기구 모두 제한 시간 안에 안정화.
- 실제 브라우저 37개 활동·117개 안내 조건, 533개 검사 통과. 대상 40조건은 장면 자세·그래프·관측·저장 값 일치까지 대조했다. 이는 자동 교육 경로 회귀 검사다.
- 별도 포트에서 학생 UI로 직접 수행: 수레 밀기, 빈 수평대 관찰, 추 양쪽에 놓기와 칸 이동, 용수철 15cm 늘리기와 취소, 수평·영점 조절 후 사과를 걸고 눈높이를 맞춰100g 읽기, 고등 지레에 추를 추가하기. 각 대표 결과를 장면·그래프·저장·다시 불러오기와 대조했다.
- 390px iframe에서도 실제 포인터로 용수철을10cm 늘리고5.00N 기록의 일치를 확인했다. 모바일 폭의 반응형 검수이며 실물 터치 기기 검수는 아니다.
- 근거: `verification/results/rapier-v10/`, 화면: `verification/evidence/rapier-v10/`. 원래 사용자 포트4173과 사이트는 변경하지 않고 전용4218/4220 포트를 사용했다.

검수 중 수정한 문제: 회전축과 무게중심을 동시에 위치 잠금하여 회전하지 않던 문제, 내부 코일의 이중 축척, 저울 물체와 케이스 겹침, 0길이 연결선의 비유한 축척, 사선 운동 속력 누락, 떨어진 추의 이론 결과 오표시. 별도 코드 리뷰에서 지적한 항목도 수정·재검증했다. 최종 시각 검수에서 SVG 그래프가 공통 아이콘 높이25px를 상속하던 문제도 수정했다. 데스크톱 그래프 실측 크기는332×186.75px이며 숫자와 축을 읽을 수 있음을 화면으로 확인했다.

## 범위와 한계

Rapier 전체를 실제 장치의 정밀 복제로 보지 않는다. 판 질량·감쇠·마찰·멈춤 장치, 용수철 감쇠, 마우스 입력→힘 대응은 가상 기구의 명시적 근사다. 수레 바퀴는 개별 동적 강체가 아니다. 부력·유체·모빌·안정성 등 나머지 기구는 기존 모형을 유지한다. 실제 학교 크롬북4GB의30fps와 학습 효과는 이 검수로 확인하지 않았다. 상세 식·축척·대표 상태3개는 `reviewer-brief.md`에 정리했다.
