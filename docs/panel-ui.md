# 설명·실험 기록 UI 수정

2026-10-13. 사용자가 지적한 대상은 3D 배경이나 수레, 문구만이 아니라 설명과 실험 기록 영역의 시각 디자인이다.

## 시각 변경

- 설명 패널: 큰 둥근 카드와 중첩 박스를 줄이고, 얇은 테두리·작은 모서리·구분선으로 안내 / 힘 설정 / 예상 / 실행의 위계를 만든다. 고정 높이를 없애 내용만큼 표시한다. 긴 설명 단계는 최대 높이 안에서 스크롤한다.
- 글자: 활동 제목 18px, 안내 13px, 보조 11–12px. 기존 녹색 계열과 따뜻한 종이색을 유지한다. 숫자와 단위는 고정폭 글자로 구분한다.
- 힘 설정: 두 개의 큰 색 카드 대신 색 띠·역할·방향·N 값이 정렬되는 행으로 만든다.
- 기록: 큰 빈 박스와 반복 그림 카드를 접이식 표로 교체한다. 회차 / 청록 N / 주황 N / 예상 / 관찰을 실제 실험 데이터로 표시한다. 새 결과가 생기면 열리고, 직접 접을 수 있다. 설명 단계에서 자동으로 펼쳐 근거 회차를 고르게 한다.
- 설명 선택: 세 개의 작은 카드 대신 그림과 문장이 나란한 행으로 정리한다. 선택 상태와 확인 버튼을 구분한다.

## 유지한 부분

Three.js 런타임 스크립트는 기준 커밋 dcd5969와 일치한다. 교실 배경, 황동 실험대, 수레와 상자, 재질·조명·화살표·카메라·물리 계산을 수정하지 않았다. 기존 헤더와 수업 단계, 학생 기록 스키마, 교사 평가 의미도 유지한다. 한국어/영어의 표 머리글과 접근성 이름은 중앙 사전에 둔다. 새 기록 UI는 글자가 있는 수업 모드에만 적용한다.

문구 수정은 ‘실험 카드’라는 지시를 새로운 표의 ‘회차 선택’에 맞추는 부분으로 한정한다.

## 검수

기존 예상→실험→결과 검수와 수업 기록·평가 검수를 실행한다. 실제 UI에서 표 펼치기/접기, 근거 회차 선택, 설명 확인을 점검한다. 데스크톱과 모바일에서 장면 가림, 가로 넘침, 표 읽기를 확인한다. 증거 화면은 D:의 outputs/panels에 보관한다.
