# 물리 엔진과 시각적 피드백 개선 검토

2026-10-18 · Superpowers brainstorming의 기술 검토(spike) 결과. 엔진 적용 방안과 검증 기준을 제안한 문서이며, 새 물리 엔진을 구현하거나 성능을 측정한 결과는 아니다.

## 결론

기존 Three.js 배경·실험대·수레·재질은 유지한다. Rapier를 공통 물리 계층으로 추가하고, 교과 실험에 필요한 용수철·부력·계측 모델을 연결하는 방식을 권한다. 초중고는 같은 물리 세계를 사용하고 안내·조작 범위·계측 깊이만 다르게 한다.

## 현재 소스에서 확인한 한계

1. `index.html`의 `PHYSICS.solve/advance`는 합력·돌림힘·질량·관성에 따른 평면 운동을 적분한다. `advancePhysics`는 최대 1/120초씩 나누어 계산한다. 따라서 현재 움직임 전체가 단순 영상인 것은 아니다. 다만 일반적인 접촉·충돌·관절·수레와 짐의 상호 작용을 다루는 공통 물리 세계는 없다.
2. `teaching-apparatus.js`의 수평대는 `Math.sign(left*leftPos-right*rightPos)*.12*progress`로 회전한다. 불균형 크기가 달라도 최종 각도는 약 ±6.88도다. 막대의 질량·관성·회전축 높이와 추의 충돌로 각도가 정해지는 구조가 아니다.
3. `teaching-geometry.js`는 여러 기구의 결과 자세를 관찰 진행률로 계산한다. 용수철·부력·마찰·완충 장치도 시간에 따른 실제 힘과 운동을 공통으로 적분하는 방식으로 보완해야 한다.
4. 수레의 `cartDisplayScale`은 큰 이동을 화면에 맞춰 축소한다. 소스 기반 계산에서 같은 4N을 1.2초 적용하면 1kg 수레의 이론 이동은 2.88m, 표시 이동은 1.008 장면 단위다. 0.5kg은 5.76m, 표시 이동은 1.45 단위다. 실제 2배인 거리 차이가 화면에서는 약 1.44배로 압축된다. 비교 실험 안에서는 동일 축척을 유지하고 카메라 추적·눈금·그래프로 범위를 보완하는 편이 좋다.
5. `teaching-ui.js`의 관찰·기록은 1.2초에 마무리되고 `record()`는 입력 조건의 해석식 결과를 저장한다. 화면의 실제 궤적을 측정한 값과 구별해야 한다. 정적 실험은 안정화 후 계측하고, 운동 실험은 정해진 모의 시간에 관측한다. 관찰 일시정지는 물체가 물리적으로 멈춘 상태와 구별한다.

## 접근 방식 비교

| 방식 | 장점과 범위 | 판단 |
| --- | --- | --- |
| 기존 계산과 결과 애니메이션 보강 | 적은 변경으로 흔들림·속도 차이·눈금 반응을 보완할 수 있다. 일반적인 접촉·충돌·다관절 반응은 별도 구현해야 한다. | 임시 개선에 적합 |
| Three.js + Rapier + 교과별 힘·계측 모델 | 강체·충돌·관절을 공통으로 처리하고 기존 장면을 연결할 수 있다. 물리 단위와 계측·수업 판정을 함께 정비해야 한다. | 권장 |
| Cannon-es 기반 공통 물리 계층 | JavaScript 기반의 다른 선택지이며 스프링·힌지 등도 제공한다. 같은 기구로 정확도·성능을 직접 비교해야 한다. | Rapier 도입 조건이 맞지 않을 때 대안 |

Rapier는 WebAssembly 초기화가 필요하다. 현재처럼 빌드 없는 구조에서는 공식 compat 패키지로 시제품을 만들 수 있다. 정식 적용에서는 호환 버전을 고정하고 필요한 파일을 함께 제공해 학교 네트워크의 외부 CDN 의존을 줄인다. 특정 엔진이 이 기기에서 더 빠르다는 비교 측정은 아직 하지 않았다.

## 학생이 보아야 할 실제 반응

| 실험 | 직접 조작과 물리 반응 | 계측과 해석 |
| --- | --- | --- |
| 수평대·지레 | 추를 놓으면 접촉하고, 막대가 하중과 거리에 따라 회전한다. 감쇠에 따라 흔들림이 줄어든다. | 추 위치·질량·회전각·각속도·돌림힘. 균형 복귀에는 축과 전체 무게중심 높이도 명시해야 한다. 이상적인 중립 평형을 강제로 수평으로 돌려놓지 않는다. |
| 수레·두 힘의 평형 | 힘을 주는 동안 가속하고 놓으면 관성으로 이동한다. 짐을 늘리면 같은 힘에 대한 가속도가 줄어든다. 바퀴 회전은 이동 거리와 연결한다. | 위치·속도·가속도·힘 이력. 마찰 없는 평형에서 이미 움직이는 수레는 등속 운동한다. |
| 용수철·용수철저울 | 당기는 동안 실제 길이가 변하고, 놓으면 질량·강성·감쇠에 따라 진동하고 안정된다. | 실제 늘어난 길이에서 힘과 눈금을 구한다. 코일의 피치를 갱신하되 철사의 굵기는 유지한다. |
| 마찰·빗면 | 작은 힘에는 버티고 임계 힘을 넘으면 미끄러진다. 힘을 빼면 마찰에 따라 감속한다. | 정지/운동 마찰의 교재 모델과 엔진 접촉 마찰을 중복 적용하지 않는다. 바퀴 구름 저항과 나무토막 미끄럼 마찰도 구별한다. |
| 안정성·모빌·돌림힘 | 중심을 옮기거나 물체를 기울이면 중력·관절·접촉에 의해 복원되거나 넘어진다. | 무게중심, 지지 범위, 관성, 실제 작용점으로부터 회전 반응을 확인한다. |
| 부력·넘친 물·잠수부 | 실제 잠긴 부피에 따라 부력이 변한다. 가라앉고 떠오르는 운동과 저울 값이 함께 바뀐다. | `F_b=ρgV_submerged`와 물의 저항을 별도 힘 모델로 적용한다. 수면 파문은 별도 시각 근사이며, 정밀 유체 해석 결과로 취급하지 않는다. |

물체를 가리는 원·화살표를 다시 덧씌우지 않는다. 접촉, 회전, 코일 길이, 줄 방향, 바퀴 회전, 접촉 그림자를 우선 피드백으로 사용한다. 과학적 힘 화살표가 필요한 과정에서는 실제 작용점·방향·크기와 일치시킨다. 호버 안내의 작은 흔들림은 장식이며 실제 물리 상태·계측값을 바꾸지 않아야 한다.

## 공통 구조의 방향

- 입력 → 물리 세계 → 물체 자세, 계측값, 그래프, 실험 기록으로 이어지게 한다. 결과를 화면과 기록에서 따로 계산하지 않는다. 해석식은 검증용 이론값으로 보존하고 측정값과 구별한다.
- 배치 조작과 힘을 주는 조작을 분리한다. 수레를 밀거나 당길 때는 힘·충격량 또는 제한된 스프링 연결로 조작하고, 동적 물체의 위치를 매 프레임 덮어쓰지 않는다. 실제 손힘을 측정하는 기능은 아니므로 입력과 힘의 대응을 교정한다.
- 내부 단위는 m·kg·s로 통일하고, 장면 좌표 변환은 한곳에서 처리한다. 보기 좋은 모델의 크기로 물체의 질량·관성이 뜻하지 않게 결정되지 않게 한다.
- 고정 시간 간격과 렌더 보간을 사용한다. 초기 검증 후보는 물리 1/120초다. 그 값의 적정성은 관절·스프링·기기 측정으로 결정한다. 표시 프레임률이 달라도 결과가 같아야 한다.
- 정적 실험의 안정화와 운동 실험의 관측 시점을 별도로 정의한다. 예를 들어 정적 기구의 속도·각속도가 충분히 작게 유지된 구간에서 평균을 읽는다. 등속 운동은 ‘정지’로 판정하지 않는다.
- 초기에는 한 번에 현재 기구만 활성화한다. 방·소품 전체에 충돌체를 만들지 않는다. 간단한 상자·구·캡슐 충돌체, 필요한 관절, 휴면 기능을 우선 사용한다.
- 저사양은 그림자·후처리·물 시각 효과를 줄인다. 물리 법칙과 계측 기준은 학년·화질에 따라 바뀌지 않는다. 4GB 내장 GPU 기기의 30fps는 실제 기기 검수 전까지 목표다.
- 저장 기록에는 모의 시간·실제 관측값·물리 모델 버전을 남긴다. 기존 해석식 기반 기록을 새 엔진의 실측 기록인 것처럼 변환하지 않는다.

## 먼저 검증할 세 기구

1. **수평대:** 하중을 놓는 접촉, 실제 회전, 축·무게중심·감쇠, 평형 판정. 가장 직접적으로 현재의 고정 각도 연출을 대체한다.
2. **수레:** 일정 힘·질량·관성, 같은 축척에서의 운동 비교, 두 힘의 평형, 잡기·놓기 입력.
3. **용수철:** 늘어남·복원·감쇠 진동, 안정화 후 눈금 읽기, 기록과 장면의 일치.

이 세 기구에서 공통 입력·물리·계측 연결을 검증한 다음 마찰·빗면·안정성·모빌로 확장한다. 부력·넘친 물은 잠긴 부피와 유체 힘 모델을 별도로 검수한다. 고무 변형·정밀 유체 등은 별도 범위로 다룬다.

## 손계산과 검수 기준 제안

| 조건 | 기준값 |
| --- | --- |
| 1kg 수레, 2N, 처음 정지, 1초, 마찰 없음 | a=2m/s², v=2m/s, x=1m |
| 2kg 수레, 같은 조건 | a=1m/s², v=1m/s, x=0.5m |
| 합력 0, 처음 속도 1m/s, 마찰 없음 | 1초 뒤에도 v=1m/s |
| 100g×20cm와 200g×10cm | 양쪽 돌림힘 각각 0.196N·m, 알짜 돌림힘 0 |
| 0.5kg, 용수철 상수 50N/m, g=9.8m/s² | 정적 늘어남 9.8cm, 힘 4.9N |
| 물 1000kg/m³에 200cm³ 잠김, 물체 무게 9.8N | 부력 1.96N, 정적 매단 힘 7.84N |

초기 수치 오차 허용 목표는 대표 이상 조건에서 1–2%로 제안한다. 이는 아직 달성한 수치가 아니다. 대칭 평형의 장시간 드리프트, 충돌 관통, 에너지의 비정상 증가, 브라우저 프레임률·화질 차이, 드래그 취소·일시정지·복원·기록 재현도 함께 검수해야 한다. 기존 37개 활동·117개 안내 조건의 교육 경로가 유지되는지도 별도 회귀 검수한다.
