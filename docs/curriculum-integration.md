## 수업·조작·기록

각 활동은 **준비 → 실험 → 정리 → 적용**으로 진행한다. 한 번에 현재 지시와 바꿀 조건 최대 두 개를 보여 주며 다른 조건은 접는다. 실험 기록도 기본적으로 접는다. 예상·기구 준비·영점·물체 올리기·학생 화살표·눈금 읽기·표/그래프·설명·새 상황 적용을 각각 기록한다. 초등 전체 12차시를 한 수업에 끝내는 방식이 아니다.

총 37개 활동, 117개 안내 조건, 45개 목표 대조 항목이다. [목표별 구현표](teacher-guide-coverage.md)는 원문 쪽수, 연결 활동, 별도 교사 검토 여부를 제공한다. guide.html은 모든 안내 조건의 순서와 기구·안전·확장 활동을 한/영으로 표시한다.

- 전자저울: 비슷한 네 물체 예상 → 수평 → 전원 → 빈 접시 영점 → 물체 올림 → 직접 읽은 값 입력 → 순서·차이 비교.
- 용수철저울: 부분·용량·큰/작은 눈금 확인 → 영점 → 안정화 → 눈높이 → 읽기 → 빈 봉투 영점 → 물체 제거 후 표시자. 틀린 읽기와 수정도 보관한다.
- 중등 탄성: 초기 위치 표시와 영점 → 같은 용수철의 5/10/15/20 cm 측정 → 실제 측정점 그래프 → 25 cm 예상·확인. 서로 다른 용수철의 점을 한 직선에 섞지 않는다.
- 고등 지레: 빈 기구 수평 → 지정된 세 실험의 빈칸을 추 조절로 해결 → 개수×칸의 규칙. 정답 조건을 자동으로 채우지 않으며 매 조건 관찰 전에 예상을 기록한다.
- 설계·모빌·생활 조사: 계획, 조건 통제, 수정 전후, 근거 설명, 조사 출처, 발표·동료 의견을 남긴다. 달 운동 장치와 기울어진 건물 소개는 선택 확장이다.

## 연령별 경계와 평가

초등 학생에게 힘의 형식적 정의, 질량 구분, 후크 법칙, 돌림힘·일의 식을 요구하지 않는다. 수평대는 같은 거리와 다른 거리의 결과를 구별한다. 도구는 같은 짐을 직접 드는 경우와 각각 비교하고 지레/빗면의 보편적 우열이나 거리-힘 교환을 평가하지 않는다. 중등의 계수·후크 식은 교사 배경이며 학생은 측정과 관계를 설명한다. 고등은 힘과 돌림힘 평형 조건을 함께 확인한다.

안내 조건과 일치하는 실제 기록, 학생이 읽은 저울값, 확인 질문, 설명, 처음 예상·돌아보기, 필요한 계획이 있을 때만 제출 근거를 확인한다. 자유 탐구와 과거 기록은 보존하되 새 안내 실험을 완료했다고 소급하지 않는다. 예상 오답을 감점하지 않으며 첫 답·수정 답을 보관한다. 조사·발표·협력·경청과 설명의 질은 교사가 검토한다. 버튼 클릭과 정답 제출만으로 습득·공식 성취수준을 인증하지 않는다.

## 구조·호환

teaching-geometry.js: 공통 표시 기하. lesson-guidance.js: 학생 조작·관찰 안내. curriculum-model.js/curriculum-extension.js: 과목·변수·계산·기록 검증. lesson-content.js: 순서·조건·준비·질문. teaching-apparatus.js: 기존 장면에 추가하는 기구. teaching-ui.js: 학생 흐름. teacher-coverage.js/teacher-guide-content.js/teaching-records.js: 출처·교사 안내·기록 검토.

저장 키 force-lab-curriculum-v1을 유지하고 schemaVersion 2로 읽는다. 이전 v1 파일을 보존·변환하며 측정값을 재계산한다. 가져오기는 원래 기기 기록을 덮어쓰지 않는다. 이름·학번·자동 서버 업로드는 없다. ?course=elementary|middle|physics|mechanics, ?lang=en, ?lite=1을 지원한다. 이전 ?course=lesson, ?wordless=1, teacher-legacy/guide-legacy와 촬영·화질·사이트 셸 API를 유지한다.
