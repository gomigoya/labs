# 힘과 평형 학생 과정 검수 — v5.0.0

2026-10-17. 기존 교실, 실험대, 수레의 형상·재질을 유지했다. 학생 UI에서 테스트 기록을 비우고 **초등 11개·중등 17개·고등 물리학 7개·역학 확장 2개, 총 37개 활동·117개 안내 조건**의 준비 → 실험 → 정리 → 적용을 진행했다. 실행 중에는 실제 버튼, 선택 상자, 화살표 조작, 눈금 입력, 설명 입력을 사용했다. 별도 API 통합 검사는 수치 적분·좌표·저장 형식을 확인한다.

## 발견한 문제와 수정

| 범위 | 발견한 문제 | 최종 구현 |
|---|---|---|
| 학생 안내 | 첫 조건의 조작이 모두 접혀 있거나 실행 버튼이 입력을 가림 | 현재 조작 1–2개를 먼저 표시. ‘전체 실험 순서’·보조 조건은 접음. 큰 행동 문장 + 구체적인 관찰 문장. 준비가 안 된 이유 표시. 실행 버튼 겹침 제거 |
| 초등 크기·무게 | 큰/작은 물체 비교가 질문에만 존재 | 큰 빈 상자와 작은 금속을 같은 힘으로 밀고 거리 비교하는 두 실제 조건 추가 |
| 수평대·모빌 | 안내 정답 위치·무게가 자동으로 맞춰짐 | 직전 값에서 시작해 학생이 개수·칸·무게를 바꾸어 수평을 찾음. 모빌 장식 추가와 구슬·별·마름모 선택도 장면에 반영 |
| 두 수평대 추론 | A/B, B/C 근거 장면 없이 문장만 제시 | 같은 거리 A/B 기울기와 다른 거리 B/C 수평을 실제 기구로 비교 |
| 용수철저울 | 눈높이가 상태값에 그침. 빈 고리 조건이 제거 조작을 대신함 | 눈·시선이 표시자와 정렬됨. 고리에서 직접 제거해야 빈 상태 기록 가능. 빈 봉투 → 영점 → 물체, 읽은 값 입력·수정 기록 유지 |
| 직접 들기·지레·빗면 | 비교 물체·상승량이 달라짐 | 같은 추를 동일 0.5m에 해당하는 0.45 장면 단위만큼 올림. 초등 힘 비교는 100·25·30처럼 자연수 눈금 사용 |

| 풍선·부력 | 평형 풍선이 내려감. 공기 속 풍선에 물 수조 표시. 이미 잠긴 추의 부력이 계속 증가 | 평형 허용 오차 적용, 공기 장면의 물 제거. 넘침은 추의 0·1/2·전체 잠김과 수집한 물의 양을 일치시킴 |
| 넘친 물 | 공기 중/물속 센서 값이 빠짐 | 기준 9.8N, 물속 센서, 빈 그릇, 물+그릇, 넘친 물, 센서 차이를 함께 비교 |
| 힘과 운동 | 큰 힘에서 수레가 원점으로 순간 이동. 선풍기 방향·공 화살표 불일치 | 교육 모드의 경계 초기화 제거. 계산 좌표는 유지하고 표시 축척만 줄임. 공 중심에 힘 화살표 배치, 옆바람 방향 수정 |
| 장치 설계 | 목표선·범퍼가 계산한 거리와 불일치. 비교 중 질량·속도도 바뀜 | 1m 목표선과 접촉·압축 위치를 같은 축척으로 표시. 질량·출발 빠르기·완충재 값 통제 |
| 고등 단원 순서 | 알짜힘 복습이 뒤 활동에 위치 | 첫 활동 안에서 같은 방향 합 → 반대 방향 평형 → 스패너 거리·힘·각도. 이후 추 실험과 두 평형 조건으로 진행 |

## 교사가 판단할 항목

자동 확인은 조건에 맞게 제출한 측정·응답 근거를 뜻한다. 설명의 질, 생활 사례 조사 출처, 자유 설계의 타당성, 발표·협력·경청, 실제 학습 습득은 교사가 평가한다. 달 운동 장치와 기울어진 건물 소개는 확장 기록·관련 장면을 제공한다.

수레는 원문의 스톤·상자를, 동일 추는 원문의 우유 등 비교 물체를 대신한다. 모빌은 제공한 장식과 무게·위치로 만드는 제한된 설계 모형이다. 회전·유체·들어 올림은 방향과 관계를 보여 주는 보간이며 실물의 시간·오차·손의 감각을 재현하지 않는다. 실물 실험·모둠 활동과 연결해 사용한다. 실제 4GB Chromebook의 30fps와 학생 대상 사용성·학습 효과는 이번 데스크톱 검수로 보증하지 않는다.
