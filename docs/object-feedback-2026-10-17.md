# 물체 호버 반응·가림 제거 검수 · 2026-10-17 · v6.2.0

## 적용

수평대의 상자부터 모든 실험의 공통 장면 입력에 적용했다. 물체를 가리던 원·양방향 아이콘·점선 이동 화살표를 제거했다. 물체 위에 마우스를 올리거나 키보드로 초점을 옮기면 해당 물체만 0.72초 동안 작게 흔들린 뒤 원래 자세로 돌아온다. 계속 올려 두어도 반복하지 않는다. 잡는 순간 모션을 복원하고 실제 드래그를 시작한다. 교실·실험대·수레·기구의 형상과 재질은 유지한다. 힘의 크기·방향을 나타내는 과학적 벡터는 유지한다.

장면 위의 짧은 문구는 접근성 읽기용으로만 남기고, 예상 입력 안내는 설명 패널의 입력칸 옆에 둔다. 놓을 자리는 필요한 물체를 끄는 동안 빈 공간에 작은 안내로 표시한다. 손잡이는 보이지 않는 입력 영역으로 유지하며 실제 투영된 물체 크기와 최소 44px 영역으로 잡을 수 있다. 입력 영역이 겹치면 작은 부품을 우선하고, 장면 밖 설명 패널·머리말에는 걸치지 않는다. 키보드 초점 테두리는 접근성을 위해 남긴다.

흔들림은 렌더링 전용으로 최대 이동 0.015 장면 단위, 회전 0.022rad 이하이다. 매 프레임 물리·기구 갱신 전에 복원하며, 잡을 때도 앵커와 입력 스냅샷을 얻기 전에 복원한다. 조건값·평형 계산·기록에 넣지 않는다. ‘이동 줄이기’ 선호가 있으면 장식 모션을 끈다.

## 직접 검수와 수정

- 데스크톱 37활동·117조건을 실제 포인터로 재수행하고 저장된 모든 조건의 pointer 근거를 별도로 확인했다. 숫자 메뉴나 실험 실행 API로 안내 조건을 완료하지 않았다. 전원·영점 등은 실제 준비 버튼, 눈금·예상은 학생 입력, 단계 이동은 버튼과 키보드를 사용했다.
- 앞 버전에서 검증한 제스처 거리를 현재 물체 앵커에 맞춰 재생했다. 이번 검수는 입력·시각 반응 검수이며, 새 학생이 안내 없이 과제를 이해한다는 사용성 조사로 해석하지 않는다.
- 390×680에서 수레, 수평대, 전자저울, 용수철저울, 탄성 모양, 고등 추 지레, 안정성의 7활동·27조건을 실제 포인터로 통과했다. 마지막 입력 영역 수정 후 수평대·용수철저울·고등 지레와 예상 입력 이동을 재검수했다.
- 공통 button:hover 스타일이 상자 위에 사각 배경·테두리를 만들던 것을 장면 입력에 한정해 제거했다. 마우스 초점의 배경은 투명, 테두리 0, outline 없음이다.
- 검토 중 수레의 넓은 입력 영역이 위에 실린 짐을 가로채는 문제를 실제로 재현했다. 작은 부품 우선 처리와 몸통의 잡는 위치를 수정한 뒤 같은 동작에서 질량 4→3kg, 미는 힘은 그대로인 것을 확인했다.
- 가는 힘 화살표는 원뿔 머리뿐 아니라 선 부분도 입력 영역에 포함했다. 작용선 옮기기와 렌치 끝점 조작을 재검수했다.
- 잘못 놓기·키보드 Esc 취소에서 조건과 기록 수가 유지됐다. 원래 자세와 드래그 스냅샷 복원은 별도 코드 검토에서도 확인했다.
- 일반 모션 기록은 43개 움직임 프레임 후 190개 정지 프레임을 확인했다. 드래그 시작 검수는 11개 드래그 프레임 모두 장식 움직임이 없었다. 실제 검수 브라우저의 이동 줄이기 선호에서는 호버 중에도 장식 움직임이 없었다. 일반 모션은 로컬 검수용 iframe 미디어 환경에서 별도로 검사했고 사용자 설정을 바꾸지 않았다.
- 단위 검사 84개 통과. 별도 전체 과정 API 회귀는 데스크톱·390px 각각 37활동·117조건·452검사 통과이며, 실제 포인터 검수와 구분해 보관한다. 검수 도중 마찰 마지막 조건으로 넘어가지 않은 자동 검수 누락은 저장 검증이 포착했다. 단계 제목·준비 상태를 확인하도록 검사 도구를 보완하고 실제 세 조건과 저장 근거를 재확인했다.

## 증거와 재현

`verification/results/hover-v8/summary.json`에 집계, `student-pointer-report.json`에 전체 저장 근거, `student-runs.json`과 `mobile-student-runs.json`에 실제 좌표·동작·결과가 있다. 실패 시도도 남겨 두므로 활동별 마지막 시도가 최종 결과이다. `cargo-before-fix.json` / `cargo-after-fix.json`, `hover-*-qa.json`, `reject-cancel.json`에 개별 검수 근거가 있다. API와 단위 근거는 `teaching-*.json`, `validate-*.json`이다.

`verification/evidence/hover-v8/final-balance.png`는 최종 전체 화면이다. `hover-motion.gif`는 실제 검수 브라우저 프레임을 모아 반복 재생한 미리보기이며, 제품의 호버 모션은 한 번만 재생한다. 다른 PNG 일부는 최종 문구 배치 수정 전의 회귀 검수 화면이다.

전용 포트에서 `node serve.mjs 4207` 실행 후 실험실에서 조작하고 `/__student_audit`에서 저장 근거를 확인한다. `/__teaching_qa`의 API 검사는 그 포트의 시험 기록을 바꾸므로 학생이 쓰는 포트에서 실행하지 않는다. 일반 모션 검수용 `/__motion_qa_frame`은 로컬 서버 전용이며 배포 자산이나 사용자 환경을 바꾸지 않는다.

실제 아동 참여 사용성 조사·물리 터치 기기·4GB Chromebook 성능 인증은 이번 검수 범위가 아니다.
