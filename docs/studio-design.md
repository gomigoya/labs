# 기존 디자인을 보존한 수업 구조 개선 · 2026-10-13

사용자 수정 지시: 원래 실험실의 디자인을 유지하고, 화면 구조·실험 방법·교육 요소만 개선한다.

## 유지한 디자인

기준 커밋 5388d69의 3D 교실, 선반과 소품, 황동 원형 실험대, 노란 수레, 재질, 조명, 후처리, 색감을 복원했다. 크림색 반투명 패널, 녹색 글자와 버튼, 둥근 모서리도 유지한다. 교사 안내서와 기록 화면은 원래 스타일 그대로다. 직사각형 회색 실험대와 흰색·남색 UI는 사용하지 않는다. 해당 시도는 Git 기록 6c864fb에 보관한다.

## 바꾼 구조와 교육 요소

- 수레가 보이는 공간과 조작 영역을 분리한다. 데스크톱은 오른쪽 패널, 모바일은 장면 아래 조작부를 사용한다. 장면 자체는 원래 디자인을 유지하며 카메라 구도만 조정한다.
- 목표 → 고정된 힘 / 내가 바꾸는 힘 → 움직임 예상 → 실험 실행 순서로 배치한다. 힘의 실제 N 값, 방향, 색과 역할을 함께 표시한다.
- 교사 안내서에서 재구성한 여섯 단계 수업, 기본 빠른 경로, 조건 통제, 형성 평가 기준, 수정 이력을 유지한다.
- 예상 선택 전에는 실행 버튼을 비활성화한다. 실행하면 집게를 놓고 1.2초 관찰하며, 결과를 실제 실험 기록으로 남긴다.
- 기록을 장면 아래 별도 영역에 모은다. 설명 단계에서는 실제로 정지한 실험을 근거로 선택한다. 파란 상자 전이 활동에서는 크기와 방향을 다시 설계한다.
- 모바일에서는 조작부가 물체를 가리지 않도록 세로 스크롤을 사용하고 실험 시작 시 장면으로 돌아간다.
- 기존 ko/en 사전, localStorage 기록 스키마, 글자 없는 전시 모드, 저사양 모드, 심화 그래프와 셰이더를 유지한다.

## 참고 범위

[McGraw Hill 공개 자료](https://learn.mheducation.com/rs/303-FKF-702/images/virtual-labs-list-of-labs.pdf)의 장면·절차·기록 분리, [Labster 힘 실험 소개](https://www.labster.com/blog/get-students-excited-forces-free-body-diagrams)의 3D 탐구 구조, [ExploreLearning 교사용 자료](https://help.explorelearning.com/en/articles/8908851-gizmos-lesson-materials-overview)의 목표·수업 순서·배경 구분을 참고했다. 타사 외형을 복제하지 않는다. 오래된 공개 자료를 최신 UI라고 주장하지 않으며 Gizmos 전체를 3D라고 분류하지 않는다.

## 검수 기준

| 지점 | 기준 |
|---|---|
| 3D 장면 | 원래 지오메트리·재질·조명 유지 |
| UI 디자인 | 크림색 유리 패널·녹색 계열·원래 둥근 모서리 유지 |
| 조작 | 고정 변인과 조작 변인 구분, 실제 값 표시 |
| 실행 | 예상 선택 후 실험, 1.2초 조건 통제 |
| 기록 | 실제 예상·관찰만 누적, 설명 근거 선택 가능 |
| 모바일 | 장면 → 조작 → 기록, 가로 넘침 없음 |
| 교사 자료 | 원래 스타일·내용·평가 의미 유지 |
