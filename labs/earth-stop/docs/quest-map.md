# 지구 자전이 멈추면 — 퀘스트 지도

[theory-card.md](theory-card.md)의 물리·단위·시각 문법을 공유한다. 화면에는 단어·삽화·캐릭터·이모지 없이 기하 입체와 선화 기호만 둔다. 문서 속 질문과 함수명은 화면 문구가 아니다.

성취기준 인용(출처: `D:/labs/docs/curriculum/science-2022.csv`):

- **6과12-02**: “지구의 자전을 알고, 낮과 밤이 생기는 이유를 설명할 수 있다.”
- **4과01-01**: “일상생활에서 힘과 관련된 현상에 흥미를 갖고, 물체를 밀거나 당길 때 나타나는 현상을 관찰할 수 있다.” 관성은 심화 연결이다.

## 퀘스트 표

| Q | 연결 성취기준 | 학습 질문 | 장면 속 조작 | 시각 문법 | 관찰 증거 | 완료 조건 = PHYS 판정 |
|---|---|---|---|---|---|---|
| 1 | 6과12-02 | 지금 우리는 얼마나 빠르게 움직일까? | 현재 주기에서 적도 핀의 속도 렌즈와 벤치마크 비교를 연다 | 마디·겹치기 | 화살표가 여객기 점선보다 길고 소리 마디를 넘는다 | `judgeQ1({phi,speedSeen,benchSeen})`: 절대 위도 ≤1°, 두 열람 플래그 모두 참 |
| 2 | 6과12-02 | 극으로 갈수록 속도는? | 적도 상태를 고정한 뒤 핀을 높은 위도로 끈다 | 계단·겹치기 | 적도 점선보다 짧은 화살표, 60°에서 절반 | `judgeQ2({fromPhi,phi,decreaseSeen})`: 시작 절대 위도 ≤1°, 끝 ≥60°, 실제 `v` 감소, 관찰 참 |
| 3 | 4과01-01 심화 | 땅만 갑자기 멈추면 몸은? | 급정지 방식에서 큰 정지 버튼을 누른다 | 등시간 점·접선 렌즈 | 지표는 멈추고 구슬의 동쪽 흔적이 이어진다 | `judgeQ3({runId,phi,mode,measurement,relativeSeen})`: 현재 실행·위도와 일치하는 PHYS 급정지 측정, 방식 `sudden`, 관찰 참 |
| 4 | 6과12-02 | 천천히 자전이 느려지면 태양일은? | 완만한 원호 스위치를 고르고 주기 다이얼을 늘려 표시를 연다 | 시간 점·그래프 | 태양 통과 사이 점이 늘어나 전체 고리가 길어진다 | `judgeQ4({P,mode,daySeen})`: `gradual`, 유한 P가 30~365일, 열람 참, 태양일이 30일 상태 이상 |
| 5 | 6과12-02 | 자전이 없어지면 낮밤 전체 주기는? | 완만한 방식에서 맨 끝 정지 걸림을 고른다 | 공전 원호·전체 고리 | 지구본 자전 없이도 태양 방향이 돌아온다 | `judgeQ5({P,mode})`: `gradual`, P=Infinity, `solarDay(P)=C.Y` |
| 6 | 4과01-01 심화·6과12-02 | 급정지 상대 속도를 시속 약 100 km 이내로 줄이는 위치는? | 현재 주기 기준으로 핀을 극 부근까지 옮긴다 | 한계 윤곽·겹치기 | 속도 화살표가 한계 윤곽 안에 들어간다 | `judgeQ6({phi})`: 유효 위도이고 `v(phi,T0)≤27.78 m/s`; 포함 경계에 기계 반올림만 허용 |

Q1·Q2·Q6는 현재 주기 기준을 고정해 질문이 달라지지 않게 한다. Q3도 명세대로 현재 자전에서 출발한다. 자유 실험의 느린 P를 급정지 측정으로 몰래 쓰지 않는다. Q4·Q5 진입 시에만 느린 자전 탐구 상태를 세운다.

## 예상 그림 후보

후보는 기하 모형의 작은 루프다. 아래 글 설명은 제작 지시이며 화면에는 그 도해만 넣는다. 각 줄에 오개념을 포함한다.

| Q | 후보 A | 후보 B | 후보 C | 정답 | 오개념 |
|---|---|---|---|---|---|
| 1 | 점으로 끝나는 속도 | 자전거 윤곽 길이의 화살표 | 여객기 윤곽을 넘는 화살표 | C | A: 정지해 있다고 생각함 |
| 2 | 적도와 같은 화살표 | 높은 위도의 짧은 화살표 | 높은 위도의 더 긴 화살표 | B | A: 각속도와 선속도 혼동 |
| 3 | 구슬과 지표 모두 정지 | 동쪽 접선에 이어지는 점 | 서쪽 접선에 이어지는 점 | B | A: 운동이 즉시 사라짐 |
| 4 | 원래 길이의 시간 고리 | 약간 늘어난 고리 | 접힌 축을 가진 긴 시간 고리 | C | A: 느린 자전도 하루는 같음 |
| 5 | 현재 태양 통과 고리 | 밝은 반고리만 전체라고 둘러싼 윤곽 | 밝은 반고리와 어두운 반고리를 모두 감싼 공전 고리 | C | B: 밝은 시간과 낮밤 주기 혼동 |
| 6 | 적도 핀과 긴 화살표 | 중위도 핀과 여전히 한계를 넘는 화살표 | 극 가까운 핀과 한계 안의 화살표 | C | B: 조금만 북쪽으로 가도 충분하다고 생각함 |

Q5의 “반년”은 밝은 구간 자체로는 오답이 아니다. 질문 도해는 태양을 다시 만나는 **전체** 고리를 강조한다. 정지 시 밝은 시간 약 182.625일, 태양일 365.25일이다. 일출·일몰 비교 렌즈는 극이 아닌 적도에서 보여 준다.

## 원리 카드 — 글 없는 그림 등식

| Q | 화면에 표시할 도해 |
|---|---|
| 1 | 지구 적도 핀과 접선 화살표 → 같은 원점의 여객기 점선 윤곽을 넘는 마디 줄 |
| 2 | 적도 띠·높은 위도 띠 나란히 → 전체 화살표·반 길이 화살표 겹침 |
| 3 | 지표·구슬의 겹친 화살표 → 지표는 점, 구슬은 같은 접선 화살표 |
| 4 | 짧은 자전 원호 → 짧은 태양 통과 고리; 늘어난 자전 원호 → 긴 태양 통과 고리 |
| 5 | 고정된 자전축 원판과 공전 원호 → 밝고 어두운 반고리를 둘러싼 하나의 전체 고리 |
| 6 | 극에 가까운 핀 → 점선 한계 윤곽 안에 들어온 화살표와 포개진 끝점 |

## 퀘스트 진행과 측정 경계

장면 제시 → 예상 선택 → 장면 속 조작 → 관찰 사건 → 예상과 실제 겹침 → 원리 카드 순서로 진행한다. 틀린 예상은 감점하지 않는다. 예상 선택은 조작 잠금만 해제하며 정답 선택 자체를 완료 판정으로 쓰지 않는다. 상단 띠에는 여섯 퀘스트 선화 기호와 진행 점을 두고 완료는 채움, 현재는 밝기로 표시한다.

완료 직후의 조작 값은 유지한다. 다음 퀘스트 진입 때만 시작 조건을 세운다. 자유 실험은 언제든 열리며, Q1·Q2·Q3·Q6의 시작 주기는 현재로 복원한다. Q2의 `fromPhi`는 조작 시작 시 실제 고정한 값이다. Q6는 남북 양쪽의 절대 위도로 성공할 수 있고 북쪽만 정답으로 강요하지 않는다.

Q3 실행 때 호출자가 양의 안전 정수 `runId`를 증가시킨다. `stopMeasurement`의 결과를 먼저 저장한 뒤 연출한다. 재실행·퀘스트 재진입 때 현재 측정은 `null`, 관찰 플래그는 거짓으로 비우고 이전 기록은 이전 번호 아래 남긴다. 서로 다른 번호의 기록을 합치거나, 미관측을 속도 영으로 채우지 않는다. 극에서 실행해 실제 속도가 영인 측정과 측정 자체가 없는 상태는 다르다. 이동한 위도와 기록 위도가 다르면 Q3는 실패한다. 함수는 실행 번호의 저장소를 갖지 않는다.

열람 플래그는 해당 실행/조건에서 해당 렌즈를 실제 연 경우에만 기록한다. 조건 변경으로 렌즈 내용이 바뀌면 기존 열람 증거를 재사용하지 않는다. 이 기록 관리는 M4의 책임이고 모든 수치·임계·완료 여부는 PHYS가 결정한다.

태양일은 `solarState`를 먼저 확인한다. `empty`는 빈 격자, `synchronous`는 값 없는 끊긴 고리 사건이다. 무한대 숫자나 잘못된 영을 그래프에 넣지 않는다. UI 범위 밖의 동주기를 교사 API로 탐색해도 같은 경계 처리를 쓴다. 정지의 `Infinity`는 입력 상태 기호이며 측정값으로 표시하지 않는다.

## 손계산 검증 대표 상태

상수는 PHYS와 독립적으로 hand-check 파일에 다시 적는다. 기본 상대오차는 0.5%, 적도 요구값은 0.2%, 태양일은 0.1%, 30 m/s 안전 위도는 절대 0.05°다. 영·사건·불리언은 별도로 검증하고, 레일 기준점은 절대 1e-12로 대조한다.

| 상태 | 입력 | 결과 | 독립 손계산 |
|---|---|---|---|
| 현재 적도 | phi=0°, P=86164.1 s | 464.580650086 m/s, 1672.49034031 km/h | `2π·6371000/86164.1` 및 시속 환산 |
| 높은 위도 | phi=60°, P=T0 | 232.290325043 m/s | 적도 속도에 cos60°를 곱함 |
| 양극 | phi=±90°, P=T0 | 0 m/s | 회전축까지 거리 영 |
| 현재 태양일 | P=T0 | 1.000000052일 | `1/(86400/86164.1−1/365.25)` |
| 느린 자전 | P=2일 / 10일 / 30일 | 2.011011700 / 10.281491907 / 32.684563758일 | `1/(1/P일−1/365.25)` |
| 유한 끝 | P=365일 | 533265일 | `365·365.25/(365.25−365)` |
| 동주기 사건 | P=31557600 s | 값 `null`, 상태 `synchronous` | 상대 각속도 영: 반복 주기 없음 |
| 완전 정지 | P=Infinity | 속도 0, 태양일 365.25일 | 자전 없는 공전 한 주기 |
| 속도 한계 설계 | 27.78 m/s | 최소 절대 위도 86.571904571° | `acos(27.78/(2π·6371000/86164.1))` |

명세의 2일→2.0055일, 10일→10.25일은 주어진 식과 각각 약 0.275%, 0.307% 어긋나 태양일 허용오차를 넘는다. 구현을 그 수치에 맞추면 같은 식을 위반하므로 올바른 손계산값을 기대값으로 쓴다. 30일→32.68일은 일치한다. “거의 정지”인 365일과 “정지”는 같은 상태가 아니다.

## 구현 분할과 이번 실행 계획

이번 M1은 독립 상수 손계산·판정 경계 테스트를 먼저 작성하고, 모듈을 구현해 대조한 뒤 두 문서의 수치를 PHYS에서 재계산한다. 추가 패키지·화면 파일·커밋·푸시는 만들지 않는다.

| 단위 | 책임 | 완료 기준 |
|---|---|---|
| M1 물리·설계 (이번) | 지정된 `src/15-physics.js`, `tools/hand-check.mjs`, 이 문서와 이론 카드 | hand-check 전부 통과, 두 JS 구문 확인, 마커 로드, 문서 수치 로그 |
| M2 방·콘솔·모형 (후속) | 지구과학실·태양 램프·지구본·위도 핀·주기 다이얼 | 모든 손잡이가 RANGE/DETENTS와 매핑을 사용, 지구본 회전 각속도는 P의 역수 |
| M3 시각 문법·셰이더 (후속) | 마디·벤치마크·접선·명암 경계·그래프·렌즈 | 물리값을 장면에서 재작성하지 않음, 저사양에도 현상·그래프 유지, 필요한 과장은 PHYS에 추가하고 검증 |
| M4 퀘스트·연출 (후속) | 여섯 예상 루프·관찰 플래그·실행 번호·상태 전이 | 완료 조건은 judgeQ 함수 호출, 이전 시행 오염 없음, 사건을 연출보다 먼저 기록 |
| M5 교사 모드·안내서 (후속) | A/B 고정·표현 층·교사 발문·한계 안내·사이트 연계 | 밝은 시간/태양일 구분, 화면 단어 없음, 셸 예약 위치와 품질 모드·접근성 규칙 준수 |

레일 구간 배분, 정지 흡착, Q1의 적도 허용 구간은 조작성을 위한 설계 결정이다. 근거가 약한 물리 추정은 사용하지 않았다. 나중에 도입하는 물리 추정은 코드 주석과 문서에 모두 “추정”으로 명시한다.
