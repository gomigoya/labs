# 지구 자전이 멈추면 — 이론 카드

슬러그: `earth-stop`. 대상은 초등 고학년 중심이다. 명세 `D:/labs/topics/specs/earth-stop.md`, master-lab-prompt의 철학·이론 해부·시각 문법·퀘스트, site-addendum을 바탕으로 한다. 화면 구현은 다음 단계이며 이 문서의 화면 제안은 로우폴리 입체와 코드 선화 도해만 쓴다. 단어·삽화·캐릭터·이모지는 없다. 퀘스트 연결은 [quest-map.md](quest-map.md).

교육과정 원문은 `D:/labs/docs/curriculum/science-2022.csv`에서 인용한다.

- **6과12-02**: “지구의 자전을 알고, 낮과 밤이 생기는 이유를 설명할 수 있다.”
- **4과01-01**: “일상생활에서 힘과 관련된 현상에 흥미를 갖고, 물체를 밀거나 당길 때 나타나는 현상을 관찰할 수 있다.”

관성은 후자의 직접 성취 요구가 아니라 심화 연결이다. 가상 급정지를 실제 안전 실험이나 인체 생존 판단으로 안내하지 않는다.

## a. 한 줄 통찰

우리는 지구와 함께 빠르게 움직인다. 땅만 갑자기 멈추면 몸은 동쪽 운동을 이어 가며, 자전이 느려지면 태양을 다시 만나는 주기가 길어진다.

## b. 3단계 학습 경로

| 단계 | 발견 |
|---|---|
| 알아챔 | 적도 구슬의 속도 화살표가 여객기 기준 윤곽보다 길다. |
| 조작 | 핀을 극으로 옮기면 화살표가 짧아진다. 급정지시키면 지구본만 멈추고 구슬은 접선 운동을 잇는다. |
| 비교·설계 | 위도에 따른 속도 감소와 느린 자전에 따른 태양일 증가를 구분하고, 속도 한계 안에 드는 극 부근 위치를 찾는다. |

## c. 보이지 않는 주인공과 시각 형태

주인공은 함께 움직이던 **접선 속도와 관성**, 그리고 자전·공전의 **상대 각속도**다. 관성을 바깥으로 미는 새로운 힘으로 그리지 않는다.

- 현재 속도: 청록 실선 마디 화살표. 한 마디는 소리 기준 속도이며 `mach(v)`가 마디 수다. 여객기 등 기준은 같은 축의 점선 윤곽이다.
- 시간: 호박색 태양 조명과 회색 과거 점. 같은 물리 시간 간격의 점만 연결한다.
- 급정지: 멈춘 지표에 회색 기준점을 남기고 구슬의 동쪽 접선에 청록 흔적을 이어 그린다. 지표 기준 상대 속도는 처음의 `v(phi,T0)`다.
- 색과 함께 실선/점선·화살촉/둥근 점·명도 차로 구분한다. 사건 순간에는 접선 도해 하나만 남긴다.

## d. 영웅 장치와 방

지구과학실의 콘솔 위에 큰 지구본, 남북 핀 레일, 몸을 뜻하는 무표정 기하 구슬, 태양 램프를 둔다. 구슬은 캐릭터나 인체 삽화가 아니다. 회전 지구본에 한쪽 조명이 명암 경계를 만든다. 급정지 장면과 느린 자전 장면은 같은 장치를 쓰되 다른 물리 질문을 다룬다. 완전 정지 시에는 태양 램프 방향이 공전에 따라 한 바퀴 이동해야 한다.

## e. 지배 방정식과 API 계약

수치·판정의 유일한 원천은 `src/15-physics.js`의 `PHYS`다. 모든 시간 입력·출력은 초(SI), 속도는 m/s, 위도 `phi`만 도 단위다. `C.day=86400`, `C.R=6371000`, `C.T0=86164.1`, `C.Y=31557600`(365.25일), `C.sound=343`이다.

| 함수 | 실제 식·반환 |
|---|---|
| `v(phi,P)` | `(2πR/P) cos(phi·π/180)`; 양극은 삼각함수 잔여값 대신 정확한 영. 정지는 `P=Infinity`로 영. |
| `mach(speed)` | `speed/343`. 벤치마크와 같은 속도 축의 마디 수. |
| `solarDay(P)` | `1/abs(1/P−1/Y)`; 유한 양의 P에 적용. `P=Y`는 `null`, `P=Infinity`는 `Y`. |
| `solarState(P)` | `cycling` / `synchronous` / `stopped` / `empty`. 값이 없는 동주기를 사건으로 분리한다. |
| `phiSafe(vMax)` | `acos(clamp(vMax/v(0,T0),0,1))`의 도 단위 결과. 의미 있는 입력은 음이 아닌 속도이며 적도 속도 이상은 영도. |
| `stopMeasurement({runId,phi,mode,executed})` | 실행한 급정지만 `{runId,phi,relativeSpeed:v(phi,T0)}`. 미실행·잘못된 실행 번호·위도·방식은 `null`. |

연속 계산 `v`, `mach`, `phiSafe`는 호출 경계에서 단위·유한값·위도 범위를 보장한다. 입력 검사와 실패 판정은 측정/퀘스트 경계에 둔다. `solarDay`는 특이점·빈 상태를 직접 다룬다. 공개 상수·걸림 배열은 동결한다. 순수 함수이며 내부 시간·기록·난수·DOM이 없다.

현재 적도는 **464.580650086 m/s**, **1672.49034031 km/h**, **마하 1.354462537**. 위도 60°는 **232.290325043 m/s**, 양극은 **0 m/s**. 한계 30 m/s의 최소 절대 위도는 **86.297585348°**, 5 m/s는 **89.383348342°**다.

### 명세 수치의 대조와 용어 정정

| P | PHYS 태양일(일) | 명세와의 관계 |
|---|---|---|
| 현재 T0 (0.997269676일) | 1.000000052 | 표시상 하루. 입력을 태양일로 바꾸지 않는다. |
| 2일 | 2.011011700 | 명세의 2.0055는 식과 불일치. |
| 10일 | 10.281491907 | 명세의 10.25는 식과 불일치. |
| 30일 | 32.684563758 | 명세의 반올림 32.68과 일치. |
| 365일 | 533265 | 거의 동주기이므로 매우 길다. 완전 정지가 아니다. |
| 완전 정지 | 365.25 | 공전에 의해 태양 방향이 한 해에 한 바퀴 변한다. |

명세의 “낮의 길이”를 **태양일(낮과 밤 전체 반복 주기)**로 해석한다. 자전축 기울기를 생략한 적도에서 밝은 시간만 보면 태양일의 절반이다. 정지 시 태양일은 365.25일, 밝은 시간은 182.625일이다. 따라서 “반년”은 밝은 시간에 대해서는 올바르며, Q5의 오개념은 전체 주기와 밝은 구간의 혼동이다. 극에서는 단순한 일출·일몰 설명을 적용하지 않는다.

`P→∞`의 태양일은 `Y`로 접근한다. 무한대로 발산하는 곳은 `P→Y`다. UI의 유한 범위는 그 특이점 직전까지만 가며, 끝의 정지 걸림은 불연속 상태 전환이다. `C.P_stop=Infinity`로 두어 유한 P를 임의 포화하지 않는다. UI 밖 `P>Y`도 양의 주기이므로 절댓값을 쓴다. 태양의 이동 방향까지 필요하면 다음 단계에서 별도 물리 API를 명세화해야 한다.

## f. 조작 변수와 손잡이

| 변수 | 장면 속 조작 | 범위·걸림·물리 연결 |
|---|---|---|
| 위도 | 지구본 핀을 남북 레일에서 끈다 | `RANGE.phi=[−90,90]`도. 걸림은 −90, −60, −30, 0, 30, 60, 90도. `phiRailX`와 `phiFromRailX`. |
| 항성 자전 주기 | 콘솔의 원호 다이얼 | `RANGE.P=[86164.1,31536000]`초, 현재부터 365일까지. `periodRailX`, `periodFromRailX`. 현재·유한 끝·정지 걸림. |
| 방식 | 각진 정지 윤곽과 완만한 원호 윤곽의 스위치 | 내부 값 `sudden` / `gradual`. 문구는 화면에 넣지 않는다. |

위도 레일은 양반구 대칭의 구간별 선형이다. 절대 위도 0/60/85/90도가 중앙으로부터 x 오프셋 0/0.3/0.4/0.5에 대응한다. 북쪽 x는 0.5/0.8/0.9/1이며 남쪽은 반사한다. 주기 레일은 `x=0.9·ln(P/T0)/ln(Pmax/T0)`다. x가 0.9부터 0.95 미만이면 유한 끝에 머물고, 0.95 이상이면 정지에 흡착해 표시 손잡이는 x=1에 둔다. `Infinity`를 JSON 숫자로 저장하지 말고 정지 상태 기호로 직렬화한다.

Q1 적도 허용은 ±1도이며 레일 폭은 0.01이다. Q6 북쪽 허용 폭은 약 0.068561909, Q2는 0.2, Q4는 약 0.380987702, Q5 정지 흡착 영역은 0.05다. 모두 최소 0.009 이상이고 이웃 걸림의 최소 간격은 0.1로 최소 0.05 이상이다. Q3는 실행 사건이므로 레일 허용 폭이 없다. 남북 양쪽 모두 안전 위도 조건을 만족한다.

| 원리 | 3장 사전의 문법 | 화면에 표시 |

| 접선 속도의 크기 | 마디 | 청록 화살표에 소리 기준 마디, 끝에 부분 마디. |
| 벤치마크 비교 | 겹치기 | 같은 원점·눈금의 점선 막대와 교통수단 선화 기호. |
| 위도에 따른 감소 | 계단·겹치기 | 위도 걸림마다 남긴 점과 현재 화살표, 적도 점선 윤곽. |
| 관성 | 시간·운동 흔적 | 같은 시간 간격의 접선 점, 정지 지표 잔상. |
| 낮밤 경계 | 숨은 구조 | 지구 단면 렌즈의 밝은 반원·어두운 반원과 회전 원호. |
| 상대 각속도 | 시간 점·상쇄 | 자전 원호와 공전 원호를 겹치고 남은 원호를 태양 통과 점으로 연결. |
| 설계 속도 한계 | 문턱 | 한계 점선 윤곽과 그 안에 들어오는 청록 화살표. |
| 반복 관측 | 기록 | 실행마다 조건 기호와 결과 막대; 새 실행의 빈 행은 막대를 그리지 않는다. |

## i. 예상 그림 후보와 오개념

매 퀘스트의 후보는 같은 장치로 만든 짧은 비교 루프다. 멈춘 구슬·반대쪽 접선·같은 길이 화살표 같은 오개념을 포함한다. Q5는 밝은 구간과 전체 주기 도해를 함께 넣어 질문의 뜻을 시각적으로 고정한다. 후보표는 퀘스트 지도에 둔다.

## j. 원리 카드

원리마다 한 장의 글 없는 도해를 남긴다. 원인 쪽 핀·원호와 결과 쪽 마디·점 고리를 같은 기호로 잇는다. 수식 글자나 문장 대신 도형의 길이와 겹침을 쓴다. 상세 등식은 퀘스트 지도에 둔다.

## k. 콘솔 그래프 2개

| 그래프 | 축과 값 | 표현·경계 |
|---|---|---|
| 위도–속도 | 가로는 위도 핀/구면 호 기호, 세로는 마디 화살표. x=`phiRailX(phi)`, y=`v(phi,T0)` | 청록 대칭 곡선, 적도 기준 점선, 현재 커서. 비선형 가로축임을 걸림 위치로 드러내고 실제 속도 축은 공통 선형을 유지한다. |
| 자전 주기–태양일 | 가로는 회전 원호 기호, 세로는 태양 통과 고리. x=`periodRailX(P)`, y=`solarDay(P)` | 호박색 곡선, 큰 값은 접힌 축 윤곽과 크기 마디로 분리. 유한 곡선을 정지 점까지 직선 연결하지 않는다. `synchronous`는 끊긴 고리 사건, `empty`는 빈 격자. |

그래프와 콘솔은 실제 PHYS 반환값만 받는다. 축 압축 시 압축 기호를 두고 수치 좌표와 시각 좌표를 구분한다. 일조 점을 세려면 하루보다 촘촘한 고정 물리 간격으로 전체 주기를 샘플링하며, 밝기만으로 전체 주기를 판정하지 않는다.

## l. 현상 셰이더 설계

- 명암 경계: 지구 표면 법선과 태양 방향의 내적으로 밝은 반구와 어두운 반구를 만든다. 기울기 없는 구면을 사용한다. 좁은 발광 경계는 도해 강조이며 실제 대기 발광의 예측이 아니다.
- 속도: 반투명 청록 화살표와 방향 스트릭을 전용 ShaderMaterial로 그린다. `uUnit`은 소리 기준 마디, `uStyle`은 현재 실선/기준 점선을 구별한다. 길이는 `mach(v)`와 같은 선형 비율이며 색은 청록 정체성을 유지하고 크기는 마디 수로도 읽힌다.
- 흔적: 급정지 시작점과 동쪽 접선에 고정 시간 간격 점을 둔다. 가산 혼합과 블룸을 약하게 적용해 점·마디 코어를 남긴다. 입자 밀도나 장식 진동으로 힘이 추가된 것처럼 보이게 하지 않는다.
- 밝은 시간과 어두운 시간의 점은 채움·빈 윤곽으로 구분한다. 저사양에서도 현상 셰이더와 그래프를 유지한다.

## n. 흔한 오해 2개와 깨는 장면

- “함께 서 있으니 지구가 멈춰도 몸은 그대로다.” Q3에서 구슬·지표의 직전 화살표를 겹치고, 지표 화살표만 없어지는 순간 구슬 흔적이 이어지는 장면으로 깬다.
- “자전이 멈추면 영원히 한쪽만 낮이다.” Q5에서 자전 없는 지구 주변으로 태양 방향이 공전에 따라 돌아오는 장면으로 깬다. 반년의 밝은 구간과 한 해의 전체 주기를 별도 도형으로 비교한다.

## o. 과장 스케일 목록

- ⤢ 위도 레일은 각도 비례가 아니다. 극 부근을 넓힌 매핑은 PHYS에 있다. 지구본 핀의 실제 위도는 원래 phi로 배치한다.
- ⤢ 주기 레일은 로그 압축이고 정지는 연속 감속의 마지막 유한 점이 아니다. 두 매핑과 정지 흡착 경계는 PHYS에 있다.
- ⤢ 지구본 크기·구슬 크기·접선 흔적의 공간 크기·재생 시간은 탁상 도해의 축척이다. 벤치마크와 속도 화살표는 같은 축척을 사용한다. 긴 물리 시간을 짧게 재생해도 등시간 점의 물리 간격은 바꾸지 않는다.
- 새 과장 수치가 필요하면 M3에서 PHYS API와 hand-check를 함께 확장한다. 이 단계에서는 명세에 없는 배율·사건 시간을 추정해 코드에 넣지 않는다. 근거가 약한 물리 추정은 사용하지 않았다.

## 근사와 한계

완전 구형 지구, 자전축 기울기와 궤도 이심률 생략, 같은 방향 원궤도 공전이다. 급정지는 물리적으로 실현할 수 없는 가상 경계 조건이다. 대기·바다의 관성, 지각 변형, 마찰·충돌·인체 내구성을 계산하지 않는다. 급정지의 접선은 최초 속도를 보여 주는 국소 도해이며 장시간 탄도·탈출·지표 충돌 궤적이 아니다.

천천히 감속할 때의 감속 시간·가속도·몸에 작용하는 힘은 명세에 없어 모델링하지 않는다. 태양일은 각 P에서의 일정한 자전 상태를 비교하는 준정적 관계다. 자전축 각속도는 P에 **반비례**한다. 명세의 “P에 비례”라는 회전 표현은 주기에만 적용한다. 속도 한계는 교육용 수치 조건이며 실제 안전을 보장하지 않는다.

## p. 카메라 샷

가로 여섯 샷: 지구과학실 전경 / 지구본·태양 램프 전체 / 적도 핀·벤치마크 겹침 / 극 부근 레일 / 급정지 접선 렌즈 / 자전·공전과 태양 통과 고리.

세로 세 샷: 지구본과 아래 콘솔 / 핀과 세로 벤치마크 / 태양 방향 고리. 상단 진행 띠와 하단 도구대 사이에 현상을 두고 데스크톱 왼쪽 아래·모바일 오른쪽 위 셸 공간을 비운다. 새 렌즈가 열리면 이전 렌즈는 닫는다.

## q. 방 소품

여덟 소품: 별 지도 원판, 지구 단면 패널, 자전·공전 원호 패널, 축을 세운 작은 지구본, 태양 램프 스탠드, 돔 창 하늘, 기하 구슬 보관 트레이, 모래시계. 글 없는 입체·선화만 사용한다. 소품은 배경 깊이를 만들되 핀·접선·벤치마크를 가리지 않는다.
