# 지구 자전이 멈추면

지구본·태양 램프·위도 핀·관성 구슬로 접선 속도와 낮밤 전체 주기를 비교하는 초등 고학년 중심 실험실입니다. 화면은 선화 기호와 기하 장치만 사용하며 교사 수치 층의 숫자·단위 외 단어가 없습니다. 상태는 draft, 과학 검토는 아직 완료되지 않았습니다.

## 실행

기존 D: 캐시 환경 설정을 보존하고 다음 명령을 실행합니다.

```powershell
$env:TEMP='D:\CodexWork\Temp'
$env:TMP='D:\CodexWork\Temp'
Set-Location D:/labs/labs/earth-stop
node tools/assemble.mjs
node tools/hand-check.mjs
node tools/quest-check.mjs
node tools/teacher-check.mjs
node tools/capture.mjs --out shots/r4
Set-Location D:/labs
node D:/labs/tools/serve.mjs --root labs/earth-stop
```

assemble은 src 조각을 index.html로 묶습니다. hand-check는 전체 물리·표현용 순수 함수, quest-check는 실제 PHYS를 쓰는 여섯 퀘스트와 오답·오래된 증거·중단된 관찰, teacher-check는 범용 원본 동일성·실제 설정·모드·초기화·대기·문자 감사를 검사합니다. 이 샌드박스에서는 브라우저를 실행하지 않았습니다. 캡처는 팀장 환경의 Playwright와 WebGL이 필요합니다. `--only teacher-base,teacher-numbers,thumb`으로 상태를 고를 수 있습니다. `--lite`는 저사양 캡처입니다.

캡처에는 1440×900, 1920×1080, 1280×720 교사 띠와 375×812 모바일, teacher-*·attract-1..3·touch-pulse·thumb 상태가 있습니다. 썸네일은 __lab.capture('thumb')로 1200×750 UI 없는 히어로 JPEG를 저장하고 도구가 루트 thumb.jpg로 복사합니다. 아직 생성한 thumb.jpg는 없습니다. report.json의 오류·문자·띠 잘림과 실제 이미지의 구별·가림을 함께 확인합니다.

## 조작과 URL

상단 세 모드는 학생 퀘스트·자유 탐험·교사 시연입니다. 지구본 핀을 남북으로 끌어 위도를 바꾸고, 콘솔 다이얼로 항성 자전 주기를 조절합니다. 방식 스위치는 급정지/준정적 느린 자전을 구별합니다. 큰 정지 버튼은 현재 자전에서 출발하는 실제 급정지 측정을 만듭니다. 렌즈로 속도·벤치마크·위도 감소·상대 속도·태양일을 관찰합니다. 자유 모드의 층 순환과 비교 고정으로 더 탐험합니다. 퀘스트에서는 예상 그림을 먼저 선택합니다.

교사 띠는 재생·한 프레임·0.25배속, 실제 층 16개와 쌓기, A/B 고정·해제, 스포트라이트·레이저·수치, 여섯 퀘스트 바로가기, 학급 예상과 초기화입니다. 데스크톱은 72px 터치 셀 4열로 33개 버튼을 9행에 배치합니다. 모바일에서는 뷰포트 높이 식으로 셀을 줄입니다. 교사 손잡이와 기호는 1.4배입니다. A/B는 GRAMMAR.pin()이 소유하는 세계 좌표 스냅샷입니다.

- `/`: UI와 사이트 셸 숨김/표시. 교사 전용 Space: 재생, `.`: 한 프레임, Esc: 처음 상태.
- `?teacher=1`: 교사 진입. `?lang=en`: 접근성 사전과 guide.html 영어 본문.
- `?idle=N`: 양의 초만 대기 시간으로 사용, 기본 90초. 교사 모드와 카드 진행 중에는 대기하지 않습니다.
- `?lite=1`: 저사양. 사이트의 __SITE__.quality도 읽습니다. `?capture=1`: 자동 프레임 없이 수동 step 캡처.
- 대기 중 만지면 손 맥동 후 첫 학생 퀘스트로 초기화합니다. 오류·다섯 번 연속 1000ms 초과 프레임은 다시 시작 오버레이를 표시합니다.

## 과장과 한계

⤢ 위도 레일은 극 부근을 넓힌 구간별 선형이며 주기 레일은 로그 압축입니다. 정지 걸림은 유한 곡선의 연속 끝이 아닙니다. 지구본·구슬·접선 거리·재생 시간은 탁상 축척이며 속도와 벤치마크는 같은 축척입니다. 긴 주기의 시간 점은 고정 물리 간격을 유지하고 표시 한도 뒤 접힘을 보입니다.

완전 구형, 축 기울기·이심률 생략, 같은 방향 원궤도입니다. 급정지는 실현 불가능한 가상 조건입니다. 대기·바다·지각·마찰·충돌·인체 내구성을 계산하지 않습니다. 접선은 초기 운동의 국소 도해이며 장시간 탄도가 아닙니다. 느린 자전은 일정 주기끼리의 준정적 비교입니다. 감속 시간·가속도·힘을 예측하지 않습니다. 설계 속도 27.78 m/s는 실제 안전 기준이 아닙니다. 태양일은 전체 주기이고 기울기 없는 적도의 밝은 시간은 절반입니다. 동주기 P=Y와 완전 정지를 혼동하지 않습니다.

## 결정 기록

- 실험실별 연결은 TEACHER_CFG 하나에 모으고 그 아래 컨트롤러·대기는 달 원본과 동일하게 유지합니다. closer라는 범용 슬롯의 값은 여기서는 P 레일 위치입니다. 물리량 이름 변경이나 감속 모델 추가를 하지 않았습니다.
- 수치 층은 위도, 속도, 소리 기준 배수, 86400초 기준 태양일 배수, 설계 경계 위도입니다. m/s만 허용 단위에 추가하고 audit·검사를 함께 수정했습니다.
- 배경을 제외한 실제 층 전부를 연결하며 부모 hero·console부터 쌓습니다. 의미 층을 초기화해도 처음 장치 구조는 복원합니다. 기록 초기화는 GRAMMAR.clear()가 한 곳에서 담당합니다.
- 장치 크기는 콘솔 발까지 포함한 경계 대신 지구본·궤도의 물리 표현 경계로 맞춥니다. 목표 너비는 화면 70%이며 제한된 세로 공간에서는 가림 방지가 우선입니다. 바닥은 카메라 프레이밍으로 줄입니다.
- 가로 예상 덱은 왼쪽, 모바일 덱은 상단에 둡니다. 빈 덱은 그리지 않고 사건에는 도해 하나만 표시합니다. 급정지는 구슬 따라가기와 굵은 시간 점을 사용합니다. 실제 5초 구별·60~75% 점유·모바일 가림은 팀장 캡처로 확인해야 합니다.
- 초기 명세와 상충한 태양일·설계 경계는 theory-card와 PHYS를 따릅니다. 27.78 m/s 경계는 86.571904571°입니다. 새 물리 추정값은 추가하지 않았습니다.

## 공개 훅

src/70-loop.js가 공개하는 실제 window.__lab 이름입니다.

| 이름 | 용도 |
|---|---|
| `quest` | QUEST 상태·go/pick/skip/auto 등 |
| `state` | S 입력·재생·카메라·성능 상태 |
| `PHYS` | 물리와 순수 표현 함수 |
| `SHOTS`, `SHOTS_VERTICAL`, `PRESETS` | 가로·세로 카메라 및 대표 입력 |
| `set`, `preset` | 입력과 대표 상태 설정 |
| `shot`, `flyTo` | 즉시 샷과 보간 이동 |
| `layer` | 구조 키와 의미 층 켜기/끄기 |
| `step` | 제한된 수동 프레임 실행 |
| `quality` | high/low 전환 |
| `textAudit` | 보이는 단어·비허용 수치 검사 |
| `heroCoverage` | 장치 경계·점유·UI 겹침·잘림 |
| `perf` | 프레임·렌더 호출·품질 통계 |
| `capture` | JPEG 저장, thumb 특수 경로 |

80-teacher.js는 `teacher`, 85-attract.js는 `attract`를 추가합니다. 전역 GRAMMAR는 층·고정·초기화 연결이며 별도 __lab 키는 아닙니다.
