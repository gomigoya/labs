# 다른 별에서 내 몸무게는

같은 질량의 추를 다른 천체로 옮겨 무게·양팔 평형·같은 초속도의 점프를 비교하는 글 없는 실험실입니다. 초등 3~6학년 관찰·예상·비교 활동용이며 현재 상태는 draft, 과학 검수 전입니다.

## 실행

PowerShell에서 D: 작업·캐시 경로를 유지합니다.

```powershell
$env:TEMP='D:\CodexWork\Temp'
$env:TMP='D:\CodexWork\Temp'
Set-Location D:/labs/labs/weight-worlds
node tools/assemble.mjs
node tools/hand-check.mjs
node tools/quest-check.mjs
node tools/teacher-check.mjs
node tools/capture.mjs --out shots/r4
Set-Location D:/labs
node D:/labs/tools/serve.mjs --root labs/weight-worlds
```

캡처는 자체 서버와 Playwright를 사용하며 브라우저 호스트에서 실행합니다. 이 R4 작업에서는 브라우저를 실행하지 않았습니다. `--only teacher-strip,teacher-numbers,teacher-class-predict,q4-event,thumb`으로 일부를 고릅니다. 전체 상태에는 세로 모드, 1440×900·1920×1080·1280×720 교사 띠, 375×812 모바일, 대기·손 맥동·복구가 있습니다. 썸네일은 실험실 루트 `thumb.jpg`로 복사됩니다. 이 파일은 캡처 실행 전에는 생성되지 않습니다.

## 조작과 URL

천체 선반·회전 다이얼·이전/다음 버튼은 같은 천체 선택을 바꿉니다. 추 손잡이·+/−는 추 개수를 바꿉니다. 점프 레버는 새 실행 번호의 시험을 시작합니다. 양팔 또는 계측 상한은 확인 아이콘으로 관찰 기록을 남깁니다. 자유 실험에서는 설명 층을 개별로 켤 수 있습니다. Q1~Q7은 예상 후 조작하며 오답 예상도 계속 탐험할 수 있습니다.

상단 학생·자유·교사 아이콘으로 모드를 바꿉니다. 교사 오른쪽 띠에서 재생/한 프레임/0.25배속, 전체 층, A/B 고정·해제, 스포트라이트, 레이저, 수치, 퀘스트 바로가기, 학급 예상, 초기화를 조작합니다. Space는 재생, `.`은 한 프레임, Esc는 처음 상태, `/`는 UI와 사이트 셸 숨김입니다. 수치 층 외에는 화면에 단어·숫자 단위를 그리지 않습니다.

- `?teacher=1`: 교사 시연으로 시작합니다.
- `?idle=N`: 양의 유한한 N초를 대기 진입 시간으로 사용합니다. 기본 90초입니다. 교사 모드와 학생 카드 진행은 대기에서 제외합니다.
- `?lang=en`: 접근성 이름과 안내서 영어 본문을 선택합니다.
- `?lite=1`: 후처리와 입자를 줄입니다. 핵심 힘 셰이더와 그래프는 유지합니다. 사이트 quality 설정도 읽습니다.

대기 화면을 만지면 손 선화가 맥동하고 첫 학생 퀘스트로 돌아갑니다. 오류 또는 다섯 연속 장시간 프레임은 되돌리기 오버레이를 엽니다. 완전히 멈춘 브라우저 이벤트 루프에서는 다음 프레임이 와야 정체를 감지할 수 있습니다.

## 과장·근사·한계

실제 마디 n·gRatio는 보존하고 표시만 30으로 제한합니다. 30 초과는 끊김이며 태양·중성자별은 항상 확대 표식입니다. 실제 점프 정점도 보존하고 표시만 0.02~3 m로 제한합니다(**추정**). 공간은 g=0·정점 null이며 무하중을 양팔 평형 증거로 쓰지 않습니다.

천체 견본·기둥·스프링·선반 간격은 실제 축척이 아닙니다. 반지름 비교 윤곽은 제곱근 압축과 상하한을 사용하고 확대 표식을 둡니다. 선택 구는 읽기 쉽게 확대했습니다. 상한 끊김·받침 관통은 **추정** 도해이며 파괴 강도는 계산하지 않습니다.

구형·비자전·표면 일정 중력의 뉴턴 근사입니다. 가스 행성·태양에 서 있을 수 없고 중성자별의 상대론·생존은 다루지 않습니다. 일정 초속도 2.8 m/s는 **추정**이며 같은 힘과 다릅니다. 대기·저항·자세·높이별 중력 변화를 무시합니다. 실제 달 점프는 2.41371017623 m로 명세의 반올림 2.42 m와 구별합니다. 질량 40 kg와 태양의 표준중력 환산 1118.32481737 kg 상당값을 혼동하지 않습니다.

## 실제 공개 훅

`src/70-loop.js`의 `window.__lab` 기본 이름은 `state, PHYS, quest, SHOTS, SHOTS_VERTICAL, set, preset, shot, flyTo, layer, step, quality, textAudit, heroCoverage, perf, capture, run`입니다. 뒤 모듈에서 `teacher, attract`를 더합니다. `window.GRAMMAR`는 층·핀·기록·상태 API입니다.

| 훅 | 입력·동작 |
|---|---|
| `set(name,value)` | body, nWeights, playing, t, sound. 천체·추는 정수 범위로 제한합니다. |
| `preset(index)` | 지구 / 달 / 목성 / 태양 / 중성자별 / 금성 / 공간 순서입니다. |
| `shot`, `flyTo`, `SHOTS`, `SHOTS_VERTICAL` | 가로 여섯·세로 세 샷과 부드러운 이동입니다. |
| `layer(name,on)` | 기본 키와 한국어 문법 키입니다. 시각 문법 문서를 참고합니다. |
| `step(n,dt)`, `run()` | 같은 update 경로 진행·새 점프 시험입니다. |
| `quest`, `teacher`, `attract` | 학생 판정·교사 시연·대기 상태와 제어입니다. |
| `quality('high' 또는 'low')` | 품질 단계 전환입니다. |
| `textAudit`, `heroCoverage`, `perf` | 실제 DOM 단어·장치 화면 점유·렌더 성능 검사입니다. |
| `capture(name)` | 서버 /__save/로 JPEG 전송. thumb는 UI 없는 1200×750 히어로 샷 후 원래 카메라·품질·UI를 복원합니다. |

Node 검사는 브라우저 경계를 스텁으로 대체합니다. 실제 캡처, 투사 거리 판독, 5초 테스트, 터치 크기, 가림, 성능, 브라우저 이벤트·포커스와 썸네일 픽셀은 캡처 호스트에서 검수해야 합니다. 커밋·푸시는 하지 않습니다.
