# 검수 요약 — 다른 별에서 내 몸무게는

물리 교사·대학원생의 30분 검토용입니다. 근거는 [이론 카드](theory-card.md), [퀘스트 지도](quest-map.md), `src/15-physics.js`입니다. 아래 표는 PHYS를 `node -e`로 불러 계산했습니다. 실제 화면은 브라우저 호스트에서 별도 검수합니다.

## 식·상수·판정

구형·비자전 표면 중력 `g=GM/R²`, 지구 비 `r=g/g(0)`, 질량 `m=8n kg`, 무게 `W=mg`, 점프 정점 `h=v²/(2g)`입니다. `G=6.674e-11 m³/(kg·s²)`, `v=2.8 m/s`(일정 초속도는 **추정**), 추는 정수 `n=1~5`, 기본 `n=5`입니다. 표준 중력 `9.81 m/s²`는 kg 상당값 환산에만 사용하고 지구 비에는 쓰지 않습니다.

이 표에서 사용하는 천체 상수: 지구 `M=5.972e24 kg, R=6.371e6 m`; 달 `M=7.342e22 kg, R=1.737e6 m`; 태양 `M=1.989e30 kg, R=6.957e8 m`. 나머지는 PHYS.C.bodies와 이론 카드 e절의 같은 표를 사용합니다.

실제 마디 `a=W/weight(0,1)=n·r`, 보이는 마디 `min(a,30)`이며 `a>30`만 끊김입니다. 양팔은 같은 장소의 두 W를 비교합니다. 공간은 별도 `g=0`, 무게 0, 양팔 `unloaded`, 정점 `null`·사건 `no-apex`입니다. 무하중은 질량 평형 증거가 아닙니다. Q7은 지구 제외 `r∈[0.85,1.15]`; Q5는 서로 다른 실행 번호의 지구·달 시험을 요구합니다.

## 대표 입력 → 계산값

교사 수치 행 순서는 질량 / 중력 / 지구 비 / 무게 / 실제 마디입니다. 화면은 소수 둘째 자리로 표시하므로 아래 원값과 구별합니다. 마디의 ×는 지구 추 하나 무게를 단위로 한 무차원 값입니다.

| 천체 i, 추 n | m kg | g m/s² | r | W N | h m | 실제 → 표시 마디 |
|---|---:|---:|---:|---:|---:|---:|
| 지구 0, 5 | 40 | 9.81953203282 | 1 | 392.781281313 | 0.399204359933 | 5 → 5 |
| 달 1, 5 | 40 | 1.62405579535 | 0.165390345479 | 64.9622318140 | 2.41371017623 | 0.826951727395 → 0.826951727395 |
| 태양 7, 5 | 40 | 274.269161460 | 27.9309808800 | 10970.7664584 | 0.0142925292043 | 139.654904400 → 30 |

수치 층 그대로의 다섯 행:

| 상태 | kg | m/s² | × 지구 비 | N | × 실제 마디 |
|---|---:|---:|---:|---:|---:|
| 지구 | 40.00 | 9.82 | 1.00 | 392.78 | 5.00 |
| 달 | 40.00 | 1.62 | 0.17 | 64.96 | 0.83 |
| 태양 | 40.00 | 274.27 | 27.93 | 10970.77 | 139.65 |

손계산은 반올림 전 값을 사용합니다.

- 지구: `6.674e-11·5.972e24/(6.371e6)²=g`, `W=40g`, `h=2.8²/(2g)` → 표의 지구 행입니다.
- 달: `6.674e-11·7.342e22/(1.737e6)²=g`, `r=g/g(0)`, `W=40g`, `a=5r` → 표의 달 행입니다.
- 태양: `6.674e-11·1.989e30/(6.957e8)²=g`, `W=40g`, `a=5g/g(0)>30` → 실제 힘을 보존하고 표시만 자릅니다.

## 근사·과장과 검수 범위

표시 점프 높이는 `0.02~3 m`로 제한하는 **추정** 매핑입니다. 태양 표시 정점은 하한이지만 실제 정점은 표의 원값입니다. 천체 견본 크기·반지름 제곱근 윤곽·선반 간격·스프링 변형은 실제 축척이 아니며 확대 기호를 붙입니다. 끊김·받침 관통은 **추정** 도해로 스프링 상수·파괴 강도·생존을 계산하지 않습니다. 표면 일정 중력, 대기·저항·자세·높이별 중력 변화 무시, 가스 행성·태양의 가상 표면, 중성자별의 뉴턴 근사·상대론 미반영을 전제로 합니다. 같은 힘과 같은 초속도는 다른 조건입니다.

콘솔 그래프는 시험 전에도 모델 예측을 표시합니다. 천체 정점은 범주별 분리된 점·줄기이고 연속 곡선이 아닙니다. 실제 시행 기록은 별도 층입니다. 수치의 큰 값에서 `.toFixed(2)`는 JavaScript 반올림 표현이며 SI 원값을 바꾸지 않습니다.

## 검수 질문 다섯 가지

1. 질량 점·양팔 평형·무게 마디가 서로 다른 관찰 증거로 읽힙니까?
2. 지구 비가 표준 중력이 아니라 천체표 지구 g를 분모로 합니까?
3. 태양의 추 하나와 여러 추에서 상한 양옆이 구별되며, 같은 끊김이 같은 힘이라는 오해를 막습니까?
4. Q5의 두 실행 번호와 같은 초속도 가정이 실제 인간 점프의 예측과 구별됩니까?
5. 중성자별·공간·가상 표면·표시 제한의 한계와 실제 물리값을 구별할 수 있습니까?
