## 퀘스트 진행과 측정 경계

- 순서는 Q1~Q7, 마지막은 설계다. 각 단계는 장면 제시 → 예상 → 조작 → 관찰 → 실제와 예상 겹침 → 카드 순서다. 예상 전 장치는 잠기고, 오답 예상은 감점 없이 수정할 수 있다. 유령 안내는 손 삽화 대신 반투명 손잡이 윤곽과 움직임 선으로 만든다.
- 화면 진행은 채워진 점·빛나는 현재 점·장치 선화 아이콘으로만 나타낸다. 자유 실험은 언제든 연다. 완료 시 선택과 추 개수는 유지하고 다음 퀘스트 진입 때만 시작 상태를 세운다.
- 기본 시작은 지구와 추 다섯 개다. Q2 시작 때 `visited=[]`, Q5 시작 때 `runs=[]`로 두며 이전 세션 기록으로 자동 통과시키지 않는다. Q2는 같은 추 개수로 양팔의 두 접시를 함께 바꾼다. 단순 선반 방문은 확인 기록이 아니다.
- 점프마다 호출자가 새 양의 정수 `runId`를 발급한다. `jumpTrial`은 번호·천체·추 개수·height·event를 돌려주지만 저장하지 않는다. `judgeQ5`는 기록의 높이 숫자를 신뢰하지 않고 입력으로 다시 계산한다. 재렌더·재생·같은 번호 복제는 새로운 시험이 아니다. 같은 번호가 서로 다른 조건에 붙으면 그 번호의 기록 전부를 제외한다.
- 시험이 없으면 그래프와 노트는 빈 상태다. `jumpHeight(9)=null`, 공간 시험은 `no-apex` 사건으로 남기며 0 높이 또는 무한대 정점으로 그리지 않는다. 번호나 입력이 없으면 `jumpTrial=null`이다. Q5는 공간 사건만으로 통과하지 않는다.
- 스프링은 정확히 30마디까지 정상, 초과부터 `broken=true`다. 이 값의 전이를 먼저 기록한 뒤 연출 지연을 적용한다. ‘끊김’은 계측 포화이며 실제 스프링 파단 계산이 아니다. 받침 관통은 **추정** 연출이다.
- Q7의 허용 구간은 양 끝을 포함한다. 레일은 천체 이산 칸이라 경계 근처 연속 가상 천체를 만들지 않는다. 천체 한 칸 간격 1/9, 끝 선택 구간 폭 1/18로 손으로 고르기 충분하다. 추 칸 간격 1/4, 끝 구간 폭 1/8이다.
- 판정은 예상 정답 선택 여부나 카메라·애니메이션 종료를 조건으로 추가하지 않는다. Q4만 명세의 상한 확인 UI 플래그를 사용하며 반드시 PHYS의 초과 결과와 함께 검사한다.

## 손계산 검증 대표 상태

독립 상수에서 `g=GM/R²`, `r=g/g지구`, `W=40g`, `h=2.8²/(2g)`를 계산한다. 천체표는 이론 카드와 동일하다. 아래 값은 표시 매핑 전 원값이다.

| 상태 (추 5개, 질량 40 kg) | g m/s² | r | W N | h m | 실제 마디 |
|---|---|---|---|---|---|
| 지구 | 9.81953203282 | 1 | 392.781281313 | 0.399204359933 | 5 |
| 달 | 1.62405579535 | 0.165390345479 | 64.9622318140 | 2.41371017623 | 0.826951727395 |
| 금성 | 8.86907677814 | 0.903207683269 | 354.763071126 | 0.441985124050 | 4.51603841634 |
| 토성 | 11.1851147928 | 1.13906800807 | 447.404591713 | 0.350465781765 | 5.69534004037 |
| 목성 | 25.9173970358 | 2.63937191194 | 1036.69588143 | 0.151249756856 | 13.1968595597 |
| 태양 | 274.269161460 | 27.9309808800 | 10970.7664584 | 0.0142925292043 | 139.654904400 |
| 중성자별 | 1.29058475e12 | 1.31430372210e11 | 5.162339e13 | 3.03738286075e-12 | 6.57151861049e11 |
| 공간 | 0 | 0 | 0 | 정점 없음 | 0 |

명세의 기대값과 독립 손계산을 각각 상대 0.5%로 비교한다. 명왕성·화성도 hand-check에 포함한다. 지구 점프 0.40 m와 달 점프 2.42 m는 반올림 근사다. 명세 수치 사이에 허용오차를 넘는 모순은 발견되지 않았다. ‘가장 무거운 행성’은 제시된 표의 행성 중 표면 중력이 가장 큰 곳을 뜻하며 천체 자체 질량 순위 퀴즈가 아니다.
