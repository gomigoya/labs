# 공룡과 줄다리기 — 퀘스트 지도

[이론 카드](theory-card.md)의 식과 문법을 따른다. 완료 조건은 `PHYS.judgeQ1`~`judgeQ12`가 계산한다. 종은 SPECIES의 한국어 키, 바닥은 GROUNDS의 μ를 순수 값으로 전달한다. 학생 조작부는 한국어 DOM HUD이며 `?lang=en`에서는 영어로 안내한다.

교육과정 원문(`science-2022.csv`, UTF-8 BOM):

- **4과01-01**: “일상생활에서 힘과 관련된 현상에 흥미를 갖고, 물체를 밀거나 당길 때 나타나는 현상을 관찰할 수 있다.”
- **6과01-03**: “화석의 생성 과정을 모형으로 설명하고, 지구의 과거 생물과 환경을 추리하는 활동을 통해 화석의 가치를 인식할 수 있다.”

모든 퀘스트는 4과01-01에 직접 연결한다. 6과01-03은 화석에 근거한 과거 생물 추리와 **추정 모형의 한계**를 다루는 보조 연결이다. 근육 법칙을 실제 공룡의 측정 결과라고 평가하지 않으며 화석 생성 과정은 별도 수업이 필요하다.

## 퀘스트 진행 규칙과 측정 경계

- 예상 고르기 전에는 대상 조작을 잠그고 카드가 흔들리는 피드백을 준다. 선택 뒤 이번 손잡이 하나가 빛난다. 나머지는 은은하게 남겨 자유 탐구로 이어진다.
- 예상 → 조작 → 관찰 사건 → 예상과 실제 겹침 → 설명 선택 → 정리 카드 순서다. 예상이 틀려도 완료를 막지 않으며 별은 예상 정답 여부만 반영한다. 모델 결과와 다름을 보고 다시 생각할 수 있다.
- 이번 조건은 완료 후 유지하고, 다음 퀘스트 진입 시에만 시작 조건을 세운다. 표시·이동·해금 순서는 `src/62-curriculum.js`의 단계 표를 따른다. 단계 1은 N1→N2→Q1→Q2→Q4, 단계 2는 N3→N4→N5→Q5→Q3, 단계 3은 Q6→Q7이며, 퀘스트 번호와 판정은 유지한다. Q4는 Q2의 성공한 팀을 자갈에서 시작하며, 결과가 없으면 트리케라톱스·49명을 쓴다. Q5는 Q4의 유리 조건을 이어 받는다. Q7은 30명·자갈로 고정한다. N5는 정지마찰과 미끄러짐을 각각 0.6초 이상 관찰한다.
- UI가 당김을 실행할 때마다 증가하는 양의 정수 `run`을 부여한다. 기록은 `{run,n,species,mu,rivalN}`이며 결과는 저장된 winner 문자열을 신뢰하지 않고 PHYS.matchOutcome으로 재계산한다. 완료된 실행만 observations에 넣는다. 드래그 중 샘플·후보 미리보기는 실행 기록이 아니다.
- Q4는 서로 다른 실행에서 같은 인원·종의 두 바닥을 비교한다. 배열의 시간 순서는 무관하다. Q5는 `after.run > before.run`으로 시간 순서를 확인한다. run은 실행 식별자이며 PHYS는 전역 카운터를 소유하지 않는다. 같은 run은 재실행 증거가 될 수 없다. 퀘스트 재진입 시 관찰 배열·방문 목록을 새로 비운다.
- 데이터가 없으면 observations·visited는 빈 배열, before·after는 null이다. 미관찰 상태를 0 N의 측정으로 그리지 않는다. 판정은 false이며 `slipOnset`의 이전 힘이 없으면 null이다.
- `slipOnset`은 정확한 마찰 한계 도달이 아니라 직전 이하에서 현재 초과로 넘어갈 때만 true다. 한계 사건은 연출 쿨다운보다 먼저 기록한다. 한계 계산에 무한한 값이나 가짜 운동 궤적을 넣지 않는다. 최소 인원의 Infinity는 계산 상한 내 해 없음 사건으로 바꾼다.
- 정적 승부에서 패배가 근육 제한이면 미끄러짐을 연출하지 않는다. 마찰 제한이면 발 접촉과 미끄러짐 방향을 상징으로 보여 준다. 깃발 이동과 회색 시간 점은 **추정 연출**, 실제 가속도 검증에 쓰지 않는다.
- Q6의 compareOpen과 visited는 실제 비교 창 열기·종 선택 이벤트로 UI가 만든 순수 플래그다. 같은 종을 여러 번 선택해도 다른 종 방문으로 세지 않는다. 새 렌즈가 열리면 이전 렌즈를 닫는다.
- 다섯 칸 단계 표시와 실험 제목으로 진행을 표시한다. 도구 설명과 성취기준은 화면 밖 교사 안내서에 둔다. 모든 시각 숫자는 본 문서의 설명이며 기본 화면은 짧은 문장과 힘 막대로 읽힌다.

## 구현 분할

U3는 기존 7개 퀘스트의 `confirm → explain → card` 흐름을 추가한다. 설명 보기 3개는 순서를 섞고, 오답은 반박 장면과 hint를 보여 주며 정답을 선택할 때까지 기다린다. 별은 예상만 반영한다. 설명 문구·검증은 `63-explain.js`, 단계 진행·기록은 `65-quests.js`가 맡는다. 정리 카드와 보관함은 `cardHTML`을 공유하고, 완료한 퀘스트의 개념을 여섯 원으로 표시한다. R1부터 글자 영역 예외는 폐기하고 학생 HUD 전체에 글을 표시한다. 데이터·흐름·별·글자 경계·한국어·영어 문구·개념 지도를 검사한 뒤 기존 세 검사 도구를 모두 실행한다.

이번 단계는 M1과 두 설계 문서만 생성한다. 아래는 다음 단계의 경계다.

| 단위 | 책임 | 완료 기준 |
|---|---|---|

## U5a — N3 줄 한가운데 저울

N3(id 10, 인덱스 9, 개념 ④)은 자갈의 5 대 5에서 먼저 당기고 한 팀을 한 명 늘려 다시 당긴다. 예상 A는 한 팀 힘, B는 두 팀 합, C는 0이다. 마지막 유효 관찰이 한 명 차이이고 그 앞에 균형 관찰이 있어야 성공한다. 장력계 층은 기존 층 끝에 기본 꺼짐으로 추가하며 N3에서는 양쪽 화살표와 함께 켠다. 세 저울은 `PHYS.tensionOf` 하나의 값을 공유하고 정지 후에도 유지한다. 교사 안내: 가벼운 줄의 장력이 어디서나 같고, 장력의 크기를 양 팀 한계의 최솟값으로 정하는 것은 이 실험의 모델 가정이다. 실제 줄다리기의 동적 장력·자세 변화는 모사하지 않는다. 정리 카드의 연결 문장은 N3에만 표시한다. 표시 순서는 `[7,8,0,1,3,9,10,11,4,2,5,6]`이고 단계 2는 `[10,11,12,5,3]`이다.

### N5 / id 12 — 서서히 당기기 (개념 ⑤)
