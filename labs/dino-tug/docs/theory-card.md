# 공룡과 줄다리기 — 이론 카드

설계 기준: `D:/labs/topics/specs/dino-tug.md`, master-lab-prompt의 철학·이론 해부·시각 문법·퀘스트, site-addendum. 이번 산출물은 순수 물리와 설계까지다. 아래 장면·셰이더·교사 기능은 후속 구현 계약이며 화면 코드가 아니다. [퀘스트 지도](quest-map.md)와 같은 PHYS 값을 사용한다.

대상은 초등 3~6학년이다. 교육과정 CSV의 문장을 그대로 인용한다.

- **4과01-01**: “일상생활에서 힘과 관련된 현상에 흥미를 갖고, 물체를 밀거나 당길 때 나타나는 현상을 관찰할 수 있다.”
- **6과01-03**: “화석의 생성 과정을 모형으로 설명하고, 지구의 과거 생물과 환경을 추리하는 활동을 통해 화석의 가치를 인식할 수 있다.”

전자는 직접 연결이다. 후자는 화석 표본과 과거 생물의 추정 모형을 연결하는 보조 맥락이다. 이 실험만으로 화석 생성 과정 전체를 성취했다고 평가하지 않는다. 화면에는 단어·단위·삽화·캐릭터·이모지가 없고, 로우폴리 입체와 계측 선화만 쓴다. 문서의 종명과 수식은 화면 밖 설명이다.

## a. 한 줄 통찰

줄다리기의 당김 한계는 근육과 마찰 중 작은 값이며, 큰 동물일수록 체중에 비한 근육 힘은 작아진다.

## b. 3단계 학습 경로

| 단계 | 발견 |
|---|---|
| 알아챌 현상 | 작은 공룡에게는 아이 하나가 이기지만 큰 공룡에게는 팀이 필요하다. |
| 조작하며 발견할 규칙 | 아이를 더하면 팀 한계가 쌓인다. 같은 팀도 바닥만 바꾸면 결과가 뒤집힌다. |
| 비교로 확인할 법칙 | 근육과 마찰 윤곽의 안쪽이 당김 한계다. 질량 증가에 비해 근육 힘 증가는 느리다. |

## c. 보이지 않는 주인공과 시각 형태

주인공은 **두 종류의 한계와 그 최솟값**이다. 근육은 보라색 짧은 점선 끝, 마찰은 분홍색 긴 점선 끝으로 구별한다. 실제 한계 막대는 아이 팀의 주황 또는 공룡의 초록 실선으로 안쪽 윤곽까지 채운다. 색 외에도 점선 주기·끝 모양·명도를 다르게 한다. 한 마디는 바닥과 무관하게 아이 근육 한계 **137.34 N**이다. 실제 줄 장력과 양쪽 최대 능력 막대를 혼동하지 않도록 두 능력 막대는 줄 바깥 비교 받침에 둔다. 줄 위에는 같은 장력의 양방향 짝만 표시한다. 현재 모델은 실제 장력을 계산하지 않으므로 그 짝의 길이를 수치화하지 않는다.

## d. 영웅 장치와 방

고생물 표본실의 길쭉한 실험대 위에 줄다리기 트랙을 둔다. 왼쪽은 같은 모양의 둥근 말뚝을 쌓는 아이 대기열, 오른쪽은 캡슐·둥근 박스로 조립한 공룡 표본 모형이다. 종별로 작은 몸, 두 발, 갑옷판, 뿔, 거대 두 발, 긴 목의 입체 실루엣을 다르게 한다. 얼굴 표정이나 의인화는 없다.

바닥 카세트를 옆으로 빼서 유리·모래·자갈·아스팔트 견본을 끼운다. 접촉면 렌즈를 열면 모눈 위 단면 선화가 맞물림을 보여 준다. 거칠기 형상은 μ 자체의 미시적 계산 결과가 아닌 **추정 도해**다. 옆의 **1.3 m** 키 말뚝은 비교 눈금이다. 명세에 공룡 키 자료가 없으므로 질량만으로 실제 키·몸길이를 만들어 내지 않는다. 공룡 모형의 크기와 비율은 **추정 전시 모형**으로 취급한다.

## e. 지배 방정식

모든 계산은 `src/15-physics.js`의 PHYS에서 한다. SI 단위는 kg·m·s·N, μ는 무차원이다. 상수는 C 하나에 모으고, 종 질량과 바닥 견본은 SPECIES·GROUNDS에 둔다.

| 관계 | 실제 구현 식과 상수 | 의미 |
|---|---|---|
| 근육 | `k = 0.5×70×9.81 / 70^(2/3) = 20.2149043956 N/kg^(2/3)`; `muscle(m)=k×m^(2/3)` | 사람 기준의 **추정**. 단면적과 질량의 기하학적 스케일 법칙 |
| 아이 근육 | `C.kidMuscle=0.4×35×9.81=137.34 N` | 어린이 계수는 별도의 **추정** |
| 마찰 | `friction(m,mu)=mu×m×9.81` | 수평의 질량 없는 줄, 미끄러지기 직전의 정지 마찰 상한 |
| 팀·공룡 한계 | `kidCap(n,mu)=n×min(137.34,mu×35×9.81)`; `dinoCap(s,mu)=min(muscle(SPECIES[s]),friction(SPECIES[s],mu))` | 아이들의 힘은 정확히 합산된다는 **추정** |
| 비교·비율 | `net=kids-dino`; `abs(net)≤1 N`이면 비김, 그 밖에는 큰 한계가 승리. `weightRatio(s)=muscle(m)/(m×9.81)` | net은 능력 차이이며 실제 운동의 알짜힘이 아니다. 체중 대비 근육 힘은 `m^(-1/3)`에 비례 |

`minKidsToWin`은 명세대로 `floor(dinoCap/kidCap(1,mu))+1`이며 상한을 넘으면 Infinity다. 엄격한 `>` 정의라서 임의의 연속 μ에서는 최소 인원에서도 1 N 비김 띠 안일 수 있다. 그래서 Q2는 인원과 승부를 둘 다 확인한다. 실제 견본의 Q2·Q3 임계 인원에서는 이 충돌이 없다. Infinity는 발산하는 그래프 값이 아니라 상한 내 해 없음 사건으로 취급한다.

`outcome`은 `{kids,dino,net,winner,limiter}`다. limiter는 패한 쪽의 한계다. 비김에는 패자가 없으므로 더 작은 능력 쪽을 진단하고 정확히 같은 능력이면 아이 쪽을 택한다. 마찰·근육 한계가 같으면 마찰을 택한다. 비김에서는 패배·미끄러짐 연출을 하지 않는다.

명세 수치 보정: Q1의 **122.95 N**은 근육 한계다. 자갈에서는 `0.55×15×9.81=80.9325 N`이 더 작으므로 실제 공룡 한계는 **80.9325 N**, 아이와의 차이는 **56.4075 N**이다. 아이 승리라는 정답은 같다. 딜로포사우루스의 공식값 **1097.433852 N**과 명세의 1097.6 N 차이는 허용오차 안의 반올림 차이다.

## f. 조작 변수와 손잡이

| 변수 | 장면 속 행동 | 범위·걸림 |
|---|---|---|
| 공룡 | 하단 도구대 입체 견본 선택 | 벨로키랍토르 15 / 딜로포사우루스 400 / 스테고사우루스 3000 / 트리케라톱스 6000 / 티라노사우루스 8000 / 아르젠티노사우루스 70000 kg |
| 아이 수 | 대기열의 손잡이를 끌어 말뚝을 트랙으로 보낸다 | 정수 1~100명. `RANGE.kids`; `DETENTS`는 1·10·20·30·49·59·68·100명 |
| 바닥 | 재질 견본을 카세트에 넣는다 | 유리/빙판 0.05, 모래 0.35, 자갈 0.55, 아스팔트 0.8 |

레일은 좁은 물리 범위에 로그를 억지로 넣지 않고 선형 정수 칸을 쓴다. `railX(n)=(n-0.5)/100`은 칸 중심, `kidsFromRailX(x)=clamp(1+floor(100x),1,100)`이다. floor 직전에는 `C.railRoundoffUlps=8`을 사용해 `8×Number.EPSILON×max(1,abs(100x))`만큼 부동소수점 반올림을 보정한다. 양끝 칸까지 **폭 0.01**, 요구 최소 **0.009** 이상이며 이웃 걸림 칸 최소 간격 **0.09**, 요구 최소 **0.05** 이상이다. 끝점 중심은 **0.005·0.995**다. 칸 경계는 오른쪽 칸에 속하고 끝은 마지막 칸에 속한다. 바닥·종은 견본 선택이므로 연속 레일을 만들지 않는다. 걸림 값은 명세에 별도 지정이 없어 학습 임계값과 대표 인원에서 골랐다.

카드는 선화와 평면색의 그림 등식만 쓴다. 작은 윤곽 선택, 같은 조각 합산, 바닥 전후 반전, 비율 비교를 기존 장면 문법으로 반복한다. 카드 문장이나 숫자 읽기를 요구하지 않는다. 퀘스트별 도해 계약은 지도에 둔다.

## k. 콘솔 그래프 2개

1. **팀의 한계 대 아이 수**: 가로축 끝은 말뚝 더미 선화, 세로축 끝은 마디 화살표. 현재 바닥의 `kidCap`은 계단으로, 선택 공룡의 `dinoCap`은 초록 점선 수평 윤곽으로 나타낸다. 현재 인원 커서를 두고 바닥을 바꿀 때 이전 계단을 점선으로 남긴다. 표시 길이에는 PHYS.forceVisual을 함께 적용한다.
2. **체중 대비 근육 힘 대 질량**: 가로축은 작은 표본과 큰 표본의 선화 양끝, 세로축은 동일 체중 윤곽과 그 안의 근육 막대 선화다. 종별 `weightRatio` 점을 놓고 질량 가로축은 로그 배치한다. 가로축은 별도 조작 레일이 아니다. 두 끝 종을 선택하면 같은 높이 기준의 막대가 나란히 고정된다. 무차원 비율에 절대 힘 압축 함수를 사용하지 않는다.

## l. 현상 셰이더 설계

힘 비교 막대는 반투명 발광 ShaderMaterial이다. uUnit은 한 마디, uStyle은 실선 또는 두 종류의 점선이다. 색은 팀·공룡·근육·마찰의 정체성을 유지하고 값은 길이와 채움, 밝기로 나타낸다. 가산 입자 스트릭은 각 막대의 방향을 따라 흐르되 방향과 밀도는 표시 힘에 종속시킨다. 물질이나 힘이 줄을 타고 흘러간다는 설명으로 쓰지 않는다. PHYS.forceVisual의 length와 compressed를 그대로 받는다.

접촉면은 발광 접촉점과 반투명 단면을 쓴다. `slipOnset(previousForce,force,mass,mu)`가 마찰 한계를 **넘을 때** 사건을 기록한다. 이전 값이 null이면 빈 상태다. 근육 제한 패배에서는 접촉 미끄러짐 입자를 켜지 않고 근육 윤곽에 닿는 채움만 보인다. 이번 모듈은 시간별 장력 데이터를 제공하지 않으므로 장면이 가짜 측정값을 만들어 slipOnset에 넣지 않는다. 정적 결과에서는 outcome의 패자·limiter를 근거로 마찰 제한 패배 사건만 표시한다.

## o. 과장 스케일 목록과 근사·한계

- **추정, ⤢ 힘 압축**: b=`force/137.34`, b≤10이면 길이 b, 그 밖에는 `10+5×ln(1+(b-10)/5)`. 20마디의 표시 길이는 **15.4930614433**이다. 압축 시작부터 끊김과 ⤢를 붙인다. 눈금은 물리 마디를 이 함수로 변환한 위치에 둔다. 압축된 구간의 화면 길이를 같은 물리 마디로 세지 않는다.
- **추정, ⤢ 모형·접촉 확대**: 공룡 모형 크기와 단면 거칠기는 실제 생체 치수·미시적 표면이 아니다. 정량 길이 비교에는 사용하지 않는다. 실제 비율을 계산하는 새 함수를 만들 자료가 없으므로 수치 배율도 발명하지 않는다.
- **추정, ⤢ 깃발 이동·먼지**: 승리 방향·마찰 제한 사건의 상징 연출이다. 시간 점을 속도·가속도 측정으로 사용하지 않는다. 한계 차이를 질량으로 나눠 실제 가속도를 만들지 않는다.
- 근육 계수와 아이 계수는 **추정**, 공룡 실제 근력의 복원이 아니다. 아이들은 같은 각도로 정확히 힘을 합친다. 공룡의 발톱·자세·기울기·동마찰, 줄 질량·탄성·지형 변형을 무시한다. 바닥 μ는 대표값이다.
- 아르젠티노사우루스는 체중 대비 근육 힘 **0.05**, 유리에서도 μ=**0.05**라 근육·마찰 한계가 **34335 N**으로 같다. 부동소수점 계산에서 근육이 미세하게 작아질 수 있다. 이것은 실제 생물의 특별한 경계가 아니라 모델 계수의 우연이다.
