# 공룡과 줄다리기 v2 — 개편 설계안 (초안, 사용자 검토용)

확정된 방향 (2026-10-24): **개념 사다리 3단계 · 보는 물체 고르기 · 글 있는 2단 설명 · 개념 지도**.
이 문서는 구현 전 설계다. 화면 문구는 모두 초안이며, 사용자 검수 후 확정한다.

## 1. 설계 원칙

1. 나라·학년별로 따로 만들지 않는다. **개념 순서로 3단계**를 만들고, 나라와 학년은 단계에 붙은 표지(성취기준 코드)로 둔다.
2. 한 번에 한 변수만 바꾼다 (NGSS 3-PS2-1, MS-PS2-2의 공통 조건).
3. 예상 → 조작 → 관찰 → **설명(2단 선택)** → 정리 카드. 예상이 틀려도 감점하지 않는다.
4. 설명 보기의 오답은 연구에서 확인된 실제 오개념으로 만든다. 오답을 고르면 "틀렸어요"로 끝내지 않고 그 오개념을 반박하는 장면을 다시 보여 준다.
5. 글 허용 범위: 미션 한 줄(기존), 개념 칩·정리 카드, 설명 질문·보기·피드백, 단계 이름. **조작 버튼 라벨 등 그 밖의 글은 계속 0**이다.
6. 정지 장면에도 힘 화살표를 계속 보여 준다. 평형은 "힘이 없음"이 아니라 "힘이 서로 상쇄됨"이다.

## 2. 단계와 성취기준 표지

| 단계 | 수준 | 한국 | 미국 |
|---|---|---|---|
| 1 | 정성. 숫자 없음 | 4과01-01 (3~4학년군, 밀기·당기기 현상 관찰). 평형 개념은 이 기준을 넘는 확장이다 | 3-PS2-1 |
| 2 | 화살표, 한 직선 위 힘의 합, 수치(N) | 중1 [9과05-01] 힘의 평형 조건(나란한 힘의 합력만), 마찰력 | MS-PS2-2 |
| 3 | 한계, 몸무게, 작용·반작용 연결 | 중1 알짜힘 단원 (정확한 코드는 고시 원문 확인 필요) | MS-PS2-1 |

- 학생: 단계 1에서 시작해, 해당 단계 퀘스트를 마치면 다음 단계가 열린다. 교사: 교사 모드에서 단계를 직접 고른다.
- 수치(N) 표시는 단계 2부터 켠다 (기존 교사 모드의 숫자 토글 재사용).
- 용어는 `?lang`으로 전환: 한국 평형·합력·알짜힘·장력, 미국 balanced/unbalanced·net force·tension.
- 성취기준 코드는 교사 안내서의 표로만 둔다. 학생 화면에는 나오지 않는다.

## 3. 개념 6개 (개념 지도)

| # | 개념 (학생용 한 문장, 초안) | 막으려는 오개념 |
|---|---|---|
| ① | 힘에는 크기와 방향이 있어요 | 힘은 있다/없다 둘 중 하나다 |
| ② | 크기가 같고 방향이 반대인 힘은 서로 상쇄돼요(평형) | 안 움직이면 힘이 없다 |
| ③ | 힘이 같지 않으면 더 큰 쪽으로 움직임이 바뀌어요 | 세게 당긴 한쪽이 무조건 이긴다 / 조금 늘려서는 안 바뀐다 |
| ④ | 줄 하나의 장력은 어디서나 같아요 | 장력은 양쪽의 합이다 / 이기는 쪽 줄이 더 팽팽하다 |
| ⑤ | 마찰은 필요한 만큼만 생기고, 한계가 있어요 | 마찰은 항상 최대다 / 마찰은 움직일 때만 생긴다 |
| ⑥ | 당기는 능력은 근육과 마찰 중 작은 쪽이에요 | 큰 동물이 무조건 힘이 세다 |

## 5. 퀘스트 카드 (질문, 설명 보기 초안)

보기 중 ◎가 정답, ✕는 노린 오개념이다. 보기 순서는 실행 때마다 섞는다. 정답이 가장 길거나 가장 구체적이지 않게 다듬는다.

### N1 맞잡기 (개념 ①②)
- 장면: 아이 5명 대 아이 5명, 자갈. 깃발은 가운데.
- 질문: "두 팀이 똑같이 당기면 어떻게 될까요?"
- 예상 그림: 왼쪽 깃발 / 가운데 멈춤 / 오른쪽 깃발 (정답: 가운데)
- 관찰: 깃발이 멈춘다. 양 팀의 같은 길이·반대 방향 화살표가 **계속 보인다**.
- 설명: ✕ "힘이 없어서 안 움직여요" / ◎ "두 힘이 같고 방향이 반대라서 서로 상쇄돼요" / ✕ "줄이 너무 팽팽해서 못 움직여요"
- 정리 카드: "크기가 같고 방향이 반대인 두 힘은 평형을 이뤄서 물체가 움직이지 않아요."

### N2 한 명 더 (개념 ③)
- 장면: N1의 5 대 5에서 **한 팀에만** 한 명 추가 (인원 손잡이는 팀별).
- 질문: "한 팀에 한 명만 더 오면 어떻게 될까요?"
- 정답: 많은 쪽으로 깃발이 이동.
- 설명: ◎ "힘이 한쪽만 더 커져서 평형이 깨져요" / ✕ "한 명 정도로는 아무 변화가 없어요" / ✕ "무거운 쪽이 항상 이겨요"
- 정리: "힘이 같지 않으면(불균형) 더 큰 쪽으로 움직임이 바뀌어요."

### Q1 작은 공룡 (개념 ⑥ 맛보기)
- 질문: "작은 공룡이면 아이 혼자서도 이길 수 있을까요?"
- 설명: ✕ "공룡이니까 무조건 힘이 세요" / ◎ "작은 공룡은 가벼워서 땅을 붙잡는 힘(마찰)이 작아요" / ✕ "아이가 더 어려서 봐줘요"
- 정리: "가벼운 공룡은 땅을 붙잡는 힘이 작아서 아이 한 명에게도 질 수 있어요."

### Q2 트리케라톱스 (개념 ③)
- 질문: "트리케라톱스를 이기려면 아이가 몇 명 필요할까요?"
- 설명: ◎ "아이들 힘을 모은 합이 공룡의 힘을 넘을 때 이겨요" / ✕ "아이가 몇 명이든 공룡이 이겨요" / ✕ "아이가 많으면 서로 방해해서 힘이 줄어요"
- 정리: "힘은 더해져요. 합이 상대보다 크면 그쪽으로 움직여요."

### Q4 바닥 바꾸기 (개념 ⑤)
- 질문: "같은 팀인데 바닥만 유리로 바꾸면 누가 이길까요?"
- 설명: ✕ "미끄러운 바닥은 아이 팀 힘만 줄여요" / ◎ "바닥이 미끄러우면 발이 땅을 붙잡는 힘(마찰)이 줄어서, 가벼운 쪽이 먼저 미끄러져요" / ✕ "공룡은 발이 커서 안 미끄러워요"
- 정리: "마찰은 땅이 발을 붙잡는 힘이에요. 바닥이 미끄러우면 마찰이 줄어요."

### N3 줄 한가운데 저울 (개념 ④) — 단계 2
- 장면: 아이 5 대 5, 줄 가운데 장력계. 이어서 6 대 5로 한 번 더.
- 질문: "줄 가운데 저울은 몇을 가리킬까요?"
- 예상 그림: 한 팀 힘만큼 / 두 팀 힘의 합 / 0 (정답: 한 팀 힘만큼)
- 관찰: 눈금이 각 팀의 화살표와 같은 값. 양 끝에 장력계를 하나씩 두면 같은 값을 가리킨다. 6 대 5에서도 양쪽 값이 같다.
- 설명: ✕ "저울은 양쪽 힘을 더해서 보여 줘요" / ◎ "줄은 하나라서 양쪽 끝에 걸리는 힘(장력)이 같아요" / ✕ "이기는 팀 쪽 줄이 더 팽팽해요"
- 정리: "팽팽한 줄의 장력은 어디서나 같아요. 이기는 쪽과 지는 쪽의 줄 힘도 같아요."
- 다음 연결 문장: "그런데 왜 한 팀만 끌려갈까요?" (N4로)

### N4 팀을 따로 보기 (개념 ③④) — 단계 2
- 장면: 6 대 5. **보는 물체 고르기**: 줄 / A팀 / B팀. 고른 물체에 걸린 화살표만 켜진다.
- 질문: "줄의 힘은 같은데 왜 한 팀만 끌려갈까요?"
- 관찰: 줄을 고르면 두 장력이 같아 합이 0. 진 팀을 고르면 줄이 당기는 힘이 땅의 마찰보다 커서 합이 0이 아니다.
- 설명: ✕ "줄의 힘이 한쪽이 더 커서요" / ◎ "끌려가는 팀은 줄이 당기는 힘이 땅이 붙잡는 힘(마찰)보다 커서 힘의 합이 0이 아니에요" / ✕ "이기는 쪽 줄이 더 힘을 줘요"
- 정리: "한 물체의 힘의 합이 0이면 평형이에요. 무엇을 보느냐에 따라 힘의 합이 달라져요."

### N5 서서히 당기기 (개념 ⑤) — 단계 2
- 장면: 아이 팀 하나, 유리 바닥. **당기는 힘 슬라이더**를 천천히 올린다. 마찰 화살표가 같이 길어지다가 한계에서 미끄러진다.
- 질문: "마찰은 처음부터 가장 크게 버틸까요?"
- 설명: ✕ "마찰은 처음부터 항상 최대예요" / ◎ "마찰은 당기는 힘에 맞춰 커지다가 한계에서 미끄러져요" / ✕ "마찰은 움직일 때만 생겨요"
- 정리: "마찰은 필요한 만큼만 생겨요. 한계를 넘으면 미끄러져요."

### Q5 유리 위 인원 (개념 ⑤)
- 설명: ◎ "인원이 늘면 마찰의 한계도 같이 커져요" / ✕ "바닥이 같으면 한계는 인원과 상관없어요" / ✕ "유리에서는 인원이 늘수록 더 미끄러워요"
- 정리: "마찰의 한계는 발이 땅을 누르는 힘에 따라 커져요."

### Q3 티라노 (개념 ③, 수치)
- 설명: ◎ "아이들 힘의 합이 티라노의 한계를 넘는 인원(약 59명)이 필요해요" / ✕ "티라노는 아무리 많아도 못 이겨요" / ✕ "아이 10명이면 충분해요"
- 정리: "힘의 합을 비교하면 이길 수 있는 사람 수를 알 수 있어요."

### Q6 큰 종의 비율 (개념 ⑥) — 단계 3
- 설명: ✕ "클수록 몸무게에 비해서도 힘이 더 세요" / ◎ "몸이 클수록 몸무게에 비해 근육 힘은 작아져요" / ✕ "크기와 상관없이 똑같아요"
- 정리: "큰 동물일수록 몸무게에 비해 근육 힘은 작아요. (이 실험의 값은 추정이에요.)"

### Q7 가장 무거운 종 (개념 ⑥) — 단계 3
- 설명: ✕ "가장 무거운 종도 아이 30명이면 이겨요" / ◎ "30명의 힘의 합 안에 드는 종까지만 이길 수 있어요" / ✕ "이기고 지는 건 종 이름에 달렸어요"
- 정리: "이기는 쪽은 한계의 합이 큰 쪽이에요."

## 6. 새로 만드는 구성요소

| 요소 | 내용 | 막는 오개념 |
|---|---|---|
| 상대 팀 = 아이 팀 | PHYS에 상대 종류 `kids`(N명) 추가. 같은 인원이면 **정확히 비김** | 정수 인원으로는 공룡과 정확한 비김이 안 나오는 문제 |
| 장력계 | 줄 가운데와 양 끝에 놓이는 눈금. 값 = 약한 쪽 한계 (모델 가정) | ① 합 오개념, ② 이기는 쪽 줄이 더 팽팽 |
| 보는 물체 렌즈 | 줄 / A팀 / B팀 선택. 해당 물체의 힘만 표시 | 평형과 작용·반작용 혼동 |
| 서서히 당기기 | 당기는 힘 슬라이더. 마찰이 필요한 만큼만 커지다 한계에서 미끄러짐 | 마찰은 항상 최대 |
| 설명 단계 UI | 질문 + 3지선다 + 피드백(오답이면 반박 장면 재생) | 개념 정립 |
| 개념 지도 | 개념 6개 별. 퀘스트 시작 시 "이번 개념", 끝에 정리 카드 | 무엇을 배우는지 불명확 |
| 단계 선택 | 학생 자동 해금 + 교사 선택 + 성취기준 표 | 학년·국가 대응 |
| 진단·기록 | 사전·사후 2단 문항(개념 6개), 예측·이유 정답률 로그 | 효과 검증 |

## 7. 모델과 물리 한계 (교사 안내에 명시)

- 줄은 가벼운 줄을 가정한다. 실제 줄다리기 측정에서는 한쪽이 우세해지면 장력이 줄어든다(DeStefano 외 2020).
- 근육 한계는 "그 팀이 낼 수 있는 최대 당김"이다. 실제 근육은 버틸 수 있는 힘이 당길 수 있는 힘보다 크지만, 모델은 같다고 가정한다.
- 사람의 균형·무게중심·몸 기울이기는 반영하지 않는다.
- 일정 속도 운동도 평형일 수 있다는 내용은 이번 범위에서 제외한다.
- 공룡 질량과 근육 계수는 기존대로 **추정**이다.

## 8. 구현 순서 (각 단위가 끝나면 검증 가능한 상태)

| 단위 | 내용 | 검증 |
|---|---|---|
| U1 | PHYS 확장(상대 아이 팀, 장력 값), 순수 함수 테스트 | hand-check: 5 대 5 정확한 비김, 장력 = 약한 쪽 한계 |
| U2 | 개념·단계·퀘스트 데이터 표(한 곳) + 퀘스트 순서 분리 | quest-check: 12개 퀘스트가 단계·순서에 맞게 해금 |
| U3 | 설명 단계 UI + 정리 카드 + 개념 지도, 글자 감사 예외 확장 | 브라우저 캡처: 겹침 없음, 글자 예외 범위 한정 |
| U4 | N1·N2 (평형, 불균형) | 브라우저: 정지 장면에도 화살표 표시 |

## 9. 사용자 검토가 필요한 것

1. 설명 보기와 정리 카드 문구 전체 (초안). 한국어 연령 수준, 영어판은 별도 번역.
2. 퀘스트 12개와 순서, 단계 경계(특히 N4가 단계 2인지).
3. 단계 3의 중1 알짜힘 성취기준 코드는 고시 원문으로 확인해야 한다.
4. 진단 문항(U8)은 현장 교사 또는 연구자의 검수를 권한다.
