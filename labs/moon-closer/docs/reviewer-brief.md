# 검수 요약 — 달이 가까워지면

물리 교사·대학원생용 30분 검토 자료입니다. 근거는 [이론 카드 e절](theory-card.md)·[퀘스트 지도](quest-map.md)와 `src/15-physics.js`입니다. 아래 값은 `node -e`로 PHYS를 직접 불러 대조했습니다. 표는 물리 함수의 계산값이며 실제 수치 층 표시의 동작 검수는 별도입니다.

## 식과 실제 상수

d=d₀−closer(중심 사이 거리), d₀=3.844×10⁸m, R=6.371×10⁶m, m/M=0.012294, Gm=4.9028×10¹²m³/s², r달=1,737km, T₀=27.3217일, 항성일=86164.1s, ρ지=5514·ρ달=3344kg/m³, g=9.81m/s²입니다. 이론 카드 질량비 0.01230은 설계 근삿값으로 구현 상수와 구별하며, 27.32일은 구현 주기의 반올림입니다.

| 현상 | PHYS와 같은 식 |
|---|---|
| 평형조석 | H=(m/M)R⁴/d³, r=H/H₀=(d₀/d)³, ζ(θ)=H(3cos²θ−1)/2; 달 쪽·반대쪽 +H, 사이 −H/2 |
| 차등 가속도 | aₜ=2(Gm)R/d³; `personTidalForce(massKg)=massKg·aₜ`는 지구 규모 차등력이며 사람 몸 길이를 넣은 식이 아님 |
| 공전·시직경 | T=T₀(d/d₀)^(3/2), α=2r달/d (rad), 도 단위는 180/π 곱함 |
| 항구 시간 변화 | Ωrel=2π/항성일−2π/T, θ=lon0+Ωrel·t, 수위=ζ(θ), 조석 주기=π/abs(Ωrel) |
| 로슈 구간(추정) | dR=kR(ρ지/ρ달)^(1/3); k=2.456(유체), 1.26(강체) → 18,486 / 9,484km |

10cm 접근은 ΔH=H₀·expm1(−3log1p(−closer/d₀))≈2.783×10⁻¹⁰m입니다. 약 0.28nm 물 분자 지름과의 크기 비교이며 연속 유체식이 분자 하나의 실제 이동을 예측한다는 뜻은 아닙니다.

## 대표 상태: 입력 → 계산값

| 상태 | closer 입력(m) | d(km) | r | H(m) | T | α(°) |
|---|---:|---:|---:|---:|---:|---:|
| 현재 | 0 | 384,400 | 1 | 0.3566 | 27.32일 | 0.52 |
| 1/2 거리 | 192,200,000 | 192,200 | 8 | 2.85 | 9.66일 | 1.04 |
| 1/20 거리 | 365,180,000 | 19,220 | 8,000 | 2,853(추정) | 7.3시간 | 10.4 |

손계산: 현재는 `0.012294·(6.371×10⁶)⁴/(3.844×10⁸)³ → 0.3566m`; 1/2은 `r=2³=8, H=8H₀ → 2.85m, T=T₀/(2^(3/2)) → 9.66일, α=2α₀ → 1.04°`; 1/20은 `r=20³=8,000, H=8,000H₀ → 2,853m, T=T₀/(20^(3/2)) → 7.3시간, α=20α₀ → 10.4°`입니다. 곱셈에는 반올림 전 원값을 사용합니다.

## 근사와 과장

- 평형조석(대륙·수심 무시). 실제 해안 조수는 지형 때문에 훨씬 클 수 있다.
- 달은 순간적으로 다른 거리의 원궤도에 놓였다고 본다(안정화·궤도 진화 무시).
- 태양 조석, 지구 몸체 조석, 달의 조석 가속(지구 자전 감속)은 무시한다.
- 로슈 한계는 구간(추정)으로 그린다. 1/20 거리(19,220 km)는 액체 한계보다 바깥이라 달이 버틴다고 본다.
- 거리가 1/10 아래에서는 평형조석 식이 해양 깊이(평균 3.7km)를 넘어 정확하지 않다. 그 구간은 "추정" 표식(점선 해안선)으로 표시한다.

설계 과장: 거리 로그 압축, 지구 지름 마디 현재 30.2·1/20에서 1.5·레일 끝 0.6. 해수면은 설계상 K≈7×10⁵로 현재 0.36m를 지구 반지름의 약 4%로 확대합니다. 껍질 두께·대기는 실제 비율이 아니며 달/지구 크기 0.27은 실제 비율입니다. 레일 끝은 중심 거리 8,000km입니다.

구현 차이: `oceanBulge(r)`는 r≤3에서 0.04r, 그 위에서 0.12+0.30(1−exp(−(r−3)/60))로 포화하므로 큰 부풂은 고정 K와 다릅니다. “1/10 아래에서 수심을 넘는다”는 위 원문은 구간 전체에 성립하지 않습니다(1/20의 2,853m도 평균 3.7km 미만). 추정 표시의 보수적 범위로 읽고 실제 해안 수위·정확한 붕괴 거리를 단정하지 마십시오. 하루 두 번도 상대 회전 한 바퀴의 두 정점이며 모든 거리의 24시간에 고정되지 않습니다.

## 검수 질문

1. 중심 가속도를 빼면 왜 반대편 차이 화살표도 바깥을 향합니까?
2. 거리 1/2에서 8배가 되는 양은 시각 껍질 길이입니까, 물리 높이입니까?
3. 1/10 아래 추정 구간에서 수심·대륙·선형 근사가 왜 문제가 되며 수심 초과 설명을 경계 전체에 적용해도 됩니까?
4. 상대 각속도를 쓰면 가까운 거리에서도 24시간에 언제나 두 정점입니까?
5. 유체·강체 로슈 값을 정확한 붕괴 시점으로 읽을 수 없고 사람의 차등력과 몸의 변형을 구별해야 하는 이유는 무엇입니까?
