# 달이 가까워지면

달–지구 탁상 궤도 모형에서 거리를 바꾸며 조석의 차이, 양쪽 부풂, 달의 겉보기 크기와 공전 주기, 로슈 한계를 비교하는 실험실입니다. 초등 3~6학년 수업의 관찰·예상·비교 활동에 사용합니다.

## 실행

PowerShell에서 작업·임시 경로를 D:로 유지합니다. 기존 D: 캐시 환경 설정은 그대로 사용합니다.

```powershell
$env:TEMP='D:\CodexWork\Temp'
$env:TMP='D:\CodexWork\Temp'
Set-Location D:/labs/labs/moon-closer
node tools/assemble.mjs
node tools/hand-check.mjs
node tools/quest-check.mjs
node tools/teacher-check.mjs
node tools/capture.mjs
Set-Location D:/labs
node D:/labs/tools/serve.mjs --root labs/moon-closer
```

서버 기본 주소는 http://localhost:5180/ 입니다. 사용 중인 포트는 서버 출력으로 확인합니다. 캡처 명령은 자체 서버를 열므로 정적 서버와 독립적으로 실행할 수 있습니다. 기본 출력은 `shots/m2`이며 M5 검수에는 `--out shots/m5`를 사용합니다. 브라우저 캡처는 팀장 실행 대상이며, 구조·물리·상태 검사는 Node에서 실행합니다.

| 명령 | 역할 |
|---|---|
| `node tools/assemble.mjs` | `src/` 조각을 `index.html`로 조립 |
| `node tools/hand-check.mjs` | 대표 상태·레일·판정·시각 포화 함수를 독립 손계산과 비교 |
| `node tools/capture.mjs` | 가로·세로 대표 상태와 오류 검사 증거 생성 |

## 과장 스케일 — 설계 원문

- 지구–달 거리: 로그 압축. 화면 속 거리는 비례가 아니다. 대신 레일에 **지구 지름 마디**(현재 30.2마디, 1/20 거리 1.5마디, 레일 끝 0.6마디)를 달아 실제 비율을 셀 수 있게 한다.
- 해수면 높이: 고정 배율 K. 현재 조석 0.36m가 지구 반지름의 약 4%로 보이게 K≈7×10⁵. 거리가 줄어도 K는 바꾸지 않는다.
- 바다 껍질 두께와 대기: 실제 비율이 아니다.
- 달 자체 크기(지구 대비 0.27배): 실제 비율을 쓴다.

구현 대조: `PHYS.oceanBulge()`는 r≤3에서 `0.04r`, 그 위에서 `0.12+0.30(1−exp(−(r−3)/60))`로 시각 변형을 포화 압축합니다. 고배율 장면의 껍질 길이로 H나 8,000배를 재지 마십시오. 물리 높이 `tideHeight()`와 마디·그래프의 계산값을 기준으로 삼습니다. 고정 K 설명은 보존한 설계 원문이며 현재 구현과의 차이입니다.

## 근사와 한계 — 설계 원문

- 평형조석(대륙·수심 무시). 실제 해안 조수는 지형 때문에 훨씬 클 수 있다.
- 달은 순간적으로 다른 거리의 원궤도에 놓였다고 본다(안정화·궤도 진화 무시).
- 태양 조석, 지구 몸체 조석, 달의 조석 가속(지구 자전 감속)은 무시한다.
- 로슈 한계는 구간(추정)으로 그린다. 1/20 거리(19,220 km)는 액체 한계보다 바깥이라 달이 버틴다고 본다.
- 거리가 1/10 아래에서는 평형조석 식이 해양 깊이(평균 3.7km)를 넘어 정확하지 않다. 그 구간은 "추정" 표식(점선 해안선)으로 표시한다.

해석 주의: “1/10 아래”는 설계의 보수적인 추정 표시 구간입니다. 그 구간 전체에서 높이가 평균 수심을 넘는다는 뜻은 아닙니다. 1/20의 H도 2,853m로 평균 3.7km보다 작습니다. 실제 해안 수위 예보로 쓰지 마십시오. 자전과 공전의 상대 운동 때문에 “하루 두 번”은 두 부풂을 지나는 관찰이며 모든 거리·모든 24시간의 고정 횟수가 아닙니다.

## 결정 기록

| 결정 | 근거와 이유 |
|---|---|
| M1 거리 레일 두 구간 | 10cm~100,000km 접근량은 접근량의 로그, 뒤 구간은 남은 중심 거리의 로그입니다. 작은 변화와 뒤 구간의 거리 걸림을 함께 조작하도록 PHYS가 레일을 반씩 배분합니다. 경계 접근량은 10⁸m, 위치는 0.5입니다. |
| 레일 끝 중심 거리 8,000km | 설계서가 로슈 한계 안쪽까지 탐색하도록 정했습니다. 강체 한계 약 9,484km를 지나 고리 사건에 도달합니다. 안전 거리나 정확한 붕괴 거리라는 뜻은 아닙니다. |
| 현재값과 10cm를 별도 비교 | 미세 변화는 `tideExcess()`의 `expm1`·`log1p`로 계산합니다. 거의 같은 두 높이를 빼는 수치 손실을 피합니다. |
| 수치는 구현 정밀도, 본문은 설계 근삿값 | H₀는 0.3566m, 로슈는 18,486/9,484km입니다. 설계 e절 질량비 0.01230은 구현 0.012294와 구별하는 근삿값이며, 27.32일은 구현 27.3217일의 반올림입니다. |
| 설계 고정 K와 구현 포화를 함께 명시 | 원문을 보존하고 화면 부풂을 실제 높이 비율로 오독하지 않게 합니다. |
| 교육과정 연결은 확장 활동으로 해석 | 로슈 붕괴·거리 변화는 성취기준의 필수 내용이 아닙니다. 달 위상·태양계 조사·낮과 밤 설명은 별도 관찰로 보완합니다. |
| 언어 전환은 자체 스크립트와 CSS | 외부 의존성 없이 URL을 읽어 문서 언어 속성을 설정하고 두 본문 블록을 전환합니다. |
