# 원리와 시각 문법 — 로켓 발사대

학생·자유·교사 화면의 기본 표현은 코드 기하·선화뿐입니다. 글·수식은 이 문서와 안내서에서 읽습니다. 선택 수치 층만 숫자·허용 단위를 씁니다.

| 실제 층 키 | 원리 → 표현 | 선택 이유 |
|---|---|---|
| `마디` | 추력·무게·지지력을 같은 힘 마디의 화살표로 비교 | 한 마디는 엔진 하나의 6900000 N. 빈 마디·채운 마디·빗금으로 색 외에도 구별합니다. |
| `상쇄·쌓아 채우기` | 겹친 힘을 상쇄하고 받침에서 부족분을 채움 | 불꽃만으로 이륙하지 않음을 설명합니다. 별도 잉여 화살표 중복은 숨기고 큰 쌍의 남은 부분을 봅니다. |
| `문턱` | 점선 무게 문턱과 마주 보는 촉 | 즉시 이륙의 엄격 부등식과 받침 틈을 연결합니다. |
| `계단` | 노즐 개수에 따른 같은 높이씩 증가하는 마디 | 정수 1~5개의 조작 범위와 일치합니다. Q2 사건에서는 중복 기둥을 숨기고 추력·무게 쌍에 집중합니다. |
| `겹치기·숨은 구조` | 탱크 단면, 이전 연료·무게, 지구·달 비교 | 질량 감소와 중력 변화의 원인을 구별합니다. |
| `시간·운동` | 같은 시간 간격 위치 점과 별도 선형 점 띠 | 속력과 가속도 변화를 고도 압축에서 분리합니다. 범위 초과는 끊김 도형입니다. |
| `기록` | 노즐·짐·천체 조건과 결과 막대의 현재/고정 비교 | 무엇을 바꾸고 유지했는지 남깁니다. 빈 기록에 결과 영을 만들어 넣지 않습니다. |
| `그래프` | 힘·속도 곡선, 현재 점, 속도 접선 | 같은 양의 색을 장치와 일치시킵니다. 콘솔 기본 곡선은 항상 유지하고 이 층은 장치 위 비교 곡선·접선을 제어합니다. |

장면 층 키는 `room`, `console`, `hero`, `rocket`, `fuel`입니다. 교사 전체 층 순서는 `console → hero → rocket → fuel` 다음 위 표 순서입니다. 방 `room`은 배경이라 쌓기에서 제외합니다. 장면 층을 끄면 자식도 가려지는 관계를 유지합니다.

추력 보라 `#b594ff`·빈 마디, 무게 주황 `#ffaa63`·채운 마디·아래 촉, 지지력 분홍 `#f28db8`·빗금·위 촉, 속도 청록 `#64ead0`입니다. 실선·밝은 점은 현재/관찰, 점선은 기준/예측, 회색 점은 과거입니다. 점선 콘솔 전체 곡선은 현재 조건의 PHYS 예측이며 아직 관찰하지 않은 자료를 측정으로 표시하지 않습니다. 소진 추력 점프는 분리합니다. A/B 고정은 `GRAMMAR.pin()`의 세계 좌표 윤곽이며 카메라를 바꾸어도 같은 장치와 비교합니다.

후보는 같은 받침·힘 눈금·점 띠를 씁니다. Q1은 큰 틈/작은 틈/받침 위, Q2·Q6은 굵은 노즐 묶음 개수, Q3은 넓게 펼친 같은 눈금의 시간 점 간격, Q4는 짐과 남는 마디/노즐 추가/받침, Q5는 천체와 노즐 개수로 구별합니다. 잘못된 후보는 오개념 가설 도해이며 물리 기록이 아닙니다. 사건 해설은 한 개만 표시하고 빈 SVG·말풍선은 만들지 않습니다.

가로 히어로는 장치 60~75%를 목표로 투영 탐색하고 예상 카드를 오른쪽 별도 띠에 둡니다. 세로는 아래 후보 띠를 예약합니다. 콘솔까지 이중 맞춤하던 후퇴를 제거했습니다. Q2 사건은 탱크·노즐 샷으로 짧게 접근해 높이 기둥 옆 이륙을 봅니다. 로켓과 불꽃은 기존 표현 배율을 유지하고 노즐 중심 간격을 넓혔습니다. 바닥은 프레임에서 줄이는 방법을 택했습니다.

쓰지 않은 표현: 실제 사진·삽화·이모지·문자 눈금·회전 궤도 시뮬레이션·실제 화염 온도색·압축된 높이 간격으로 속력 재기. 설명이 물리 모델의 범위를 넘거나 화면을 읽는 데 글을 요구하기 때문입니다. 배경 궤도 패널은 소품이며 계산 결과가 아닙니다.

브라우저 없는 검증은 후보 SVG 유한성·물리 경로·층 키·금지 API를 확인했습니다. 5초 판독, 장치 가림, 색 대비와 투사 거리 판독은 캡처 호스트에서 확인해야 합니다.

## R9 지면과 독립 관제 단말

콘크리트 지면은 `ENV.ground.y = PHYS.SCENE.top`(0.84)입니다. 지면에 붙은 해안·시설은 같은 지면 기준 그룹으로 올립니다. 배출구는 막힌 바닥 위의 어두운 평면과 얇은 격자 마킹, 케이블 트레이와 안전 줄도 지면 마킹입니다. 지면은 장치의 그림자를 받습니다. 장치 좌표, 물리, 카메라, 히어로 경계와 UI는 유지합니다.

책상 하부 상자, 둥근 콘솔 몸체, 상판 두 장, 넓은 앞판, 나사 네 개와 나사 생성 도우미, 고무 통풍 장식 27개를 삭제했습니다. 발사대 콘크리트 판·강철 판·고정 나사도 삭제했습니다. 기존 지지 링, 노즐 보관대, 짐 샘플과 천체 받침은 장치 부품으로 유지하며 좁은 개별 지지대만 지면까지 연결합니다. 공통 갑판은 없습니다. 강철 재질 이름은 `MAT.steel`입니다.

기본 영웅 카메라 거리가 약 5.5인 점에서 refDist=6을 선택했다. 구도와 물체 크기를 바꾸지 않은 추정값이며 실제 선 두께는 팀장 캡처로 확인해야 한다. silhouettePx와 최소값은 승인된 3.2/1.3을 유지한다.

환경은 해안 발사장 그대로다. 하늘은 연한 하늘색 `#b7ccd3`, 회백색 `#d6dcd4`, 따뜻한 수평선 `#e6c3a1`, 종이색의 네 면으로 단순화했다. 구름은 캔버스에 구운 크림 띠다. 콘크리트 `#adb0aa`, 철골 `#85939a`, 바다 `#8babb5`, 식생 `#829186`, 모래 `#b6b29c`로 채도를 낮췄다. 바다는 평면과 다섯 물결선이다. 가는 철골과 봉은 inkInner=false로 법선 안쪽선만 억제하고 깊이 실루엣은 남긴다.

불꽃은 가산 혼합을 제거한 크림/주황 반투명 면이며, 연기는 회색/크림의 원판으로 단순화했다. 투명, depthWrite=false, ShaderMaterial, 라인, 스프라이트는 공통 깊이/법선 패스에서 제외된다. 접지 원판/ShadowMaterial은 기존 장면에 없으며 실제 접지 그림자는 공통 툰의 파란 hard shadow로 통일된다. 의미 있는 발광 재질과 연료/추력 셰이더는 보존한다. 그래프 화면은 크림 Basic 재질, 잉크색 기준선, 참조와 같은 fwidth 기반 1.5 CSS px 테두리를 쓴다. 사건 SVG에도 크림 판과 잉크 테두리를 넣었다.

삭제: GTAO/Bokeh/Bloom 임포트·패스·초점 갱신·품질 분기·리사이즈/캡처 보정, Hemisphere/RectArea/Point 보조광, 필/림/로켓/퀘스트 조명, RoomEnvironment와 PMREM 반사 초기화, 재질의 roughness/metalness, 하늘 그라디언트와 구름 방사형 그라디언트, 런타임 연기 색 셰이더 문자열 치환, 가산 불꽃, 어두운 HUD 배경과 blur/glow. 공통 47의 범용 재질 변환 및 AdditiveBlending 제외 판정은 원본 그대로다. 교사 레이저의 blur는 0으로 맞췄고 공통 교사 원본과 일치한다.

컴포저는 RenderPass → INK.makeOutlinePass → OutputPass다. 장면 구성 뒤 50에서 INK.convertMaterials(scene)를 한 번 호출한다. 이후 새로 만드는 문법 곡선은 라인이므로 추가 변환이 필요 없다. 단일 호출용 renderFrame 래퍼를 만들지 않고 composer.render를 직접 사용한다. low는 DPR 최대 1, 맵 1024, 흔들림 0이며 잉크/종이는 계속 활성이다. high는 DPR 최대 1.6, 맵 2048이다.

정적 줄 대조: 47 전체가 원본과 동일하다. tDepth/tNormal/tEdges를 실제 타깃 텍스처로 재연결하는 줄, setSize에서 normal/depth/edge 타깃과 두 resolution을 갱신하는 줄, nearFar/inverseProjection/DPR widths를 렌더마다 갱신하는 줄이 동일하다. 50의 makeOutlinePass 호출과 lowQuality 콜백도 동일하다. 키 목표만 이 실험실 설정으로 받는다. resize의 renderer/composer DPR·크기 호출은 참조와 동일하다. 썸네일은 1200×750/DPR 1로 같은 패스의 setSize를 통과한 뒤 원래 크기와 DPR을 복구한다. 참조의 매 프레임 재질 변환/동적 패널 탐색은 이식하지 않았으며 고정 화면 테두리는 생성 시 설치했다.

검증: assemble, 모든 src JS와 조립 ES 모듈 node --check, hand-check 193/193(기존 수 유지), quest-check 6개 실제 PHYS 자동 경로, teacher-check 통과. 요청한 어두운 색 grep과 동등한 정규식 검색 결과는 0건이다. 47 diff는 출력 없음(차이 없음)이다. 브라우저/CDN이 실행되지 않는다는 작업 조건에 따라 브라우저·GPU 셰이더 컴파일·캡처·실제 textAudit·터치·모바일 가림·명암·픽셀 선 두께는 확인하지 않았다. 정적 검증을 막는 문제는 없으며 시각 승인은 팀장 캡처에 남아 있다. 커밋·푸시는 하지 않았다.
