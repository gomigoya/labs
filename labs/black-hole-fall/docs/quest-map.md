연결 성취기준 원문(`science-2022.csv`, 밤하늘 관찰): [4과13-02] “태양계 구성원을 알고, 태양과 행성을 조사할 수 있다.” [4과13-03] “별의 정의를 알고, 북극성 주변의 별자리를 관찰할 수 있다.” 두 기준 모두 블랙홀 조석의 직접 성취기준이 아닌 심화 연결이다.

## 퀘스트 표

## 퀘스트 진행 규칙과 입력 계약

- 장면 제시 → 예상 선택 → 직접 조작 → 물리 사건 관찰 → 예상과 실제 겹침 → 원리 카드 순이다. 예상 전에는 조작을 잠그고 후보를 고르면 연다. 틀린 예상은 감점 없이 선화 두 장과 되돌림 아이콘으로 다시 보게 한다. 여섯 진행 점은 빈 윤곽·맥동·채움으로 구분한다.
- 자유 실험은 언제든 열며 모든 손잡이를 쓸 수 있다. 완료 직후 조건은 유지하고 다음 퀘스트 진입 때만 시작 조건을 세운다. Q1은 작은 질량 r=1000, Q2는 40, Q3은 200, Q4는 작은 질량 r=1, Q5는 중간 질량 r=1, Q6은 질량 선택 상태에서 시작한다. 파괴된 모형은 새 실행에 현재 입력으로 재구성한다.
- Q2는 먼저 먼 걸림값을 고정 핀으로 남겨 한 손 조작으로 가까운 칸과 비교한다. 손을 뗄 때 `snapR`를 적용하고 스냅된 r을 `measure`에 넣는다. 40·20·1의 포착 폭은 각 x=0.04다. `ratioSeen`·`comparisonOpen`은 해당 PHYS 측정 비교를 실제 열었을 때만 참이다. 플래그만으로 완료되지 않는다.
- Q3의 경계는 `r=spaghettiR`에서 intact=true, 그 안쪽에서 false다. 한 프레임에 파괴선을 건너뛰어도 `eventsBetween`이 전이를 기록한다. 정확한 경계에서 false라는 명세 Q3 표현은 상태 정의와 모순되어 채택하지 않았다. Q5·Q6은 지평선 r=1을 포함하지 않으며 파괴 문턱은 포함한다.
- Q5의 `stopped`는 손을 떼고 입력 변화가 멈춘 UI 상태다. 명세에 없는 유지 시간을 추가하지 않는다. 다른 퀘스트도 임의의 대기 시간을 판정에 넣지 않는다. Q6은 중간·큰 질량 모두 성공으로 받아들인다.
- 방향은 기본 `'radial'`, 가로는 `'transverse'`다. 판정 함수는 가로 상태를 완료로 세지 않는다. 자유 실험에서는 양 끝 압축 크기가 세로 차이의 절반임을 보여 준다.
- `measure(i,r,runId,orientation)`의 `runId`는 음이 아닌 안전한 정수다. 시작·다시 실행·퀘스트 이동 시 호출자가 새 번호를 준다. 질량 변경 비교는 같은 번호를 유지한다. 샘플 배열 순서는 관찰 순서이며 호출자가 순서대로 붙인다. 반환값은 `{i,r,runId,orientation,event,value}` 또는 유효하지 않은 입력의 `null`이다.
- `measurements(samples,runId)`는 현재 실행만 골라 입력 조건으로 다시 계산한다. 저장된 value는 판정의 근거로 신뢰하지 않는다. `eventsBetween`은 같은 실행·질량·방향의 두 조건에서만 사건 배열을 만든다. 방향이나 질량을 바꾼 행위를 낙하 사건으로 세지 않는다. 과거 실행의 먼 거리 기록과 새 실행의 가까운 기록으로 Q1·Q2를 통과할 수 없다.
- 중심 r=0과 수치 오버플로는 `event:'singularity', value:null`이다. 레일 밖 중심을 차트의 큰 숫자로 그리지 않는다. 데이터가 없으면 `[]`와 빈 격자다. Q4도 두 측정이 없으면 빈 비교다. 순수 모델 함수는 유효 입력을 전제로 하며 입력 검증은 측정과 판정 경계에서만 한다.
- 사건은 연출 쿨다운을 확인하기 전에 기록한다. 슬로·카메라·소리는 기록의 소비자이며 판정을 결정하지 않는다. 새 해설 렌즈가 열리면 이전 렌즈를 닫고 사건 순간에는 해설 도형 하나만 남긴다.

## 결정 기록과 명세 대조

명세의 rs·지평선 Δa·파괴 반지름 수치는 모두 상수에서 재계산한 결과와 허용오차 내에 있다. 수치 교정은 없다. Q3의 등호만 상태 정의를 우선했다. 명세가 정하지 않은 거리 걸림값·구간 레일·스냅 폭·포화식은 이론 카드와 PHYS에 확정했다. 이들은 물리 상수로 주장하지 않는 조작·시각 설계다. 격자·원반·부피 보존은 추정이다. reviewer-brief는 허용 파일이 아니어서 이번에 만들지 않으며 두 문서에 검수 내용을 담았다.
