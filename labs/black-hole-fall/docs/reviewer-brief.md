# 블랙홀에 빠지면 — 30분 검수 요약

물리 교사·대학원생용입니다. 표의 계산 근거는 `src/15-physics.js`이며 교육과정 연결은 4과13-02·03의 심화입니다. 먼저 식·표를 확인하고 세 상태를 조작한 뒤 아래 질문으로 검수합니다.

## 지배 방정식과 상수

G=6.674e-11 m³/(kg·s²), c=2.998e8 m/s, solarMass=1.989e30 kg, g=9.81 m/s², L=1.7 m. 질량은 태양의 10·4000000·1000000000배입니다. `r`은 지평선 반지름 배수이고 실제 중심 거리 `d=r·rs`입니다.

- `rs=2GM/c²`, 세로 `Δa=2GML/d³`, 가로 압축 크기 `GML/d³`.
- `spaghettiR=cbrt(dA(i,1)/100)`. 100 m/s²는 추정 학습 한계입니다. `intact=(r>=cbrt(dA(i,1,orientation)/100))`, `crossedHorizon=(r<1)`. 경계는 온전하며 바로 안쪽이 파괴입니다.
- 시각 늘어남 `s=1+3·tanh(atanh(0.7/3)·Δa/100)`: 한계에서 1.7, 최대 4. 세로 모양 `(s,1/√s)`, 가로 `(1/s,√s)`는 부피 보존 시각 가정(추정)입니다.
- 같은 실제 거리에서 Δa∝M, 같은 r에서는 Δa∝M⁻². 거리 반 비교는 Δa 비가 8이며 포화한 몸 길이 비가 아닙니다.

## 입력 → PHYS 계산값

수치는 유효숫자 10자리 반올림입니다. 수치 층은 r, rs(km), d(km), Δa(m/s²), r_sp 배수, stretch 순서이며 공통 컨트롤러는 소수 둘째 자리로 표시합니다. 따라서 작은 값의 0.00은 물리적 영이 아닙니다.

| 입력 (i,r,방향) | rs (m) | d (m) | Δa (m/s²) | r_sp 배수 | stretch | intact / crossedHorizon |
|---|---:|---:|---:|---:|---:|---|
| 0,40,radial | 29538.45147 | 1181538.059 | 2736.256185 | 120.5347422 | 3.999986557 | false / false |
| 0,20,radial | 29538.45147 | 590769.0295 | 21890.04948 | 120.5347422 | 4 | false / false |
| 1,0.5,radial | 11815380590 | 5907690295 | 0.008756019792 | 0.02220268935 | 1.000062442 | true / true |

손계산: 첫 행은 `2·6.674e-11·(10·1.989e30)·1.7/(40·29538.451473764362)³=2736.256185`입니다. 둘째 행은 거리가 반이므로 `8·2736.256185015995=21890.04948`입니다. 셋째 행은 `2G·(4000000·solarMass)·L/(0.5·11815380589.505743)³=0.008756019792`로 한계보다 작고 r<1이므로 온전·통과입니다. 계산은 반올림 전 값을 사용합니다.

## 근사·과장과 검수 한계

뉴턴 선형 조석 근사(L≪d)입니다. 지평선 근처·안쪽은 같은 식의 형식적 연장인 **추정**이며 상대론적 궤도·시간 지연·실제 낙하 관측을 재현하지 않습니다. 조직·손상 반응 시간·복사·생존·탈출은 계산하지 않습니다. 현재 입력의 평형 모양은 가역적이고 사건 기록은 별도입니다.

거리 레일은 구간 로그 압축·걸림 주변 선형이며 `visualRadius=4.5−3.9·railX`, 그래프는 1e-12~1e20 m/s² 로그 범위입니다. 격자·원반·입자 입력 `(s−1)/3`과 몸 부피 보존은 추정입니다. 몸 확대는 표현 전용 `presentationState`로 분리하며 판정값을 바꾸지 않습니다. 같은 스캔 시간 점은 실제 자유낙하 시간이 아닙니다. ⤢와 기준 점선으로 과장을 알립니다.
