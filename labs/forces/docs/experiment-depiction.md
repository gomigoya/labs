# 실험 과정과 결과를 한눈에 — 과학 실험실 묘사 원칙

디지털 교과서 실험실에서 아이가 **무엇을 바꿨고(과정) → 무엇이 달라졌고(결과) → 왜 그런지(이유)** 를 글을 읽지 않고도 파악하게 만드는 묘사 방법. 과학 교과서 삽화·실험 보고서 양식, 박물관 체험 전시, 다큐멘터리·모션그래픽 문법에서 공통으로 쓰는 기법을 실험실에 맞게 정리했다.

## 1. 과정 묘사

| 원칙 | 왜 | 이 실험실에서 |
|---|---|---|
| **한 화면 = 한 질문** | 질문이 없으면 결과가 '그냥 숫자'가 된다 | 퀘스트 카드 제목이 곧 질문 ("미끌미끌 vs 까끌까끌") |
| **변인을 눈에 보이게** (바꾼 것 / 그대로 둔 것 / 잰 것) | 공정한 실험(한 번에 하나만 바꾸기)의 핵심 | 실험 노트 머리에 '잰 것', 줄마다 조건 그림, **이번에 바꾼 조건만 테두리 강조**, 두 개 이상 바꾸면 "하나만 바꿔야 비교돼요" 경고 |
| **조작은 실제 도구처럼** | 슬라이더보다 '줄을 당긴다·짐을 올린다'가 기억에 남는다 | 장면 속 줄 손잡이, 잭 손잡이, 짐이 위에서 떨어져 쿵 |
| **전 → 중 → 후가 이어져 보이게** | 원인과 결과의 시간 순서 | 실시간 힘 그래프(과정), 결정적 순간 슬로 모션 + 표시선 |
| **한 번에 하나만 강조** | 주의는 한 곳에만 갈 수 있다 | 슬로 모션 동안 이름표 숨김·도구대 흐림, 해설은 하나만 |

## 2. 보이지 않는 것을 보이게

| 원칙 | 이 실험실에서 |
|---|---|
| **힘은 화살표로, 색은 끝까지 같게** | 당기는 힘 보라 · 마찰 분홍 · 무게 주황 · 부력 하늘 — 3D 화살표·그래프·카드·해설이 같은 색 |
| **돋보기(미시 확대) 인셋** | 바닥을 바꾸거나 '돋보기'를 누르면 접촉면 단면 그림이 원형 렌즈로 열린다: 유리(거의 평평) → 나무(결이 조금 걸림) → 사포(알갱이가 파고들어 맞물림). 물속 물체는 단면 위에 **아래에서 미는 화살표가 위보다 길게** 겹쳐 부력의 이유를 보여 준다 |
| **눈금은 확대해서 읽기** | 해설선이 실제 값(N)을 물체 옆에 띄운다 |

## 3. 결과 묘사

| 원칙 | 왜 | 이 실험실에서 |
|---|---|---|
| **결과는 '비교'로** | 숫자 하나는 의미가 없고, 나란히 놓아야 차이가 보인다 | **실험 노트**: 시행할 때마다 자동으로 한 줄씩 쌓이고, 막대가 자라나며 값이 붙는다 (끌기대: 미끄러지기 시작한 힘 / 용수철: 저울 눈금) |
| **지난 결과를 현재 화면에** | 예상하며 다시 해 보게 한다 | 당기기 레일에 '지난번' 눈금 표시 |
| **결론은 주장 · 근거 · 이유** | 과학 글쓰기(CER) 구조 | 성공 띠: 주장(한 줄) + 근거(측정값 칩) + 이유("왜 그럴까?"를 열면 설명과 그림) |
| **생활과 연결** | 실험실 밖으로 개념을 가져가게 한다 | 힘 카드와 성공 띠에 생활 속 장면 그림 (수레 끌기, 줄다리기, 달에서의 무게, 과일 저울, 빙판과 운동화, 수영장 튜브, 책 더미와 탁자) |

## 4. 그림 자산 (ChatGPT 이미지 생성)

- 생성: Codex(ChatGPT 계정)의 내장 `image_gen` — 같은 화풍을 묶음으로 지정(교과서풍 점토 질감 3D, 따뜻한 무채색 배경, **글자·화살표 없이**).
- 글자·화살표·수치는 그림에 넣지 않고 HTML/SVG로 겹친다 → 번역·수정이 쉽고 수치가 실제 시뮬레이션 값과 일치한다.
- 원본 1024px PNG → 512px WebP(`assets/gen/*.webp`)로 줄여 싣는다.
- 영상 생성은 연결된 도구에 없어, 움직임은 실시간 3D 연출(슬로 모션·카메라·입자)로 대신한다.
