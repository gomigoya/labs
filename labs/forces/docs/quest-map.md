# 퀘스트 지도 — 힘의 작용 (수업 흐름)

힘의 작용은 정적 관계(평형·부력)와 시간 변화(알짜힘 → 속력 변화)가 섞인 단원이다. 정적 단계는 계산·비교로, 운동 단계는 재생으로 진행한다.
각 단계는 한 가지 행동을 요구하고, 그 행동은 물리 모듈의 변수(F1, F2, 방향, g, 물체, 추 개수, 액체, 수조 높이, 바닥, 짐)를 실제로 바꾼다. 완료 조건은 물리 모듈 결과로 판정한다.
근거: 2022 개정 과학과 교육과정(교육부 고시 제2022-33호 [별책 9]) 중학교 '(5) 힘의 작용'의 성취기준, 탐구 활동, 성취기준 해설, 적용 시 고려 사항.

| 단계 | 성취기준 | 학습 질문 | 조작 대상과 행동 | 모델 | 관찰 가능한 변화 | 완료 조건 |
| --- | --- | --- | --- | --- | --- | --- |
| 1. 도입 | 9과05-01 | 힘은 무엇을 바꾸나? | 오른쪽 끌개를 끌어 도막을 당긴다 | a = F_알짜/M | 도막이 움직인다 | 도막 이동 ≥ 5 cm |
| 2. 힘의 표현과 평형 | 9과05-01 | 두 힘이 어떨 때 도막이 그대로인가? | F1·F2를 반대 방향 같은 크기(각 1 N 이상)로 맞춘다 | F_알짜 = F2 − F1 = 0 | 화살표 길이가 같고 알짜힘 화살표가 사라진다 | 유리 바닥, 두 힘 ≥ 1 N, 차이 ≤ 0.05 N, 정지 |

| 5. 탄성력 측정 (탐구) | 9과05-02 | 용수철은 힘에 따라 얼마나 늘어나나? | 추를 하나씩 더 건다 | F = kx | 기록표와 F–x 그래프에 점이 쌓이고 직선이 된다 | 서로 다른 추 개수 4점 이상 |
| 6. 마찰력 | 9과05-02 | 마찰력은 무엇에 따라 커지나? | 오른쪽 힘을 천천히 올려 도막이 막 움직이는 힘을 잰다 | f_max = μs·N | 움직이기 시작하는 순간 힘이 기록된다 | 바닥 또는 짐이 다른 조건 2개 측정 |
| 7. 부력 측정 (탐구) | 9과05-02 | 물속에서 저울 눈금은 왜 줄어드나? | 알루미늄을 걸고 수조를 올려 완전히 잠근다 | B = ρgV_잠김 | 잠길수록 눈금이 줄고 완전히 잠기면 일정 | 알루미늄 완전 잠김 |
| 8. 알짜힘과 운동 | 9과05-03 | 알짜힘이 0이 아니면 운동은 어떻게 변하나? | 도막을 출발시킨 뒤 반대쪽 힘을 키운다 | a = F_알짜/M | 속력–시간 그래프가 올라갔다 내려간다 | 빨라짐과 느려짐을 모두 관찰 |

## 단계별 설명 문장 규칙
- 조작 전: 목적 1~2문장 + 교사 발문 1개(개방형 질문).
- 조작 후: 바뀐 값과 이유 1~2문장, 실제 숫자 2개 이상.

## 비유·과장 구분
- 힘 화살표: 실제 물체가 아닌 표현. 길이는 1 N = 4.5 cm로 크기에 비례(과장 스케일).
- 화살표의 흐르는 셰브론: 방향 표시일 뿐 무엇이 흐르는 것이 아니다.
- 끌개 대차: 일정한 힘으로 계속 당기는 손의 대역(사람 손 대신 장치로 표현).
- 근사: 용수철 질량 무시, 줄 질량 무시, 공기 저항 무시, 수조 물이 넘치지 않음, 정지·운동 마찰 계수는 재질별 대표값.

## 쉬운 모드 퀘스트 (초등학생용, `src/65-kid.js`)
같은 10단계 순서를 지키고, 단계마다 지도서의 흐름(발문 → 조작 → 설명)을 **예상하기 → 실험 기구 직접 조작 → 결과 확인**으로 옮겼다. 완료 조건은 모두 물리 결과로 판정한다.

조작은 `src/67-kid-handles.js`가 기구 옆에 붙이는 **장면 속 손잡이**로 한다 (3D 물체를 정확히 맞혀 잡지 않아도 된다).
- 끌개: 줄 끝 ✋ 손잡이를 레일 따라 끈다. 레일 눈금 0~6 N(0.5 N 단위), 목표가 있는 퀘스트는 🚩 (힘 합치기 1 N, 마찰 2 N, 보스 4 N)
- 비커: 세로 레일을 위로 끌어 물에 담근다 / 바닥: 🧊 🌲 🟫 버튼 / 짐·추: ➖ ➕
- 처음에는 손잡이가 반짝이고 유령 손이 끄는 방향을 보여 준다. 성공 팝업은 1.4초 뒤 화면 아래 띠로 떠서 결과 장면을 가리지 않는다.
- 글을 못 읽는 아이를 위해 할 일은 그림으로, 퀘스트·예상·퀴즈·설명은 소리로 읽어 준다 (🔊).
조작은 버튼이 아니라 3D 기구를 직접 끌고 누른다: 끌개 대차를 좌우로 끌기(0.5 N 단위), 추 걸이 누르기, 비커 끌어 올리기, 바닥·도막 누르기, 달나라는 로켓을 끌어 중력을 바꾼다. 예상을 고르기 전에는 기구가 잠기고, 처음과 7초 쉬면 손 모양 힌트가 끌 방향을 보여 준다.
배경은 퀘스트 주제를 따른다: 운동장(1~3), 지구 → 우주·달 표면(4, 중력에 따라 섞임), 장난감 공방(5), 얼음판·숲·사막(6, 바닥 재질에 따라), 물속(7), 경주로(8), 성(9), 칠판(10). 쉬운 모드에서는 방과 콘솔 계기를 숨긴다.

## 자유 실험실 + 연출 층 (`src/68-director.js`)

퀘스트는 "길잡이"이고, 실험실 자체는 언제든 직접 만져 볼 수 있다.

- **자유 실험실**: HUD의 `퀘스트 / 자유 실험` 토글, 시작 화면·마지막 화면의 "자유 실험실" 버튼. 기구(끌기대 / 용수철과 물)를 고르면 그 기구의 모든 조작(양쪽 당기기, 짐 올리기, 바닥 바꾸기, 물체·액체·중력 바꾸기, 잭 높이)이 장면 안에 열린다. 배경도 바닥·중력에 맞춰 바뀐다(유리→빙판, 나무→숲, 사포→사막, 약한 중력→우주).
- **퀘스트 중에도** 그 기구의 다른 조작은 은은하게(`.kh.sub`) 남아 있어 직접 더 해 볼 수 있다. 처음 만지기 전·슬로 모션 순간에는 숨겨 화면을 비운다(점진적 공개).

### 연출 기법 → 구현

| 기법 | 쓰는 곳 | 구현 |
|---|---|---|
| 타이틀 카드 + 레터박스 | 퀘스트 시작 | `dirCut` → `#ktc`(눈썹 → 제목 와이프 → 밑줄 → 위로 빠짐), `body.kbars` |
| 와이드 → 밀어 들어가기(2단 카메라) | 퀘스트 시작 | `dirReveal`: 넓은 화면 0.9s → `CAM.next`로 실험 화면 1.8s, 끝에서 감속(`ease 'out'`) |
| 슬로 모션(시간 왜곡) | 미끄러지기 시작, 물에 잠김, 성공 | `dirSlow` → 물리만 `dirTime(dt)`, 카메라·화면은 실제 시간. `SLOW ×0.25` 표식, 비네트 강화, 저음 swell |
| 해설선(모션그래픽 콜아웃) | 같은 순간 | `dirCallout`: 점 → 선 → 상자 와이프, 실제 수치(N) 표시 |
| 숨쉬는 카메라·따라가기·흔들림 | 상시 / 끌기 / 부딪힘 | `dirCamPre/Post` 오프셋(기본 화면 위에 더함) |
| 긴장 사운드 | 손잡이 끄는 동안 | `dirGrab`: 힘에 따라 높아지는 톤 |
| 입자 | 바닥 먼지, 물보라, 충격 링 | `dirDust / dirSplash / dirRing` → `#kfx` |
| 실시간 그래프(텔레메트리) | 퀘스트·자유 실험 하단 | `dirTele`: 끌기대 = 당기는 힘·붙잡는 힘, 용수철 = 늘어난 힘·부력, 미끄러진 순간 표시 |

원칙: 연출은 **과학적 사건**(정지→미끄러짐, 공기→물, 뜸)에만 걸어 "언제 무엇을 볼지"를 알려 준다. 장식용 연출은 넣지 않는다.

### 직접 써 보고 고친 것 (조작 원칙)

- **도구대**: 바닥·물체·액체·중력 고르기와 짐·추 ➖➕는 장면 속이 아니라 화면 아래 고정된 한 줄(`#khdock`)에 둔다. 장면 안에는 끌어서 조작하는 손잡이(줄·잭)만 남긴다. → 누르는 동안 버튼이 움직이지 않고, 실험 장치를 가리지 않는다.
- **바꿔도 초기화하지 않기**: 짐을 올리거나 바닥을 바꿔도 당기던 힘은 그대로. 퀘스트에서는 이미 미끄러진 도막만 출발점으로 돌린다 (`khFresh`).
- **줄다리기 고정 핀**: 마우스로는 손잡이를 하나씩만 잡을 수 있으므로, 양쪽이 모두 1 N 이상이고 손을 뗀 뒤 1.3초가 지나야 핀이 풀린다. 다시 잡으면 핀이 꽂히고 도막은 가운데로.
- **화면 틀**: 퀘스트 카드 아래 ~ 도구대 위 빈 띠에 장면 중심을 맞추고, 좁으면 살짝 넓게 본다 (`dirView` → `KVIEW` → `applyViewOffset`). 조작 중에는 틀과 따라가기 카메라를 멈춘다.
- **연출 추가**: 짐은 위에서 떨어져 쿵(도막 눌림·먼지·'바닥이 받치는 힘' 해설), 바닥은 실험대를 쓸고 지나가며 '사포 · 까끌까끌 / 붙잡는 힘 최대'를 띄운다. 물 해설은 60% 이상 잠겼을 때. 자유 실험에서 끝에 부딪힌 도막은 1.4초 뒤 줄을 풀고 제자리로.
- **결정적 순간엔 해설 하나만**: 슬로 모션 동안 힘 이름표는 숨기고 도구대는 흐리게, 해설선은 모든 UI 위에.
