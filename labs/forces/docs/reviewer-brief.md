# 검수자용 요약 — 힘의 작용 (9과05)

물리 교사·대학원생이 30분 안에 검수할 수 있도록 정리했다. 모든 화면 숫자는 `src/15-physics.js` 하나에서 나오며, `node tools/hand-check.mjs`가 손계산과 21개 항목을 대조한다(현재 모두 일치).

## 지배 방정식
| 현상 | 식 | 상수 |
| --- | --- | --- |
| 무게 | W = m·g | g: 1~10 m/s² (달 1.6, 화성 3.7, 지구 9.8) |
| 탄성력 | F = k·x | 매달기 저울 k = 20 N/m (0~5 N), 끌기 저울 k = 40 N/m (0~6 N) |
| 부력 | B = ρ·g·A·s (s = 잠긴 깊이) | 물 1000, 소금물 1200, 식용유 920 kg/m³ |
| 매달기 평형 | T = W − B, x = T/k | 수면 상승(A·s/A_비커)까지 함께 푸는 닫힌 해 |
| 마찰력 | 정지 f ≤ μs·N, 운동 f = μk·N, N = M·g | 유리 0.25/0.18, 나무 0.45/0.35, 사포 0.80/0.62 |
| 운동 | a = F_알짜/M | 반암시적 오일러, 2 ms 부분 단계, 속도 부호가 바뀌면 정지 판정 |

## 근사와 과장
- 힘 화살표 길이 1 N = 4.5 cm(표현용 과장). 화살표 위 셰브론은 방향 표시이며 물질 흐름이 아님.
- 용수철 늘어남·물체 크기·이동 거리는 실제 크기(1:1).
- 용수철·줄 질량, 공기 저항 무시. 비커 물은 넘치지 않음.
- 화면의 용수철 출렁임은 평형으로 가는 감쇠 진동(ω = √(k/m), 감쇠비 0.2, 액체 속 0.4)이며 기록값은 평형값.
- 범퍼는 도막을 멈추고 알짜힘을 0으로 만드는 수직 접촉력으로 처리.

## 대표 상태 3개 (입력 → 화면 표시 → 손계산)
| 상태 | 입력 | 화면 | 손계산 |
| --- | --- | --- | --- |
| 달에서 잰 무게 (시나리오 3) | 추 3개(150 g), g = 1.6 | 눈금 0.24 N, 늘어남 1.2 cm | 0.15 × 1.6 = 0.24 N, 0.24/20 = 1.2 cm |
| 물속에서 가벼워짐 (시나리오 4) | 알루미늄 270 g·100 cm³, 물, 완전히 잠김 | 무게 2.65 N, 부력 0.98 N, 눈금 1.67 N | 0.27×9.8 = 2.646, 1000×9.8×1e-4 = 0.98, 2.646 − 0.98 = 1.666 |
| 마찰이 버틴다 (시나리오 2) | 사포, 짐 2개(M = 0.7 kg), F2 = 3 N | 정지, 마찰력 3.00 N, 최대 정지 마찰력 5.49 N | 0.8 × 0.7 × 9.8 = 5.488 N > 3 N |

추가 확인: 나무(60 g, 100 cm³)는 물에서 60% 잠겨 뜨고 눈금 0 N. 유리 바닥에서 F2 = 3 N, 0.2 s 뒤 속력 = (3 − 0.18·0.3·9.8)/0.3 × 0.2 = 1.65 m/s.
