## 2. 실험 A: 수평 잡기 (page082)

시작 팝업: "수평 잡기의 원리를 알고, 물체의 무게를 비교해 봅시다." → 확인

**화면 1 — 양팔저울로 물체의 무게 비교하기** [코드·실행]
1. 말풍선 "저울접시 양쪽에 물체를 올려놓으세요."
2. 책상 위 5개 물체(풀, 가위, 지우개, 테이프, 연필)를 끌어 왼쪽·오른쪽 접시에 놓는다. 숨은 무게 46, 41, 27, 17, 7.
3. 저울 막대가 1초 동안 돌아 기운다. 각도 = (오른쪽 무게 − 왼쪽 무게) / 2 도. 접시는 수평을 유지한다.
4. 기운 각도가 0이면 "수평" 표시가 켜진다. 실제로 확인: 46 vs 46은 0°(수평), 46 vs 7은 −19.5°.
5. 접시에는 물체를 하나만 놓는다(새로 놓으면 교체). 다시하기 버튼, 오른쪽 화살표로 화면 2.

**화면 2 — 클립을 사용해 물체의 무게 비교하기** [코드·실행]
1. 한쪽 접시에 물체(46, 41, 27 중 하나), 다른 쪽 접시에 클립(1개 = 1)을 올려 수평을 잡는다.
2. 클립은 클립 그림을 끌어 놓거나 +1 / +10 / −1 / −10 개 버튼으로 넣고 뺀다. 개수는 말풍선에 숫자로 표시.
3. 물체 27에 클립 20개 → −3.5°, 27개 → 0°와 "수평" 표시. 클립 상한은 주석 100·코드 60이지만 실제로 67개까지 들어갔다.
4. 의도: 클립 개수로 물체의 무게를 나타낸다(비표준 단위 측정).

## 3. 실험 B: 용수철 길이 측정 (page084) [코드·실행]

1. 시작 팝업: "추의 무게에 따라 늘어난 용수철의 길이를 측정해 봅시다." / 말풍선 "추를 용수철에 매달아 보세요."
2. 같은 추 5개를 하나씩 끌어 용수철 고리에 건다. 걸 때마다 용수철이 늘어난다(1초, 탄성 모양 이징). 늘어난 높이는 코드에 적힌 값: 107 → 170 → 234 → 298 → 362 → 428 px (한 번에 약 64 px). 실제 물리 계산이 아니다.
3. 깜빡이는 손가락 아이콘을 누르면 눈금자에 **확대 원**이 뜨고 빨간 표지가 가리키는 눈금(예: 12 cm 근처)을 읽는다.
4. 5개를 모두 걸면 다시하기 버튼이 나온다. 기록표, 그래프, 계산 단계는 없다.

## 4. 아쉬운 점 (우리가 고칠 것)

| # | 아쉬운 점 | 근거 |
|---|---|---|
| 1 | 수평 잡기의 원리(무게×거리)를 다루지 않는다. 막대의 눈금 1~5가 장식이다. | A 코드에서 거리 변수를 쓰는 곳이 없다 [코드] |
| 2 | 기울기가 차이에 비례하는 즉시 값이라 진동·멈춤쇠가 없다. 차이가 크면 각도가 끝없이 커진다. | `deg = (right − left) / 2` [코드] |
| 3 | 화면 1에서 "수평"은 같은 물체를 양쪽에 놓을 때만 켜진다. 다른 물체끼리는 수평이 될 수 없어 수평 잡기 활동이 없다. | 접시마다 물체 1개 [코드·실행] |
| 4 | 물체 무게가 크기·모양과 무관한지(크기=무게 오개념)를 점검하지 않는다. | [추정] |
| 5 | 예상하기, 기록, 비교 과제(5개 무게 순서 정하기)가 없다. 안내가 글 말풍선이다. | [코드] |
| 6 | 클립 상한이 주석 100, 코드 60, 실제 67 허용으로 서로 다르다. | [코드·실행] |
| 7 | 용수철 길이가 하드코딩 값이라 하중을 바꿔도 비선형·한계를 못 보여 준다. 같은 추 5개 고정. | B 코드 [코드] |
| 8 | 용수철 실험에 기록표·그래프·"간격이 같다" 확인이 없다. 학생이 눈으로 직접 비교해야 한다. | [코드] |
| 9 | 장점: 클립 개수로 무게를 재는 비표준 단위 아이디어, 확대 원으로 눈금 읽기. | [실행] |

## 5. 우리 랩에 반영

| 원본의 내용 | 우리 랩의 현재 | 반영 |
|---|---|---|
| 용수철 추 5개 → 길이 (B) | 5단계 용수철 계단: 추를 하나씩 걸면 계단과 기록이 쌓이고 F–x 그래프가 직선이 된다 | 이미 더 낫다. 변경 없음. 눈금 확대 읽기는 후속 후보 |
| 클립으로 무게 재기 (A2) | 없음 | **새 장치 '양팔저울'에서 구현**: 클립 개수를 점으로 표시 |
| 양팔저울로 비교 (A1) | 없음(평형은 끌기대 줄다리기뿐) | **새 장치**: 접시에 물체 놓기, 기울기는 물리 모듈이 계산 |
| 수평 잡기의 원리 (거리) | 없음 | **새 장치**: 접시 걸이를 막대 눈금 1~5로 옮김. 모멘트 = 질량 × 눈금 |
| 평형 판정 | 퀘스트 2: 두 힘이 같을 때 알짜힘 화살표가 사라짐 | 유지 |

**작업 단위**
- B1 (진행): 물리 `PHYS.balance` + 감쇠 진동 `PHYS.beamStep`, 3D 장치, 직접 조작, 장치 전환. 손계산 시험 추가.
- B2 (다음): 쉬운 모드 퀘스트 3개(① 두 접시 비교 ② 클립으로 재기 ③ 거리로 수평 잡기), 예상 후보는 그림만, 기록 노트, 글 없는 원리 카드. 새 퀘스트는 처음부터 글 없이 만들어 U3/U4 이전의 시험대로 쓴다.
- 이후: 결과를 `quest-map.md`, 교사 안내서에 반영하고 5초 테스트.

**물리 모델** (B1): 접시마다 물체 0~1개 + 클립 0~60개(1개 = 1 g), 걸린 위치 1~5(눈금 간격 0.06 m). 오른쪽 모멘트 − 왼쪽 모멘트 = τ. 평형각 = clamp(atan(τ/K), ±20°), K = 0.0337 N·m/rad(1 g이 눈금 1에서 약 1°). 수평 = 모멘트 차이 ≤ 0.5 g·눈금. 물체 질량 10, 20, 30, 40, 50 g이고 크기 순서와 무게 순서를 일부러 어긋나게 한다. 근사: 접시와 걸이 질량은 양쪽이 같다고 보고 무시.
