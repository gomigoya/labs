# 이론 카드 — 힘의 작용 (중학교 과학 9과05)

## a. 한 줄 통찰
가만히 있는 물체도 힘을 받고 있다. 힘들이 서로 상쇄될 때(알짜힘 0) 운동 상태가 그대로이고, 상쇄되지 않을 때만 운동이 변한다.

## b. 3단계 학습 경로
1. 알아챌 현상: 저울로 당기면 도막이 움직이기도 하고 버티기도 한다. 물에 넣으면 저울 눈금이 줄어든다.
2. 조작하며 발견할 규칙: 반대 방향 두 힘이 같으면 평형, 같은 방향이면 더해진다. 마찰력은 바닥이 거칠고 누르는 힘이 클수록 크다. 부력은 잠긴 부피와 액체 밀도에 비례한다.
3. 숫자로 확인할 법칙: W = mg, F = kx, f_max = μN, B = ρ_액체·V_잠김·g, a = F_알짜 / m.

## c. 보이지 않는 주인공
힘. 물체마다 받는 힘을 크기에 비례하는 빛나는 화살표(1 N = 4.5 cm)로 꺼낸다. 화살표 몸통에 흐르는 셰브론 무늬가 방향을 보여 준다. 종류별 색: 중력(호박), 탄성력(초록), 부력(하늘), 수직항력(흰색), 당기는 힘(보라), 마찰력(빨강), 알짜힘(노랑).

## d. 영웅 장치와 방
"힘 관측대": 계측 콘솔 위에 두 실험대를 나란히 놓는다.
- 매달기대: 스탠드 + 용수철저울 + 매단 물체(황동 추 묶음 / 알루미늄 원기둥 / 나무 원기둥) + 승강대 위 수조.
- 끌기대: 바닥 판을 바꿀 수 있는 수평 트랙 + 나무 도막(짐 추가) + 양쪽 끌개 대차에 달린 용수철저울 2개.
방: 학교 과학실의 준비실. 창문, 선반의 추 세트와 유리병, 벽의 힘 도식 패널, 펜던트 램프.

## e. 지배 방정식
- 무게: W = m·g (질량 m은 장소와 무관, 무게는 g에 비례)
- 탄성력(훅 법칙): F = k·x (매달기 저울 k = 20 N/m, 끌기 저울 k = 40 N/m)
- 마찰력: 정지 f ≤ μs·N, 운동 f = μk·N, N = M·g (수평면)
- 부력(아르키메데스): B = ρ_액체·g·V_잠김
- 운동: a = F_알짜 / M (속력 변화). 평형: F_알짜 = 0

## f. 조작 변수
- 3D 직접 조작: 끌개 대차(당기는 힘 F1·F2), 수조 승강대(잠김), 매단 물체 클릭(교체), 바닥 판 클릭(재질), 짐 추 클릭(추가)
- 콘솔: 행성 다이얼(g), 수조 높이 다이얼, F1·F2 LED 슬라이더
- 패널 슬라이더와 단축키

## g. 시나리오 프리셋
1. 줄다리기 평형: F1 = F2 = 2 N
2. 마찰이 버틴다: 사포 + 짐 2개, 오른쪽 3 N
3. 달에서 잰 무게: 추 3개, 달 중력
4. 물속에서 가벼워짐: 알루미늄, 물에 완전히 잠김

## h. 오버레이
힘 화살표(F), 힘 이름표(L), 눈금자(K: 늘어난 길이·이동 거리)

## i. 수치 칩
저울 눈금(N) / 부력(N) / 도막의 알짜힘(N)

## j. 콘솔 화면
A: 힘 장부(선택한 물체가 받는 힘 막대, 위·오른쪽 +). B: 기록 그래프(탄성 F–x / 부력 눈금–잠긴 깊이 / 속력–시간).

## k. 현상 셰이더
힘 화살표 전용 ShaderMaterial: 가산 혼합 발광, 코어는 선명, 몸통에 방향으로 흐르는 셰브론. 색 = 힘 종류, 밝기 = 크기. 이론에 흐름이 없으므로 흐름 입자는 쓰지 않는다(셰브론은 방향 표시이며 물질 흐름이 아님을 도움말에 밝힌다).

## l. 캡션 상태기계
매달기: 공중 / 일부 잠김 / 완전히 잠김 / 떠 있음. 끌기: 정지(힘 없음) / 평형(두 힘) / 마찰이 버팀 / 빨라짐 / 느려짐 / 범퍼에 닿음.

## m. 수업 단계 (가이드 투어 대신 수업 흐름)
도입 → 힘의 표현과 평형 → 같은 방향 합력 → 질량과 무게 → 탄성력 측정 → 마찰력 → 부력 측정 → 알짜힘과 운동 → 설계 → 정리·평가 (docs/quest-map.md)

## n. 흔한 오해
1. "움직이지 않으면 힘이 없다" → 도막은 중력·수직항력·마찰력을 받고 있고 합이 0일 뿐이다.
2. "무거운 물체는 물에서 부력을 더 받는다" → 부력은 물체의 무게가 아니라 잠긴 부피로 정해진다(같은 부피의 알루미늄과 나무는 완전히 잠기면 같은 부력).

## o. 헤드라인

## p. 과장 스케일
