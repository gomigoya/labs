# 힘의 작용 — 힘이 보인다

중학교 과학 '(5) 힘의 작용'(9과05-01~04) 실험실. 매달기대(중력·탄성력·부력)와 끌기대(마찰력·수직항력·알짜힘)에서 모든 힘을 크기에 비례하는 빛나는 화살표로 보여 주고, 수업 10단계·교사용 지도서·학생 평가를 실험실 안에서 진행한다.

- **쉬운 모드(기본)**: 13퀘스트(마지막 boss)의 예상 그림 → 직접 조작 → 글 없는 SVG 원리 카드. 숫자 점수·칭호·문장 퀴즈 대신 퀘스트별 별 2~3개와 힘 카드 7장 앨범을 모은다. 인트로·끝·자유 실험 3장치도 아이콘과 숫자로 표시한다. 예상 전 잠금·유령 손·자동 다음·효과음은 유지한다. 3D/canvas의 기존 글은 U5 대상이다. 교사 모드는 ?mode=full로 연다.
- **실험 장면 집중**: 지금 실험하는 장치(쉬운 모드) 또는 작업대(자세히 모드)만 밝게 두고, 그 뒤·앞의 방은 깊이와 화면 위치로 어둡게·흑백에 가깝게 누른다(`updateFocus`, FinishShader). 쉬운 모드는 카메라 중심을 카드 바깥 빈 곳으로 옮기고(`applyViewOffset`), 퀘스트 시작 때 볼 곳에 ‘여기를 봐요!’ 고리를 띄운다.
- 수업(T): 도입 → 평형 → 합력 → 질량과 무게 → 탄성력 탐구 → 마찰력 → 부력 탐구 → 알짜힘과 운동 → 설계 → 정리·평가. 각 단계는 물리 결과로 완료를 판정한다(`docs/quest-map.md`).
- 지도서(G): 성취기준·해설, 내용 체계, 4차시 운영안, 탐구 활동 안내, 발문·오개념, 성취수준과 평가 계획.
- 평가(Y): 형성평가 8문항(자동 채점), 수행 기록(측정값 자동 입력), 운동 변화 분류, 설계 과제, 자기평가, 결과 복사·인쇄.

## 개발
```
node tools/assemble.mjs     # src/ → index.html
node tools/hand-check.mjs   # 손계산 대조 21개
```
자세히 모드는 아이콘·힘 색·숫자로 조작하는 교사 시연 화면입니다. 수업 스테퍼의 책 아이콘 및 G/Y/?는 별도 `guide.html`의 단계 안내·지도서·평가·조작 안내를 새 탭으로 엽니다.

URL 옵션: `?lite=1`, `?lesson=5`(5단계부터 수업 시작). 디버그 훅은 `window.__lab`.
# 양팔저울 · 수평 잡기 (B1)

세 번째 장치 `balance`는 같은 콘솔 위에 놓입니다. 선택하면 기존 매달기대와 끌기대를 잠시 숨기며, 다른 장치를 선택하면 복원합니다. 쉬운 모드 자유 실험의 저울 아이콘, 자세히 모드 장치 줄, H 순환(`hang → track → balance`)으로 선택합니다. 퀘스트 11개는 유지하며 B1에 새 퀘스트는 없습니다.

- 트레이의 물체를 접시로 끕니다. 이미 물체가 있으면 기존 물체는 트레이로 돌아갑니다. 접시 물체를 트레이로 끌면 제거합니다. 반대 접시로도 옮길 수 있으며 같은 실물은 한 곳에만 있습니다. 유효한 접시·트레이 밖에 놓거나 포인터가 취소되면 원래 상태로 돌아갑니다.
- 접시 위 고리를 막대 방향으로 끌면 1~5 눈금에 붙으며 틱 소리가 납니다. 두 접시는 막대 각도와 관계없이 수평입니다.
- 클립 한 개 견본 또는 열 개 묶음을 접시로 끌면 각각 +1 / +10입니다. **접시 클립 더미를 누르면 −1**입니다. 한쪽당 최대 60개이며, 옆 판에 열 점씩 여섯 줄로 표시합니다. 새 장치에는 문구·툴팁·음성 없이 아이콘과 형상만 사용합니다. 막대에 새긴 1~5와 자세히 모드의 기존 장치 선택 라벨은 예외입니다.

물체 a~e의 질량은 각각 10/20/30/40/50g이고 클립은 1g입니다. 가장 큰 붉은 상자는 10g, 가장 작은 파란 구는 20g으로 크기와 질량 순서를 일부러 다르게 했습니다. 클립 배치는 고정 시드 `mulberry32(71021)`로 만듭니다. 이미지·모델·폰트를 추가하지 않습니다.

`PHYS.BALANCE`가 질량표·클립 상한·눈금 간격·복원 강성·최대각을 소유합니다. `PHYS.balance`는 양쪽 질량×눈금, 돌림힘과 목표각·수평 판정을 계산합니다. `PHYS.beamStep`은 입력 상태를 변경하지 않는 감쇠 진동 적분이며 내부 간격은 최대 0.004초입니다. ±20°에서 바깥 방향 속도를 없애 멈춤쇠를 구현합니다. 수평 LED는 정적 돌림힘 판정 결과를 표시하므로 정적 평형으로 바꾼 직후에도 막대가 잠깐 진동할 수 있습니다.

근사: 접시·걸이 질량은 양쪽이 같아 상쇄된다고 보고 무시합니다. 걸이 위치가 서로 다를 때 실제 접시 자체가 만드는 추가 돌림힘도 이 학습 모형에서는 생략합니다. 수평 부근 돌림힘과 유효 복원 강성 0.0337 N·m/rad를 사용하는 모형이며, 접시 흔들림·막대 휨·물체 충돌은 계산하지 않습니다. 수평 허용치는 지구 중력 기준 0.000294 N·m입니다.

전용 샷은 가로 `pos=(0.45,1.82,1.50), target=(0.25,1.20,0.04), fov=38°`, 세로 `pos=(0.25,2.05,2.45), target=(0.25,1.20,0.04), fov=44°`입니다. 좌표는 기존 방의 m 단위입니다. 노트·렌즈·기존 힘 HUD는 balance에서 숨깁니다.

화면 검증용 훅:

```js
__lab.set('station', 'balance');
__lab.balance.set({left:{obj:'c',clips:0,pos:2},right:{obj:'b',clips:0,pos:3}});
__lab.balance.state(); // left, right, tau, thetaTarget, level, heavier, momentL/R, theta, omega
__lab.balance.step(600); // 1/60초씩 독립적으로 전진; 기존 __lab.step도 사용 가능
__lab.balance.place('left', 'e'); // null로 제거
__lab.balance.clips('right', 30); // 증분이 아닌 절대 개수
__lab.balance.pos('right', 5);
```

기본 상태는 양쪽 물체 없음·클립 0·위치 5·각도 0입니다. 시험은 `node tools/hand-check.mjs`로 기존 21개와 양팔저울 시험을 함께 실행합니다. 원본 조각 수정 후 `node tools/assemble.mjs`로 `index.html`을 재생성합니다.


### U4: 글 없는 결과와 힘 카드 앨범

src/64-kid-cards.js가 공통 SVG 도우미, 13종 원리 카드, 힘 글리프와 7장 앨범을 소유한다. 조립은 파일명 정렬이므로 65-kid보다 먼저 포함된다. 성공 순간 물리값을 저장해 카드가 이후 움직임에 따라 바뀌지 않는다. 예상이 틀리면 2개, 그 밖에는 3개 별을 기록하며 결과 화면은 획득 별을 최대 39개 아이콘으로 표시한다. 미획득 힘 카드는 회색 실루엣과 잠금 아이콘이다.

검증: node tools/assemble.mjs, 조립 module의 node --input-type=module --check, node --check tools/text-audit.mjs, node tools/hand-check.mjs(83개). 브라우저 제한으로 감사 도구는 팀장이 실행하며, 요약의 U4 gate: PASS/FAIL과 375×812에서 원리 카드·예상/정답·앨범·인트로 배치를 확인한다. 자세히 모드의 평가 퀴즈는 유지한다.

`?lang=en`은 DOM 번역 옵션이 아닙니다. U7b-2에서 개편할 3D 콘솔 화면의 기존 언어 분기만 남아 있습니다.
