# 힘의 작용 — 힘이 보인다

중학교 과학 '(5) 힘의 작용'(9과05-01~04) 실험실. 매달기대(중력·탄성력·부력)와 끌기대(마찰력·수직항력·알짜힘)에서 모든 힘을 크기에 비례하는 빛나는 화살표로 보여 주고, 수업 10단계·교사용 지도서·학생 평가를 실험실 안에서 진행한다.

- **쉬운 모드(기본, 초등학생용)**: 수업 10단계와 같은 순서의 퀘스트 11개(7단계 부력은 2개). 퀘스트마다 예상하기(보기 2~3개) → 3D 기구 직접 조작(끌개 끌기, 추 걸이·바닥·도막 누르기, 비커 끌어 올리기, 로켓 끌기) → 결과 설명. 배경은 퀘스트 주제(운동장·우주·공방·얼음판/숲/사막·물속·경주로·성·칠판)로 바뀐다. 9단계는 보스 미션(바닥·짐을 골라 4 N에도 버티는 도막 설계), 10단계는 ⭕❌ 정리 퀴즈 4문항. 게임 요소: 위쪽 진행 지도와 점수(퀘스트 100점, 예상 적중 +50, 퀴즈 정답 +50), 힘 카드 7장 모으기, 색종이·효과음(기본 꺼짐), 최종 칭호. 화살표 이름과 설명은 쉬운 말. 왼쪽 아래 버튼으로 자세히 모드와 오간다(`?mode=full`).
- **실험 장면 집중**: 지금 실험하는 장치(쉬운 모드) 또는 작업대(자세히 모드)만 밝게 두고, 그 뒤·앞의 방은 깊이와 화면 위치로 어둡게·흑백에 가깝게 누른다(`updateFocus`, FinishShader). 쉬운 모드는 카메라 중심을 카드 바깥 빈 곳으로 옮기고(`applyViewOffset`), 퀘스트 시작 때 볼 곳에 ‘여기를 봐요!’ 고리를 띄운다.
- 수업(T): 도입 → 평형 → 합력 → 질량과 무게 → 탄성력 탐구 → 마찰력 → 부력 탐구 → 알짜힘과 운동 → 설계 → 정리·평가. 각 단계는 물리 결과로 완료를 판정한다(`docs/quest-map.md`).
- 지도서(G): 성취기준·해설, 내용 체계, 4차시 운영안, 탐구 활동 안내, 발문·오개념, 성취수준과 평가 계획.
- 평가(Y): 형성평가 8문항(자동 채점), 수행 기록(측정값 자동 입력), 운동 변화 분류, 설계 과제, 자기평가, 결과 복사·인쇄.

## 개발
```
node tools/assemble.mjs     # src/ → index.html
node tools/hand-check.mjs   # 손계산 대조 21개
```
URL 옵션: `?lang=en`, `?lite=1`, `?lesson=5`(5단계부터 수업 시작). 디버그 훅은 `window.__lab`.
