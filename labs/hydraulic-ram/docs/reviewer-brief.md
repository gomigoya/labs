# 검수자용 요약 — 수격펌프 (Hydraulic Ram)

물리 교사·대학원생이 30분 안에 검수할 수 있도록 한 장에 정리했다. 모든 화면 숫자·색·자막은 `src/15-physics.js` 한 모듈에서 나온다.

## 1. 모델

| 구성 | 내용 |
|---|---|
| 구동관 | 길이 L = 12 m, 지름 D = 50 mm, 마찰계수 f = 0.02, 입구 손실 K_in = 0.5 |
| 압력파 | 1차원 탄성 수격, 특성곡선법(MOC), N = 20 구간, a = 1200 m/s, Δt = L/(N·a) = 0.5 ms |
| 폐수 밸브 | 열림 손실 K_w = 2.0. 유속이 v_c에 이르면 15 ms에 걸쳐 닫힘. 밸브 쪽 수두가 H_re 아래로 떨어지면 다시 열림 |
| 송출 밸브 | 체크 밸브. 수두 > h이면 열림(손실 K_d = 1.5), 역류 0.06 m/s에서 닫힘 |
| 공기실 | 일정 압력(양수 높이 h)으로 둔다 |
| 공동 | 수두 −9.5 m에서 자름(기포 붕괴 압력은 모델하지 않음) |

## 2. 지배 방정식

- 특성선: dH/dt ± (a/g)·dV/dt + (a/g)·f·V|V|/(2D) = 0 (C⁺, C⁻)
- 밸브가 닫히는 유속: ½ρ·C_dA_v·v_c² = m·g → **v_c = √(2mg / (ρ·C_dA_v))**, C_dA_v = 0.003066 m²
- 밸브가 다시 열리는 수두: **H_re = m / (ρ·A_seat)**, A_seat = 0.002 m²
- 정상 최대 유속(밸브 열림): **v∞ = √(2gH / (1 + K_in + fL/D + K_w))**. v_c ≥ v∞이면 밸브가 닫히지 않는다(멈춤: noclose)
- 주코프스키: ΔH = a·Δv/g (v_c = 1.6 m/s이면 196 m. 실제로는 송출 밸브가 열려 h에서 잘린다)
- 강체 근사 한 박자 송출량: V_d ≈ A·v_c²·L / (2g(h−H))
- 효율(D'Aubuisson): η = q·h / ((Q+q)·H)

## 4. 화면 과장과 근사

| 무엇 | 실제 | 화면 |
|---|---|---|
| 높이(탱크·수두선) | 1~40 m | 제곱근 압축 0.23·√h (40 m → 1.45 m) |
| 구동관 길이 / 지름 | 12 m / 50 mm | 약 1.7 m / 약 90 mm |
| 수격 순간 | 약 0.05 s | 슬로모션 ×1/25 |
| 공기실 수위 변화 | 수 mm | 약 10배 |
| 수두선 잔진동 | 4L/a = 40 ms 주기, 격자 나이퀴스트 모드 | 수격 순간 밖에서는 [1,2,1] 공간 필터 + τ = 40 ms 시간 평활 |

**알려진 한계**: 밸브 누수·공기 손실·공기실 압력 변동이 없어 효율이 실제 장치보다 10~20%p 높다(표시 63~96%, 현장 장치 보통 50~80%). 특히 양정비 h/H가 1.5 미만인 극단에서는 90%를 넘는다.

## 5. 검수 순서 제안 (30분)

1. 첫 화면 → 1~4 시나리오 숫자가 위 표와 맞는지 (5분)
2. 무게 900 g → "정지" 자막과 q = 0 확인 (2분)
3. `node tools/hand-check.mjs src/15-physics.js` 실행 (3분)
4. 도움말(?) 수식·과장표 읽기 (10분)
5. 슬로모션으로 압력 파면이 1200 m/s로 관을 왕복하는지 확인 (10분)
