# 이론 카드 — 수격펌프 (Hydraulic Ram Pump)

## a. 한 줄 통찰
흐르던 물을 갑자기 막으면 물기둥의 운동량이 순간 큰 압력(수격)으로 바뀌고, 그 압력이 물 일부를 낙차보다 몇 배 높이 밀어 올린다. 대가로 대부분의 물은 버려진다.

## b. 3단계 학습 경로
1. **알아챌 현상:** 밸브가 "탁" 닫힐 때마다 공급 탱크보다 훨씬 높은 탱크로 물이 솟는다. 전기도 모터도 없다.
2. **조작하며 발견할 규칙:** 높이 올릴수록 한 박자에 올라가는 물이 줄어든다. 밸브 추가 무거우면(더 빨리 흐를 때 닫히면) 한 번에 많이 올리지만, 너무 무거우면 펌프가 멈춘다.
3. **숫자로 확인할 법칙:** 올라간 물의 위치에너지는 떨어진 물의 위치에너지를 넘지 못한다. η = q·h ÷ ((Q+q)·H) < 1.

## c. 보이지 않는 주인공과 시각 형태
- **구동관 속 압력 수두.** 투명 구동관 안의 물 색으로 그린다: 음압(진공에 가까움) 남보라 → 공급 압력 청록 → 수격 고압 흰빛.
- **압력 파면.** 밸브가 닫히는 순간 생긴 고압 파면이 관을 따라 공급 탱크 쪽으로 달려간다(수격 슬로모션).
- **수두선(HGL).** 구동관 위에 떠 있는 빛나는 선. 각 지점의 압력을 "물이 올라갈 수 있는 높이"로 그린다. 평소에는 공급 탱크 수면에서 밸브까지 내려가고, 수격 순간 밸브 쪽 끝이 송출 탱크 수면까지 치솟는다.

## d. 영웅 장치와 방
- **장치:** 수격펌프 관측대. 공급 탱크(높이 조절 승강대) → 유리 구동관 → 주철·황동 펌프 본체(폐수 밸브 + 추, 송출 체크 밸브) → 유리 공기실과 압력계 → 송출관 → 눈금 기둥 위의 송출 탱크.
- **분해:** 펌프 본체·공기실 앞 반쪽이 빠지며 투명해지고, 폐수 밸브 원판·체크 밸브 플랩·밸브 시트가 축 방향으로 벌어진다.
- **방:** 시골 수리 연구소의 작은 실험실. 창밖은 언덕과 개울(수격펌프가 실제로 쓰이는 곳), 벽에는 수격 압력 도식과 펌프 단면도 패널.

## e. 지배 방정식
| 식 | 의미 | 단위·범위 | 근사 |
| --- | --- | --- | --- |
| L·dv/dt = g·H − (1 + K + f·L/D)·v²/2 | 폐수 밸브가 열려 있을 때 구동관 물기둥의 가속 | v: 0~3 m/s | 강체 물기둥 근사(해석 확인용) |
| ΔH = a·Δv / g | 밸브가 순간 닫힐 때의 압력 상승(주코프스키) | a = 1,200 m/s(강관), ΔH 최대 수백 m | 순간 닫힘 |
| V_d ≈ A·v_c²·L / (2g·(h − H)) | 한 박자 송출량(강체 근사) | 0.05~1.5 L | 마찰 무시 |
| η = q·h / ((Q + q)·H) | 디오뷔송 효율 | 0~0.9 | — |
| 특성곡선법(MOC): H_P = C_P − B·V_P, H_P = C_M + B·V_P (B = a/g) | 실제 계산 모델. 구동관을 20구간으로 나눈 1차원 탄성 수격 | Δt = Δx / a = 0.5 ms | 공기실은 일정 압력, 공동(column separation)은 수두 −9.5 m에서 자름 |

화면의 모든 수치는 MOC 계산에서 나온다. 앞의 세 식은 검증표에서 MOC 결과와 비교하는 손계산 기준이다.

## g. 이야기형 프리셋
1. **낮게 많이** (H 2, h 6, 추 400 g): 낮은 곳으로는 한 박자에 물이 많이 간다.
2. **높게 조금** (H 2, h 30, 추 400 g): 높이 보낼수록 한 박자 양이 줄어든다. 높이 × 양은 거의 그대로.
3. **가벼운 밸브** (H 2, h 15, 추 120 g): 일찍 닫혀 박자는 빠르지만 한 번에 조금씩만 올라간다.
4. **무거운 밸브** (H 2, h 15, 추 900 g): 물이 아무리 빨라져도 밸브가 닫히지 않는다. 펌프가 멈추고 물은 전부 버려진다.

## h. 오버레이
- `P` 압력장: 구동관 물 색 = 압력 수두.
- `F` 흐름: 관 속 흐름 입자와 방향 화살표(속도 비례).
- `G` 수두선: 각 지점의 압력을 높이로 그린 선과 반투명 띠.

## i. 수치 칩
1. 양수량 q (L/분) / 보조: 버려지는 물 Q (L/분)
2. 효율 η (%) / 보조: 1분에 N박자
3. 밸브 쪽 최고 압력 (bar) / 보조: m 수두, 공급 압력의 ×배

## j. 콘솔 그래프
- **화면 A:** x = 시간(최근 약 2박자), y = 밸브 쪽 압력 수두(m). 공급 낙차 H와 양수 높이 h를 점선으로.
- **화면 B:** x = 양수 높이 h(5~40 m), y = 양수량 q(L/분) 곡선 + 효율 η 곡선. 현재 상태에 커서.

## k. 현상 셰이더
- 매질: 구동관 안 물기둥. 1차원 데이터 텍스처(노드 21개 × 압력·속도)를 셰이더가 읽어 색을 정한다. 가장자리 프레넬 발광, 코어는 선명하게.
- 압력 → 색: 남보라(−9 m) → 청록(H) → 하늘(h/2) → 흰빛(h 이상). 고압 파면은 압력 기울기로 밝게.
- 흐름 입자: 관 속 InstancedMesh 스트릭. 위치는 각 지점 속도로 적분, 길이는 속도에 비례, 역류 시 방향 반전.
- 폐수 분출과 송출 분사: 가산 혼합 입자(분출량은 MOC 유량에 비례).
- 발광 총량 정규화: 압력이 높을수록 셰이더 밝기 상한을 낮춰 블룸 포화를 막는다.

## l. 캡션 상태기계
| 상태 | 조건 | 문장 예 (실제 값 대입) |
| --- | --- | --- |
| 가속 | 폐수 밸브 열림, v > 0 | 물이 구동관을 내려가며 빨라지는 중. **1.2 m/s** → 밸브가 닫히는 **1.6 m/s**까지. |
| 수격 | 닫힌 뒤 0.02초 이내 | 밸브가 닫히자 밸브 쪽 압력이 **0.2 m**에서 **15.4 m** 수두로 뛰었다. 송출 밸브가 열린다. |
| 송출 | 송출 밸브 열림 | 멈춰 가는 물기둥이 **0.23 L**를 **15 m** 위로 밀어 올리는 중. |
| 반동 | 둘 다 닫힘, 압력 하락 | 반동으로 압력이 **−1.8 m**까지 떨어져 폐수 밸브가 다시 열린다. |
| 정지 | 밸브가 닫히지 않음 | 물이 최고 **2.2 m/s**에 그쳐 추(**900 g**)를 들지 못한다. 펌프가 멈췄다. |
| 대기 | 시작 전 | 폐수 밸브를 눌러 첫 박자를 시작해 보세요. |

## n. 흔한 오해
1. "공짜 에너지다." → 올라간 물의 에너지는 버려진 물이 낙차에서 잃은 에너지보다 작다(η < 1).
2. "높이 올리려면 압력이 높아야 하니 밸브를 세게 닫아야 한다." → 밸브 쪽 압력은 양수 높이 h에서 송출 밸브가 열리며 묶인다. 닫힘 속도는 압력 크기가 아니라 한 박자에 보낼 물의 양을 정한다.

## q. 카메라 샷
1. 히어로: 3/4 시점, 장치 전체 + 콘솔 앞면.
2. 밸브 근접: 폐수 밸브와 추, 공기실.
3. 구동관 측면: 압력 파면이 달리는 관을 따라.
4. 위에서: 수두선과 두 탱크 높이 비교.
5. 송출 탱크: 물이 솟아 들어오는 위쪽.
6. 콘솔 근접: 다이얼·그래프 화면.

## r. 방 소품
창문(언덕과 개울), 선반 2개(유리병·기하 오브젝트·감은 호스), 화분 2개, 벽 도식 패널 3개(수격 압력 그래프, 펌프 단면, 효율식), 펜던트 램프, 스탠드 램프, 바닥 양동이와 렌치(주제 소품), 벽걸이 압력계 시계, 작업용 의자.
