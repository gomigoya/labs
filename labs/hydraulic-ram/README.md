# 수격펌프 관측대 (Hydraulic Ram)

전기 없이 떨어지는 물의 운동량만으로 물의 일부를 몇 배 높이로 밀어 올리는 장치를, 손으로 조작하며 보는 3D 실험실.
단일 `index.html`(Three.js 0.176, jsDelivr importmap)이며 외부 모델·이미지 없이 전부 코드로 만들었다.

## 실행

```bash
node ../../tools/serve.mjs --root . --shots shots --port 5181
```
→ http://localhost:5181 . 저사양 모드는 `?lite=1`, 투어 바로 시작은 `?tour`.

소스는 `src/`의 조각 파일이고, `node tools/assemble.mjs`가 `index.html`로 합친다. `index.html`을 직접 고치지 않는다.

| 명령 | 하는 일 |
|---|---|
| `node tools/assemble.mjs` | src → index.html |
| `node tools/test-physics.mjs src/15-physics.js` | 물리 모듈 단독 실행(8개 상태) |
| `node tools/hand-check.mjs src/15-physics.js` | 강체 근사 손계산과 대조표 |
| `node ../../tools/capture.mjs --out shots/rN` | 1440×900·375×812 캡처 세트 + 콘솔 에러·가로 스크롤 검사 |

## 조작

| 조작 | 키 |
|---|---|
| 시나리오 4개 | 1~4 |
| 공급 낙차 H / 양수 높이 h / 밸브 추 무게 | `[ ]` / `- =` / `, .` 또는 탱크·추를 위아래로 끌기, 콘솔 다이얼 돌리기 |
| 압력장 / 흐름 / 수두선 오버레이 | P / F / G |
| 실험실 · 분해 · 스튜디오 보기 | V |
| 재생·정지 / 속도 / 수격 슬로모션 | Space / 0.25~2× 버튼 / M |
| 투어 / 시네마틱 / 리셋 / 도움말 / 소리 | T / C / R / ? / N |
| 카메라 | 드래그 회전, 우클릭 이동, WASD QE, Esc |
| 시동 | 폐수 밸브(추가 얹힌 황동 원판)를 클릭 |

## 과장 스케일

| 무엇 | 실제 | 화면 |
|---|---|---|
| 높이(탱크·수두선) | 1~40 m | 제곱근 압축 0.23·√h (40 m → 1.45 m) |
| 구동관 길이 / 지름 | 12 m / 50 mm | 약 1.7 m / 약 90 mm |
| 수격 순간 | 약 0.05 s | 슬로모션 ×1/25 |
| 공기실 수위 변화 | 수 mm | 약 10배 |

## 근사와 한계

- 1차원 탄성 수격(특성곡선법, 20구간, a = 1200 m/s). 박자는 1 ms 간격으로 기록한 극한 주기(1~2 박자)를 반복 재생한다.
- 공기실은 일정 압력(h). 공동은 −9.5 m에서 자른다.
- 밸브 누수·공기 손실이 없어 효율이 실제보다 10~20%p 높다. 양정비가 작은 극단에서는 90%를 넘는다.
- 수두선은 수격 순간 밖에서 [1,2,1] 공간 필터 + τ = 40 ms 시간 평활(MOC 격자의 노드별 잔진동이 제곱근 눈금에서 톱니처럼 커 보여서).
- 강체 근사 손계산과의 차이는 3~14%(시뮬이 작게). 표는 `docs/reviewer-brief.md`.

## 결정 기록

| 결정 | 이유 |
|---|---|
| 폐수 밸브를 순간 닫힘이 아니라 15 ms 닫힘 + 역류 0.06 m/s에서 닫히는 체크 밸브로 | 순간 닫힘에서는 H4·h40 같은 조건이 거짓으로 "다시 안 열림" 멈춤에 빠졌다 |
| 극한 주기를 미리 계산해 순수 함수(`sampleAt`)로 재생 | 프레임 속도·슬로모션·되감기와 무관하게 같은 화면, 계산은 조건 바뀔 때 한 번(6~190 ms) |
| 조건 변경은 다음 "다시 열림" 박자 경계에서 교체 | 박자 중간에 바꾸면 수두선이 튄다 |
| 높이를 제곱근 압축 | 2 m와 40 m를 한 화면에. 선형이면 공급 탱크가 점이 된다 |
| 오버레이를 후처리 뒤에 따로 합성(깊이 프리패스) | 수두선·라벨이 보케·블룸에 번지지 않게 |
| 히어로 구도는 투영 탐색(`__lab.searchHero`)으로 고르고 하드코딩 | 렌더 없이 수백 후보 중 HUD 밖·콘솔 화면 포함 조건을 만족하는 가장 큰 구도 |
| 세로 히어로는 손으로 조정 | 헤드리스 소프트웨어 렌더에서 탐색이 너무 느렸다. 장치 전체가 들어가는지 캡처로 확인 |
| 무거운 추로 멈춘 상태는 위상과 상관없이 "정지" 자막 | 가속 중 자막이 "한 박자에 0.000 L"을 말하는 모순 |
| 라벨은 화면 안으로 당기고, HUD 블록과 겹치면 숨김 | 모바일에서 잘림, 근접 샷에서 헤드라인 위에 겹침 |
| 근접 샷에서 물보라 점 크기 상한 | 분해 보기에서 점이 눈송이처럼 커졌다 |
| 화면 유리 거칠기 0.3 | 점광원 반사가 블룸으로 흰 사각형이 되었다 |
| 효율을 보정하지 않고 그대로 표시, 한계로 문서화 | 숫자를 맞추려 계수를 조작하면 다른 상태가 틀어진다 |
| 투과 유리 대신 반사·클리어코트 유리 | 투과는 장면을 한 번 더 그려 프레임당 약 5 ms. 31.6 → 21.1 ms(GTX 1060, 1440×900) |
| 그림자 맵을 3프레임마다(조작 중엔 매 프레임) 갱신, GTAO 샘플 8 | 장면이 거의 정적. 차이가 캡처에서 보이지 않았다 |
| 자동 하향 임계 25 ms | 40 fps 밑으로 떨어지면 AO → 픽셀 비율 → 보케 순으로 끈다 |
| 수두선 [1,2,1] 공간 필터 | 완화형 제곱근 눈금은 H = 1 m에서 탱크 바닥이 책상을 뚫어 기각 |
