# 힘의 작용 실험실

## 2026-10-12 · 쉬운 시작 화면

기본 접속은 노란 바퀴 수레 + 청록/주황 두 힘 + 한 개의 크기 손잡이입니다. 첫 활동은 예상 없이 만져 보고, 이후 두 그림 예상→한 칸씩 조작→집게 자동 해제→운동→예상/관찰 비교로 이어집니다. 고정 핀·재생을 따로 배울 필요가 없습니다. 그래프·질량·각도·세 번째 힘은 입문에서 숨깁니다.

계단 아이콘에서 입문 / 합력 확장 / 회전·세 힘 도전을 선택합니다. 확장은 첫 세 퀘스트를 보여 주며 표현 층 버튼으로 합력·그래프·숫자를 엽니다. 수레 아이콘은 입문으로 돌아갑니다. `?level=middle`, `?level=challenge` 직접 진입을 지원합니다. 선택형 음성 도움은 스피커로 켜며 기본 꺼짐입니다. 한국어/영어 브라우저 TTS와 설치된 음성에 의존합니다.

입문 1·2·3의 목표는 각각 합력 +1 N / +5 N / 0 N(질량 1 kg, 작용선 동일)입니다. 입문 중 힘은 1–4 N 정수, 방향·작용점·질량은 잠깁니다. 관찰 종료는 시간 일시정지이며 힘에 의해 멈춘 것으로 처리하지 않습니다. 수레 바퀴 회전은 시각적 표시이며 구름 저항·회전 관성은 생략합니다. `__lab.learn`에서 시작/크기/예상/관찰/다음/단계와 상태를 검증할 수 있습니다.


외부 모델·이미지 없이 Three.js r186으로 만든, 단어 없는 힘·합력·돌림힘 실험실. 학생 퀘스트 5개와 자유 실험, 교사 시연 도구, 한·영 교사 안내서를 포함한다. 빌드 도구 없이 실행한다.

브라우저: http://127.0.0.1:4173/labs/force-equilibrium/ . 저사양은 `?lite=1`, 영어 접근성 이름은 `?lang=en`, 함께 쓰려면 `?lite=1&lang=en`. 안내서는 `guide.html`. 다른 폴더에 풀었으면 해당 폴더의 serve.ps1을 실행한다. 서버는 루프백에만 바인딩된다. Three.js와 DM Mono를 jsDelivr에서 가져오므로 첫 실행에 인터넷이 필요하다. 외부 사진·생성 이미지·모델은 없다.

## 조작

- 상단: 경로=5개 퀘스트, 네모=자유 실험. 5개 원리 아이콘으로 장 이동.
- 아래: 힘 선택(고리/이중선/삼각), −/+, 고정 핀, 재생, 되돌림, 표현 층, 효과음, 교사, 공유.
- 힘 끝: 끌어 길이와 방향 조절. 중앙 레일 고리: 작용점 이동.
- 콘솔 왼쪽 노브: 선택한 힘 크기. 오른쪽: 방향. LED 슬라이더: 질량. 황동 버튼: 재생.
- 교사 오른쪽: 핀, 전 프레임, 한 프레임, 0.25×, 마디, 목표, 잔상, 분해, 기록, A/B, 스포트라이트, 레이저, 수치, 퀘스트 격자, 작용점 −/+, 안내서, 캡처, 기본 시점, 화질.
- /: UI와 사이트 셸 숨김. 스페이스: 재생. 장면에 키보드 초점을 두고 방향키: 크기/각도. 필수 조작은 터치로 가능.

핀이 있는 정지는 구속 반력에 의한 것이다. 힘 화살표는 발생기 힘만 나타낸다. 핀을 해제한 자유 강체에서만 합력과 운동을 비교한다. 합력 0은 가속도 0이며, 기존 속도를 지우지 않는다.

## 배포·사이트 셸

`dist/labs/force-equilibrium/`을 사이트 `labs/<slug>/`로 복사하면 된다. `dist/index.html`은 이 경로로 이동하고 쿼리/해시를 유지한다. `<div data-site-slot>`은 데스크톱 왼쪽 아래, 모바일 오른쪽 위를 예약한다. 공통 셸 자체는 모 사이트 빌드가 주입한다. `/`는 `window.__site?.setVisible()`, 공유는 `window.__site?.share()`를 우선 호출한다.

시작 화질은 `window.__SITE__?.quality`를 읽고 `?lite=1`이 우선한다. `window.__lab.quality('low'|'high')`로 실행 중 전환. low: AO/DoF 끔, DPR 1, 그림자 1개 1024, 입자 72/144, 블룸 입력 치수 절반. 물리·현상 셰이더·콘솔 그래프는 유지한다. high가 2초 평균 32 ms를 넘으면 AO→DPR→DoF 순서로 낮춘다. 색 출력은 ACES, 그림자는 r186의 PCFShadowMap(구 PCFSoftShadowMap 대체).

`meta.json`은 식별자·ko/en 제목/설명·분류·썸네일·가이드를 포함한다. 제공된 작업 폴더에 hydraulic-ram 예제가 없어 해당 사이트의 실제 스키마와 자동 대조하지 못했다. 모 사이트의 필수 필드가 별도로 있으면 통합 시 매핑해야 한다.

## 공개 검증 API

```js
__lab.set('0.mag', 4); __lab.set('1.angle', 180);
__lab.set('1.attach', .65); __lab.set('mass', 2);
__lab.preset(0); __lab.mode('present');
__lab.quest.go(3); __lab.quest.pick(1);
__lab.layer('ab', true); __lab.layer('numeric', true);
__lab.quality('low'); __lab.shot(0);
__lab.pauseLoop(); __lab.step(120, 1/60);
await __lab.capture('thumb'); // 1200×750
__lab.textAudit(); __lab.diagnostics(); __lab.resumeLoop();
```

`SHOTS` 6개, `SHOTS_VERTICAL` 3개. `flyTo()`는 이동, `shot()`은 즉시. `view('hero'|'top'|'section')`. `step()`은 한 호출 최대 120프레임이며 rAF 스케줄러와 독립적이다. `capture()`는 렌더 한 회 뒤 POST `/__save/<name>.jpg`; 로컬 서버는 `shots/`에 저장하고 thumb는 실험실 폴더에도 복사한다. 호스팅에서는 다운로드로 대체한다. 캡처는 3D 캔버스이며 HTML HUD는 브라우저 스크린샷으로 따로 확인한다.

## 모델·근사·표시 배율

Fᵢ=fᵢ(cosθᵢ,sinθᵢ), R=ΣFᵢ, τ=Σrᵢ×Fᵢ, a=R/m, α=τ/I, I=m(2²+1.8²)/12. 수평 에어 테이블에서 중력·항력은 상쇄, 마찰·공기 저항 생략. 작용점은 물체와 회전하고 힘 방향은 실험실 기준. dt≤1/120 s 반암시적 오일러. 테이블 경계에서 안전 핀으로 원점 복귀(반사 운동 아님).

기본 힘 표시 0.62 장면 단위/N, 병진 0.35 단위/m, 회전 1 rad/rad. 세로 화면 힘 표시는 0.82배. 합력>8 N이면 모든 힘·합력·기준 화살표를 같은 배율 8/|R|로 줄여 비율과 마디 개수를 유지한다. 교사 도구 띠·모바일 안전 영역에 걸릴 때도 모든 화살표에 동일한 추가 표시 배율을 적용한다. 장치의 확대 도형은 표시 스케일을 뜻한다. 분해 플레넘은 정성 구조 도해이며 압력장을 계산하지 않는다. 설명 화살표는 후처리 뒤 별도 층에 합성하며 단순화한 장치 깊이 프록시로 가림을 유지한다.

## 검증과 남은 한계

대표 3상태 손계산, 자유 운동·질량 반비례 검증, 다섯 퀘스트 전 단계, 교사 표현 층, 저사양, 세로 화면과 텍스트 검사를 실행했다. 자세한 캡처·결과·자체 비평은 실험실 `docs/review-log.md`에 있다. 현재 브라우저의 low 모드에서 52–60fps(최종 극단 상태 5초 측정 약 60fps). 4GB 내장 GPU 실기기는 별도로 검증하지 못했다. 5초 테스트는 제작자의 캡처 자체 점검이며, 실제 어린이 관찰 실험을 대신하지 않는다.

## 결정 기록

1. 빈 `<theory>`는 요청 제목의 힘·평형으로 해석. 병진 평형에 돌림힘과 작용선 비교를 포함해 오개념을 방지.
2. 생성 이미지·외부 에셋 금지에 따라 이미지 컨셉 단계 대신 코드 블록아웃과 실제 렌더를 기준으로 3회 이상 비평.
3. 선형 화살표에 고리·이중선·삼각 끝을 결합해 색각 차이를 보완. 동일 방향 힘은 작은 높이 차로 나란히 읽히게 한다(물리 작용점의 y 좌표를 바꾸는 것은 아님).
4. 학생 과제는 한 번에 한 조건을 맞출 수 있도록 기본 고정 핀을 사용. 조건을 완성한 뒤 핀을 풀어 운동을 관찰.
5. 예측→조작→물리 1초 유지→비교→원리 카드. 틀린 예상도 감점 없이 유지.
6. 모든 현재/목표 쌍과 순수 물리 함수를 단일 HTML에 둔다. 외부 빌드·React·모델 파일을 도입하지 않음.
7. meta 예제 부재로 범용 ko/en 메타 사용. 기존 사이트 셸 코드는 임의로 재현하지 않고 지정 슬롯과 API 계약으로 통합.
8. 모든 개발·캐시·캡처·배포 아카이브는 D:에 저장. 앱 산출물 경로는 비어 있던 outputs 폴더를 D: 출력 폴더로 연결해 호환.
