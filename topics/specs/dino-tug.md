# 공룡과 줄다리기 — 실험실 명세 (slug: dino-tug)

연결 성취기준: 4과01-01(밀거나 당길 때 나타나는 현상), 6과01-03(화석으로 과거 생물과 환경을 추리). 대상 3~6학년. 화면은 글 0개, 삽화 금지(코드로 그린 로우폴리·선화만).

## 한 줄 통찰
줄다리기는 "누가 더 센가"만으로 정해지지 않는다. 당길 수 있는 힘은 **근육이 낼 수 있는 힘**과 **바닥이 붙잡아 주는 힘(마찰)** 중 작은 쪽이 한계다. 그래서 바닥이 미끄러우면 무거운 쪽이 이긴다. 또 몸이 커질수록 몸무게 대비 힘은 약해진다(근육 단면적 ∝ 몸길이², 몸무게 ∝ 몸길이³).

## 조작 변수
- 공룡 고르기(6종, 도구대 견본): 벨로키랍토르 15 kg / 딜로포사우루스 400 kg / 스테고사우루스 3,000 kg / 트리케라톱스 6,000 kg / 티라노사우루스 8,000 kg / 아르젠티노사우루스 70,000 kg.
- 아이 수(장면 속 줄 뒤 대기열에서 끌어 세운다): 1~100명. 아이 1명 = 35 kg.
- 바닥(도구대 견본): 유리/빙판 μ 0.05 · 모래 0.35 · 자갈 0.55 · 아스팔트 0.8.

## 물리 모델 (`src/15-physics.js`, 순수 함수, 단위 N·kg·m·s)
- g = 9.81. 근육 한계(추정): 몸무게 70 kg 사람이 자기 몸무게의 0.5배를 당길 수 있다고 보고 계수 `k = 0.5·70·g / 70^(2/3)` ≈ 20.215 N/kg^(2/3). 질량 m 인 동물의 근육 한계 `Fm(m) = k·m^(2/3)`. 아이는 별도로 `Fm_kid = 0.4·35·g` = 137.34 N (몸무게 0.4배, 어린이는 사람 계수보다 약하다고 가정, 추정).
- 마찰 한계: `Ff(m, μ) = μ·m·g` (줄이 수평, 발이 미끄러지기 직전의 최대 수평힘).
- 한 쪽의 당김 한계: `Fcap = min(Fm, Ff)`. 아이 팀: `n·min(Fm_kid, μ·35·g)` (아이는 서로 독립으로 합산). 공룡: `min(Fm(m), μ·m·g)`.
- 승부: 줄 장력은 양쪽이 같고, 먼저 미끄러지거나 한계를 넘는 쪽이 진다. `Fcap` 가 큰 쪽이 이긴다. 차이가 허용오차(1 N) 안이면 `tie`. 알짜 `net = Fcap_kids − Fcap_dino`.
- 공개 API: `C`, `SPECIES`(이름 키, 질량), `GROUNDS`(μ), `kidCap(n, mu)`, `dinoCap(species, mu)`, `outcome(n, species, mu)` = `{kids, dino, net, winner: 'kids'|'dino'|'tie', limiter: 'muscle'|'friction' (이긴 쪽이 아닌 진 쪽 기준 어떤 한계가 걸렸나)}`, `minKidsToWin(species, mu)` (정수, 불가능하면 `Infinity`), `weightRatio(species)` = Fm/(m·g) (체중 대비 힘), `slipOnset`(미끄러짐 시작 판정 보조 필요하면), 레일/슬라이더 매핑이 있으면 `railX`.
- 기대값(요구사항에서 직접): k=20.2149; Fm(15 kg)=122.95 N; Fm(400)=1,097.6 N(±0.5%); Fm(3000)=4,205 N; Fm(6000)=6,675 N; Fm(8000)=8,086 N; Fm(70000)=34,335 N; 체중 대비 힘: 15 kg 0.836, 8000 kg 0.103, 70000 kg 0.050; `minKidsToWin`(정의: `n·아이한계 > 공룡한계`인 최소 정수): (트리케라톱스, 자갈) = 49 (49×137.34 = 6,729 N > 6,675 N, 48명은 6,592 N), (티라노, 자갈) = 59 (59×137.34 = 8,103 N > 8,086 N, 58명은 7,966 N), (티라노, 모래) = 68 (8,086/120.17 = 67.3), `(티라노, 유리)` = Infinity (100명 상한 안에서 불가능: 3,924 N 대 아이 17.17 N×n → 229명 필요; 상한 100이므로 "불가능"), 30명 자갈에서 딜로포사우루스(400 kg)를 이기고 스테고사우루스(3,000 kg, 4,205 N 대 아이 4,120 N)에는 진다.

## 영웅 장치와 방
- 방: 고생물 표본실(선반의 화석 단면 도식, 발자국 석고판, 암모나이트 모형, 지층 단면 패널 2장(글 없음), 스탠드 램프, 창문).
- 장치: 길쭉한 실험대 위 **줄다리기 트랙**. 가운데 줄 마디(깃발 눈금), 왼쪽에 아이 대기열(줄에 매달리는 로우폴리 인형 패널은 금지, 아이는 같은 모양의 둥근 말뚝 아이콘 N개로 표시), 오른쪽에 공룡(로우폴리 입체: 몸통·목·꼬리·다리를 캡슐과 박스로 조립, 종마다 실루엣이 확연히 다르다: 작음/두 발/뿔/갑옷판/거대 두 발/거대 목). 공룡 옆 키 말뚝(아이 키 1.3 m 눈금)으로 크기를 센다. 바닥 판은 바닥 재질을 바꾸면 슬라이드해 교체(유리=투명 광택, 모래=입자, 자갈=돌, 아스팔트=어두운 거친 면).
- 돋보기: 발바닥 접촉면 단면 도해(forces 실험실의 접촉면 렌즈와 같은 문법): 유리(매끈) / 모래 / 자갈 / 아스팔트에서 발이 얼마나 맞물리는지.

## 시각 문법
- 힘 마디: 당김은 마디 화살표(1마디 = 아이 1명 한계 137.34 N, 상한을 넘으면 끊김 기호 + ⤢ 과장). 근육 한계와 마찰 한계를 두 가지 한계 윤곽(점선): 보라 점선 = 근육, 분홍 점선 = 마찰, 둘 중 안쪽에 있는 쪽이 실제 한계(실선이 거기까지 찬다). 바닥을 바꾸면 분홍 점선이 늘거나 준다.
- 비교(겹치기): 바꾸기 전 값 점선 잔상. 결과: 줄 가운데 깃발이 이긴 쪽으로 움직이고(시간 점으로 간격 표시), 진 쪽 발바닥 먼지/미끄러짐.
- 색: 아이 = 주황, 공룡 = 초록, 근육 한계 = 보라, 마찰 한계 = 분홍.

## 퀘스트 (예상 → 조작 → 판정, 오개념 후보 포함)
1. 아이 1명 대 벨로키랍토르 — 자갈에서 줄을 당긴다. 후보: 공룡이 이긴다(오개념: 공룡이면 무조건 센 것) / 비긴다 / 아이가 이긴다(정답: 아이 137.3 N > 123.0 N). 판정: winner==='kids'.
2. 아이는 몇 명이어야 트리케라톱스를 이길까 — 후보: 5명 / 20명 / 약 50명(정답. 정확히는 49명부터 이긴다). 판정: 아이 수가 `minKidsToWin` 이상이고 winner==='kids'.
3. 티라노사우루스 — 자갈에서 아이 몇 명? 후보: 몸무게가 훨씬 무거우니 100명도 못 이긴다(오개념) / 60명 정도(정답, 59명부터) / 10명. 판정: `minKidsToWin(티라노, 자갈)` 이상.
4. 바닥을 유리로 바꾸면 — 같은 인원으로 바닥만 바꿔 결과가 뒤집히는 것을 본다. 후보: 아이가 더 유리해진다(오개념) / 그대로 / 공룡이 더 유리해진다. 판정: 같은 아이 수·공룡에서 자갈일 때 kids 승, 유리일 때 dino 승을 둘 다 관찰.
5. 왜 미끄러질까 — 마찰 한계 윤곽을 보고 아이 팀이 이기는 조건이 "몸무게 합"인 이유를 안다. 조작: 유리 위에서 아이 수를 늘려 분홍 점선이 늘어나는 것을 본다. 판정: 유리에서 limiter==='friction' 인 상태에서 아이 수를 10명 이상 늘림.
6. 큰 동물은 왜 몸무게에 비해 약할까 — 벨로키랍토르와 아르젠티노사우루스의 `weightRatio` 마디를 나란히 비교. 후보: 클수록 체중 대비 힘이 세다(오개념) / 같다 / 작아진다. 판정: 두 종을 모두 선택해 비교 표시를 열람.
7. 설계 — 아이 30명, 자갈. 이길 수 있는 가장 큰 공룡을 고른다. 정답 딜로포사우루스(4,120 N > 1,098 N; 스테고사우루스는 4,205 N라 진다). 판정: 30명·자갈에서 winner==='kids' 이면서 가장 무거운 종.

## 근사와 한계 (guide와 reviewer-brief에 명시)
- 공룡의 실제 근력은 알려져 있지 않다. 사람 기준 계수에 `m^(2/3)` 규칙을 적용한 **추정**이며 실제 공룡과 다를 수 있다.
- 마찰계수는 대표값이고 공룡 발톱·발바닥 구조·몸 기울기(자세로 줄을 당기는 각도)는 무시한다. 줄은 수평, 질량 없음.
- 아이는 줄에 같은 각도로 서고 서로 힘을 정확히 합친다고 가정한다.
- 아르젠티노사우루스와 유리 바닥에서 근육 한계와 마찰 한계가 우연히 비슷한 값이 된다(0.05). 교사 안내서에 밝힌다.
