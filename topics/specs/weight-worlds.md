# 다른 별에서 내 몸무게는? — 실험실 명세 (slug: weight-worlds)

연결 성취기준: 4과01-02(수평잡기로 무게 비교), 4과01-03(저울로 무게 비교), 4과13-02(태양계 구성원, 태양과 행성). 3~6학년, 글 0개, 삽화 금지.

## 한 줄 통찰
**질량은 어디서나 같고 무게는 그 별의 중력만큼 달라진다.** 중력 `g = GM/R²`. 같은 몸이라도 달에서는 1/6, 태양에서는 약 28배, 중성자별에서는 상상할 수 없는 값이다. 그래서 점프 높이도 중력에 반비례한다.

## 조작 변수
- 천체 고르기(도구대 회전 선반 견본, 10종): 지구, 달, 명왕성, 화성, 금성, 토성, 목성, 태양, 중성자별(+ 우주 공간 0).
- 몸(손잡이로 추 개수 조절): 추 1~5개(1개 = 아이 8 kg 단위, 기본 5개 = 40 kg).
- 점프 시험(레버): 같은 힘으로 뛰어오른다.

## 물리 모델 (`src/15-physics.js`)
- 상수: G = 6.674e-11, g_지구 = 9.81 (기준), 지구 점프 초속도 v = 2.8 m/s (점프 높이 0.40 m 가정, 추정).
- 천체표(질량 kg, 반지름 m): 지구 5.972e24 / 6.371e6, 달 7.342e22 / 1.737e6, 명왕성 1.303e22 / 1.1883e6, 화성 6.417e23 / 3.3895e6, 금성 4.867e24 / 6.0518e6, 토성 5.683e26 / 5.8232e7, 목성 1.898e27 / 6.9911e7, 태양 1.989e30 / 6.957e8, 중성자별 2.7846e30(1.4 M☉) / 1.2e4.
- `g(body) = G·M/R²`, 지구 대비 `gRatio(body) = g(body)/g(지구 천체표 값)`. 표시 기준은 지구 천체표로 계산한 g(≈9.8195)가 아니라 **표준 9.81을 기준으로 한 비**로 쓰지 말고, 천체표 값끼리의 비를 쓴다(지구=1.0).
- 무게 `W = m·g(body)`, 질량 m은 변하지 않는다. 점프 높이 `h = v²/(2·g(body))`(지구에서 0.40 m).
- 기대값(요구사항에서): 달 1.624 m/s²(지구 대비 0.1654), 화성 3.728(0.3797), 금성 8.869(0.9032), 목성 25.92(2.640), 토성 11.19(1.139), 태양 274.3(27.93), 명왕성 0.6159(0.06272), 중성자별 1.2906e12(1.314e11) (각 ±0.5%). 40 kg 몸의 달 무게 = 64.96 N(지구 대비 같은 비). 점프 높이: 달에서 0.40/0.1654 = 2.42 m, 목성 0.151 m, 태양 0.0143 m.
- 공개 API: `C`, `BODIES`, `g(i)`, `gRatio(i)`, `weight(i, nWeights)`, `jumpHeight(i)`, `judge*`.

## 영웅 장치와 방
- 방: 행성 연구실(천체 모형이 늘어선 선반, 궤도도 패널, 돔 창의 하늘).
- 장치: 콘솔 위 **용수철 저울 + 회전 천체 선반**. 천체를 고르면 저울 받침 아래에 해당 천체의 로우폴리 구(표면 질감 셰이더)가 올라오고, 추 5개가 저울 고리에 걸리고 용수철이 늘어나 마디 눈금이 선다(마디 1 = 지구에서 추 1개의 무게, 상한 30마디를 넘으면 끊김 기호 + 천체 표면 발광 + ⤢). 옆에는 양팔저울 하나(질량 비교용): 추와 같은 개수의 기준 추가 양쪽에서 **항상 평형**이다(질량은 같다는 것을 보여 준다). 점프 높이는 옆 기둥의 높이 눈금 위에 점프 막대(동그란 인형 아님, 단순 구슬)가 올라가는 높이로 표현한다.
- 시각 문법: 무게 화살표(주황, 마디), 바꾸기 전 값(지구) 점선 윤곽과 겹치기, 질량은 추 개수(점)로 센다(변하지 않음).

## 퀘스트
1. 달에서 무게는? 후보: 같다 / 줄어든다 / 늘어난다. 정답 줄어든다(지구 대비 0.165). 판정: 달 선택 + 추 걸림.
2. 질량도 줄까? (양팔저울 평형 유지) 후보: 질량도 줄어든다(오개념) / 그대로 / 늘어난다. 판정: 지구와 달 모두에서 양팔저울이 평형인 것을 확인(두 천체를 모두 선택).
3. 가장 무거운 행성은? (목성) 후보: 토성 / 목성 / 금성. 판정: 목성 선택(행성 중 최대).
4. 태양에서는? 후보: 조금 무거워진다 / 몇 배 / 서 있을 수 없다. 정답 약 28배(몸무게 40 kg 이 약 1,117 kg 무게). 판정: 태양 선택 + 마디 끊김 상한 확인.
5. 점프 높이는? 후보: 달에서 같다 / 달에서 더 높다(정답 2.42 m, 중력에 반비례) / 달에서 더 낮다. 판정: 지구와 달에서 모두 점프 시험.
6. 중성자별은? (상상 불가능한 값: 마디 끊김, 무게가 저울을 뚫는 연출) 판정: 중성자별 선택.
7. 설계 — 지구에서와 거의 같은 무게(±15%)가 되는 천체를 지구 말고 골라라. 정답 금성(0.903) 또는 토성(1.139). 판정: 선택한 천체의 `gRatio ∈ [0.85, 1.15]` 이고 지구가 아님.

## 근사와 한계
- 천체 표면 중력은 구형·비자전 근사. 목성·토성·태양은 "표면"이 가스·대기 상층 기준(1바 고도 또는 광구)이라 서 있을 수 없다. 중성자별은 가상의 대표값(R 12 km, 1.4 M☉).
- 점프 초속도는 몸이 같은 힘으로 뛴다는 단순 가정이며 점프 자세·공기 저항·대기압 무시. 추정.
- 태양·중성자별 장면은 ⤢ 과장 표시.
