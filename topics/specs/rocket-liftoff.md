# 로켓은 언제 땅에서 떠오를까? — 실험실 명세 (slug: rocket-liftoff)

연결 성취기준: 4과01-01(물체를 밀거나 당길 때 나타나는 현상), 6과10-01·02(위치 변화, 속력). 대상 3~6학년, 글 0개, 삽화 금지.

## 한 줄 통찰
로켓은 **엔진이 미는 힘(추력)이 몸무게보다 커져야** 뜬다. 같으면 제자리, 작으면 땅에 남는다. 연료가 타서 가벼워질수록 같은 추력으로 더 빨리 가속된다.

## 조작 변수
- 엔진 수(손잡이 또는 도구대 − / +): 1~5개. 엔진 1개 = 추력 6.9 MN(새턴 V의 F-1 엔진 한 개 급, 해수면 기준).
- 짐 질량(도구대 3칸): 가벼움 / 보통 / 무거움 = 추가 0 / 2.0e5 / 5.0e5 kg 중 하나(기본 보통은 0, 아래 참조).
- 천체(도구대 2칸): 지구 g = 9.81 / 달 g = 1.62.
- 연료량은 "가득" 고정(2.0e6 kg).

## 물리 모델 (`src/15-physics.js`, 1차원 수직 운동, 공기저항 무시)
- 로켓 건조 질량 + 짐 `mDry` = 9.7e5 kg (새턴 V 1단 근사의 단순화), 연료 `mProp` = 2.0e6 kg, 점화 직후 총 질량 `m0 = mDry + 짐 + mProp` (기본 짐 0 → 2.97e6 kg).
- 엔진 추력 `T = n·6.9e6 N`, 배기 속도 `ve = 2580 m/s` → 질량 유량 `ṁ = T/ve`. 연료가 다 타면 추력 0.
- 상태: 땅 위(`onPad`) 또는 비행. 무게 `W(t) = m(t)·g`, `m(t) = m0 − ṁ·t`. 점화 후: `T > W` 이 되는 순간 이륙(`liftoffT`). 그전에는 발사대가 받치는 힘 N = W − T 로 가속도 0. 이륙 후 `a = T/m − g`. 속도·고도는 적분(고정 0.01 s 스텝, 해석해와 일치).
- 점화 순간 이륙 판정: `T0W = T/(m0·g)`. `T0W > 1` 이면 즉시 이륙. 지구·기본 짐: n=5 → T0W 1.184, n=4 → 0.947(이륙까지 14.63 s), n=3 → 0.710(107.2 s), n=2 → 0.474(292.3 s). 연료 소진 시간 `tBurn = mProp/ṁ = 2.0e6/(n·6.9e6/2580)`: n=2 에서 373.9 s 이므로 292.3 s 에 이륙 가능, n=1 에서는 747.8 s 인데 이륙 시각 847.5 s 가 더 늦으므로 **끝까지 못 뜬다**.
- 공개 API: `C`, `m0(load)`, `thrust(n)`, `T0W(n, load, g)`, `liftoffTime(n, load, g)`(점화 후 초, 못 뜨면 `Infinity`), `enginesNeeded(load, g)`(점화 즉시 이륙 가능한 최소 엔진 수), `simulate(n, load, g, tEnd, dt)` → `{ t[], h[], v[], a[], m[], liftoffT }`, `judge*`.
- 기대값(요구사항에서): `m0(0)` = 2.97e6; `T0W` n=1..5 (g=9.81): 0.2368, 0.4736, 0.7105, 0.9473, 1.1841 (±0.1%); `liftoffTime` n=4 → 14.63 s, n=3 → 107.2 s, n=1 → Infinity; `enginesNeeded(0, 9.81)` = 5; 달(g=1.62)에서 `enginesNeeded(0, 1.62)` = 1 (T0W(1, 0, 1.62) = 1.434); 짐 2.0e5 kg(m0=3.17e6)에서 지구 `enginesNeeded` = 5 (T0W(5)=1.1094); 짐 5.0e5 kg(m0 3.47e6)에서 `enginesNeeded` = 5 (T0W(5) = 1.0134, n=5 가 최소); 연료 소진 후 속도 증가는 치올콥스키 `Δv = ve·ln(m0/m_end)` 와 같다(n=5, 짐 0: m_end = 9.7e5, Δv = 2580·ln(2.97e6/9.7e5) = 2,890 m/s, 중력 손실은 `g·tBurn`을 빼면 `Δv_net = Δv − g·tBurn`; tBurn = 2.0e6·2580/(5·6.9e6) = 149.6 s; Δv_net = 2,890 − 1,467 = 1,423 m/s ±1%).

## 영웅 장치와 방
- 방: 우주센터 관제 모형실(발사 지도 패널, 궤도 도식, 창밖의 낮 하늘, 소품: 연료 탱크 모형, 별자리, 손전등 등).
- 장치: 콘솔 위 **로켓 발사대 모형**. 로켓은 원통·원뿔·핀을 조립한 로우폴리, 엔진 노즐 1~5개가 아래에 놓이고 노즐마다 불꽃(셰이더, 추력에 비례). 옆 높이 기둥(눈금)에서 고도(과장 ⤢: 높이 눈금 압축)를 센다.
- 시각 문법: **상쇄**: 추력 화살표(보라)와 무게 화살표(주황)를 마디로 나란히, 같으면 →← 기호, 추력이 크면 남는 마디만 위로. 추력 < 무게면 발사대가 받치는 힘(분홍) 화살표가 그만큼 올라온다. 연료가 줄면 무게 화살표가 점선 잔상(이전 값) 안으로 짧아진다. 속도는 같은 시간 간격의 점(간격이 넓어지면 빨라짐).

## 퀘스트
1. 엔진 1개로 뜰까? 후보: 뜬다 / 천천히 뜬다(오개념) / 안 뜬다. 정답 안 뜬다(T0W 0.237, 연료 끝까지). 판정: n=1 점화, `liftoffTime = Infinity` 확인.
2. 엔진이 몇 개부터 점화 즉시 뜰까? 후보: 3개 / 4개 / 5개. 정답 5개. 판정: n=5 점화, 점화 순간 이륙.
3. 연료가 줄면? (n=5, 속도 점이 점점 벌어짐) 후보: 일정하게 빨라진다 / 점점 더 빨라진다(정답) / 느려진다. 판정: 점화 후 가속도가 증가한 것을 관측(`a(t_end) > a(0)`).
4. 짐을 늘리면? 후보: 엔진을 더 늘려야 한다 / 그대로 뜬다(정답: 5개로 충분하지만 가속이 줄고 여유가 작아진다) / 못 뜬다. 판정: 무거운 짐에서 T0W 값이 줄어든 것을 비교 열람(짐 보통→무거움).
5. 달에서는? (g = 1.62) 후보: 엔진 5개가 필요하다 / 1개로 충분하다(정답) / 불가능. 판정: 달 선택 + n=1 점화 즉시 이륙.
6. 설계 — 무거운 짐(5.0e5 kg)을 지구에서 점화 즉시 띄우는 최소 엔진 수를 골라라(정답 5). 판정: `enginesNeeded` 와 같은 n 선택(더 작으면 실패, 더 크면 불가능한 6개는 없음).

## 근사와 한계
- 공기저항, 고도에 따른 g 변화, 엔진 진공 성능 증가, 단 분리, 곡선 궤도는 계산하지 않는다(1차원 수직 상승).
- 건조 질량·연료·추력·배기 속도는 새턴 V 1단의 단순화 값이며 실제와 다르다.
- 고도 눈금은 과장 압축(⤢), 불꽃 길이는 시각 표현.
- `1개로는 못 뜬다`는 연료가 끝나는 748 s 안에 T > W 에 도달하지 못하기 때문(연료가 더 많았다면 결국 뜰 수도 있다).
