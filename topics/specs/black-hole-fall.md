# 블랙홀에 떨어지면 — 실험실 명세 (slug: black-hole-fall)

연결: 4과13-02(태양계 구성원, 태양과 행성), 4과13-03(별) — 성취기준에 직접 단원이 없는 **심화 주제**. 3~6학년, 글 0개, 삽화 금지.

## 한 줄 통찰
블랙홀에 가까워질수록 발과 머리를 당기는 중력의 **차이**가 거리의 세제곱에 반비례해 커져 몸이 늘어난다(스파게티화). 같은 지평선 거리에서도 작은 블랙홀은 치명적이고 거대한 블랙홀은 얌전하다.

## 조작 변수
- 블랙홀 질량(도구대 3칸): 태양의 10배, 400만 배(우리 은하 중심 급), 10억 배.
- 거리(레일 손잡이, 로그): 지평선 반지름 r_s의 1000배 ~ 지평선 안쪽 0.0005배.
- 몸 방향(손잡이 돌리기): 발부터(세로) / 옆으로(가로).
- 몸 길이는 1.7 m 고정.

## 물리 모델 (`src/15-physics.js`)
- 상수: G = 6.674e-11, c = 2.998e8, M☉ = 1.989e30 kg, g = 9.81, L = 1.7 m.
- 지평선 반지름 `rs(M) = 2GM/c²`: 10 M☉ → 29,538 m; 4e6 M☉ → 1.1815e10 m; 1e9 M☉ → 2.9538e12 m.
- 몸 양 끝의 중력 가속도 차(뉴턴 근사): `Δa(M, r, L) = 2GM·L / r³ = c²·rs·L / r³`(r은 중심까지 거리, 몸 방향이 세로일 때). 가로 방향은 몸 양쪽 끝을 모으는 압축력 `Δa_c = GM·L / r³`(방향만 다르고 크기는 절반으로 단순화), 이 근사는 r이 r_s의 몇 배 이상일 때 의미 있고 지평선 근처는 추정이다.
- 견딜 한계(추정): 몸 양 끝 가속도 차 100 m/s²(약 10 g). 스파게티화 반지름 `r_sp = (c²·rs·L / 100)^(1/3)`. 지평선 반지름과 비교한 `r_sp / rs`: 10 M☉ ≈ 120.5(지평선 밖에서 이미 찢어짐), 4e6 M☉ ≈ 0.0222(지평선 안쪽에서 찢어짐, 즉 지평선을 건널 때는 멀쩡), 1e9 M☉ ≈ 5.59e-4.
- 지평선 위의 Δa(`r = rs`): 10 M☉ → 1.7512e8 m/s²(약 1.79e7 g), 4e6 M☉ → 1.0945e-3 m/s², 1e9 M☉ → 1.7512e-8 m/s².
- 공개 API: `C`, `MASSES`, `rs(i)`, `dA(i, r_in_rs)`(r을 r_s 배수로 받는다), `spaghettiR(i)`(r_s 배수), `state(i, r)` = `{ intact: boolean (Δa ≤ 100), stretch (시각 과장 계수, 아래), crossedHorizon: r<1 }`, 판정 함수.
- 시각 늘어남 과장: `stretch = 1 + 0.9·tanh(Δa / 100)·(…)` 처럼 단조 증가하고 Δa=100에서 약 1.7배, 극단에서 4배로 포화(⤢ 표시, 수식은 구현이 정하고 reviewer-brief에 적는다).
- 기대값(요구사항에서): 위 rs·Δa·r_sp 수치(±0.5%, 지평선 위 Δa는 ±1%), Δa는 r에 대해 r⁻³(거리를 반으로 줄이면 8배, 정확히 8.0), r_s 배수 입력과 m 단위 입력이 같은 결과, 질량을 10배로 하면 같은 r_s 배수에서 Δa가 1/100배(= 1/M²).

## 영웅 장치와 방
- 방: 천체 관측 연구실(성도 패널, 망원경, 돔 창의 밤하늘).
- 장치: 콘솔 위 **시공간 격자 탁상**. 블랙홀은 격자판 가운데 깔때기(어두운 구 + 사건의 지평선 링 발광, 강착 원반 셰이더, 격자 휘어짐), 몸은 막대 모양 "탐사 막대"(양 끝 마커 둘, 길이=몸). 거리 레일은 격자판 위. 몸이 가까이 갈수록 막대가 길게 늘어나고 옆 방향은 얇아진다.
- 시각 문법: 발/머리 당김 화살표(마디, 은색), 차이 화살표(청록, 늘어남 방향), 한계 윤곽(점선 링 = 스파게티 반지름 r_sp, 붉은 실선 링 = 지평선), 바꾸기 전 값 점선 잔상, 몸이 한계를 넘는 순간 사건(슬로 + 해설 기호 하나).

## 퀘스트
1. 가까이 가면 발과 머리가 받는 힘의 차이는? (10 M☉, 거리를 줄이며 차이 화살표) 후보: 차이가 없다(오개념) / 조금 커진다 / 아주 많이 커진다. 판정: 거리 ≤ 1000 r_s에서 20 r_s 이하로 접근.
2. 거리가 반이면 몇 배? 후보: 2배(오개념) / 4배 / 8배. 판정: 거리를 두 배 다른 두 걸림 칸에 놓아 비 8을 확인.
3. 몸이 찢어지는 선은 지평선 안일까 밖일까? (10 M☉) 후보: 지평선 안 / 지평선 바로 위 / 지평선 훨씬 밖(정답 약 120 r_s). 판정: r ≤ r_sp 에 도달해 intact=false 사건.
4. 질량이 큰 블랙홀은 더 위험할까? (400만 배로 바꿔 본다) 후보: 더 위험(오개념) / 같다 / 덜 위험(지평선에서 Δa가 1e-3 m/s²). 판정: 두 질량 모두에서 r = 1 r_s 에서의 Δa를 보는 비교를 열람.
5. 거대 블랙홀은 지평선을 건널 때 멀쩡할까? (정답: 건너고도 r_sp 이전엔 멀쩡) 판정: 400만 배에서 r < 1 이면서 intact=true 로 정지.
6. 설계 — 몸이 찢어지지 않고 지평선을 건너는 질량을 고른다(정답 400만 배 또는 10억 배, 10 M☉는 불가). 판정: 선택한 질량에서 `spaghettiR(i) < 1` 이고 r<1 에 intact.

## 근사와 한계
- 뉴턴 중력의 조석 근사. 지평선 근처의 상대론 효과(시간 지연, 실제 조석 계산)는 무시한다. 지평선 안쪽 거리는 "근사 값"으로 표시(추정).
- 견딜 한계 100 m/s²는 학습용 가정(추정).
- 강착 원반·격자 휘어짐은 시각 표현이며 비례하지 않는다(⤢).
- 몸을 가는 막대로 단순화한다.
